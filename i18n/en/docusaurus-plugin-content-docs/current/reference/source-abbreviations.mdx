The guide and the wiki originals were rechecked against `bedrock-wiki` 0930b39 (as of this wiki). The wiki commit the original guide recorded is `1d12a90`. License summary: `BW` is CC BY 4.0, so facts are rewritten in English with attribution and some are moved as an `Excerpt`. `BA` forbids redistribution, so only techniques were carried over. `MJ` and `NE` have no license, so only facts were carried over. `CN` has a noncommercial license, so only behavior rules were rewritten (the Cinnabar editor and evaluator are used only for noncommercial purposes, DBG-21). `NB` is a reading of Mojang's private binary for personal reference, so the analyzed code is not carried over and only behavior is rewritten.
