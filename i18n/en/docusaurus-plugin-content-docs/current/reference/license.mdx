# How the licenses apply

The text, analyses, code and test add-ons written by this project are under the MIT license (`LICENSE` at the repository root). This wiki also contains content taken from several sources. Each source has its own license, so the wiki follows the principles below. The source table at the bottom of each page shows which page uses which source, and the [source list](./sources.mdx) collects the full list by license.

## Excerpts and rewriting

The `redistribute` value in the registry is the standard.

- Sources with `redistribute: true` (MIT, BSD, Apache, CC BY, GPL, this repository's material) can have their original text moved into an `<Excerpt>` box. The box header states the source title, original path, license, and commit.
- Sources with `redistribute: false` (no license, All rights reserved, noncommercial licenses, NetEase documents, Mojang private binaries) are not copied. Only the facts are rewritten in English. The check script treats using such a source in an `<Excerpt>` as an error.

"Rewrite only the facts" means describing behavior, values, and structure without taking the wording or code as is. The rights to the original material still belong to its original author.

## Handling by license

| License | Handling |
| --- | --- |
| MIT (this repository's material) | Text, analyses, code and test add-ons newly written by this project. They can be used commercially too, as long as the copyright notice and license text are kept |
| CC BY 4.0 (Bedrock Wiki, MS Learn documents, Chest-UI, and others) | Excerpts of the original text are allowed. The source, author, license, and whether changes were made must be shown, so they are written in the excerpt box header and the table at the bottom of the page. Rewritten parts cite the same source |
| MIT, BSD-3-Clause, Apache-2.0 (third party) | Excerpted on the condition that the copyright notice and license text are kept. The license label in the excerpt box header and the table at the bottom are that notice. When software is taken as is, the original repository's LICENSE must be kept with it |
| GPL-3.0 (AsaJS, StarLibV2, and others) | By default, code is not taken and the behavior and techniques are described in prose. Where an excerpt exists, that block stays GPL and each block carries a license label. Taking an excerpted code block elsewhere means following the GPL-3.0 terms (source disclosure, keeping the same license). The rest of the wiki does not become GPL |
| PolyForm Noncommercial 1.0.0 (Cinnabar) | Used only to check behavior and as an implementation reference. The original text is not copied. The wiki rewrites only the Bedrock behavior learned that way |
| Facts-only sources | The original text is not copied. The source table states the license status (none, All rights reserved, and so on) as it is |

## What users must observe

1. **MIT notice**: When copying the parts written by this project, keep the copyright notice and license text from `LICENSE` with them.
2. **Keep the source**: When copying wiki content, carry the page's source table and the license label in the excerpt box header with it.
3. **GPL excerpts**: A GPL block taken elsewhere follows GPL-3.0.
4. **Trademarks**: Minecraft is a trademark of Mojang AB and Microsoft. The wiki is unofficial and has no relation to Mojang or Microsoft. All rights to Mojang files (`bedrock-samples`) belong to Mojang, so the wiki rewrites only facts and short structural descriptions.

A summary of third-party licenses is also in `NOTICE.md` at the repository root. This document is not legal advice. For a use that is not clear, read the original repository's license file yourself and decide.
