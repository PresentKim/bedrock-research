## Concept

Most JSON files have a line such as `"format_version": "1.21.0"` at the top. This number is the **syntax version of the subsystem for that file type**. It is not the game version. Minecraft uses this value to add new features without breaking old add-ons. For example, a `1.8.0` RP entity and a `1.10.0` RP entity have quite different syntax. Mixing different versions across files is normal. Avoid the temptation to "change format_version to the latest game version". (Source: bedrock-wiki, guide/format-version)

```json
{
  "format_version": "1.10.0",
  "minecraft:client_entity": { "description": { "identifier": "wiki:ghost" } }
}
```

**Automatic correction**: a wrongly written value "falls down" to a valid one. For example, a `1.11.0` RP entity is read as `1.10.0` and gives no error. This system is not well known and does not apply to every file, so do not rely on it.

**How to choose**: download the vanilla packs (bedrock-samples) and follow the value used most often or most recently for the same file type. The tables below are the vanilla distribution counted by the wiki as of 1.21.50 (⭐ recommended).

## Rules and reports

- **format_version is not the game version**: it is the version of a subsystem/file type (for example game 1.21.131, block format 1.21.130). https://wiki.bedrock.dev/guide/format-version#format-version-is-not-game-version . History per file: https://wiki.bedrock.dev/blocks/block-format-history , https://wiki.bedrock.dev/items/item-format-history *(confirmed)*
- **Representative values by the wiki (cited 2026-01-03)**: RP attachable, client entity, animations, animation controllers, render controllers, particles `1.10.0`; geometry `1.16.0`; sound definitions `1.20.20`; fog `1.16.100`; blocks catalog `1.20.40`; BP entity `1.21.60`, item `1.21.30`, recipe `1.21.60`, spawn rules `1.17.0`, trade table `1.18.10`. Other observations: BP entity `1.21.130`, render controller `1.8.0`, spawn_rules `1.8.0`, `sound_definitions` `1.14.0` (the more common value).
- **Latest entity format**: `1.26.0` in 2026-03, `1.26.10` recommended in 2026-04, `1.26.40` on 2026-08-20 (game 26.44). The old 1.16 broke baby spawn eggs without `minecraft:offspring`. In one case a client entity that would not load was fixed with `1.10.0`.
- **Entity format 1.26.50**: `interactions` of `minecraft:interact` must be an array (several triggers are allowed, around the sulfur cube update). `minecraft:leap_at_target` also needs the new format.
- **Leaving the format as it is** reportedly protects against behavior changes from updates, except for experimental features. On the other hand there are also problem reports about very old formats *(single reports)*: formats below 1.21.70/1.21.80 caused packet problems on mobile and were fixed, Android could not join a Realm that had old-block-format add-ons after 1.21.120, and a report that values from 1.10 to 1.16.100 are no longer registered while 1.20.10 works (file type unknown).
- **Raising the format** can make an entity silently disappear because component shapes change. Mixing item formats can make a recipe not show in the recipe book.
- **Item/block custom components** need a higher format_version to use the new schema (in Preview 26.0.x, item custom components required `"1.26.0"`).
- **Item tags need item format >= 1.20.50**, `minecraft:use_modifiers` needs 1.26.30, the spear sample needs 1.26.30, and `minecraft:fire_resistant` needs 1.21.120+ (it failed on 1.21.50/1.21.70). Geometry needs >= 1.16 for bindings.
- **The `is_experimental`** item flag no longer has any effect (experimental gameplay was split into individual toggles). The item `category` description format changed around 1.20.80.
- **bedrock-samples status**: release zips are at https://github.com/Mojang/bedrock-samples/releases . There are reports that the sample files are obfuscated (2026-10-01), that the full set is not on GitHub so it is extracted from the game folder (2026-11-02), and that the preview `terrain_texture.json` contains only new blocks (2026-11-05). Find biome/feature and sulfur cube JSON in BDS or the game install folder. Link collection: https://wiki.bedrock.dev/meta/useful-links#sample-behavior-resource-packs
- **Unofficial recipe format**: as of 2026-01 the latest is 1.21.60 (one user), and the `"unlock": {"context": "None"}` example is 1.26.30.
