| Term | Meaning |
|---|---|
| BP (behavior pack) | Pack that holds server-side definitions and scripts. Module type `data`, `script` |
| RP (resource pack) | Client assets such as textures, models, sounds and UI. Module type `resources` |
| Add-on | A bundle of a BP and an RP. `.mcaddon` is a compressed file that holds mcpack, mcworld, mctemplate and mceditoraddon files |
| `.mcpack` | Zip-format pack with the manifest at the root |
| `com.mojang` | Data folder where the game keeps packs, worlds and settings. The Windows shared path is `%AppData%\Minecraft Bedrock\Users\Shared\games\com.mojang` |
| `development_*_packs` | Folders for packs under development. Work here, not in a world copy |
| manifest | `manifest.json` at the pack root. Holds header, modules, dependencies and so on |
| header UUID | The identity of a pack. A BP and an RP must differ, and the UUID is not changed on updates |
| module | An entry in the manifest `modules`. Its type decides the pack kind |
| `format_version` (manifest) | Syntax version of the manifest. 2 is the array version, 3 is the string version with pack settings |
| `format_version` (file) | Syntax version of the subsystem for that file type. It is not a game version |
| `min_engine_version` | Minimum game version the pack supports. A low value turns on legacy behavior such as the old command parser |
| 26.x scheme | Year-based game version used since 2025-12. Internally and in the manifest it is `1.26.x` |
| Preview | Test build that is one line ahead of the stable release |
| Beta APIs | Experimental toggle that enables beta modules and features |
| subpack | Variant in the `subpacks/` folder. The default is chosen by memory tier |
| `memory_tier` / `memory_performance_tier` | Subpack selection criteria. Units of 0.25 GB / platform 1~5 |
| pack settings | `settings` in manifest v3. An RP reads them with Molang, a BP with `world.getPackSettings` |
| capability | Manifest `capabilities`. `pbr`, `raytraced`, `script_eval` and so on |
| Vibrant Visuals (VV) | Physically based rendering graphics mode. It stays on only if the RP has the `pbr` capability |
| system packs | `system_behavior_packs` and `system_resource_packs` folders since BDS 26.30. Applied automatically to every world |
| `cdn_config.json` | Unofficial config file that makes BDS fetch the RP from a CDN |
| BDS | Bedrock Dedicated Server |
| Content Log | Content error log turned on in Settings > Creator |
| `/reload` | Rereads scripts and functions of development packs. `/reload all` also rereads root tables and more |
| brarchive | Archive container with no official documentation. It bundles only JSON-family folders and is not a protection measure |
| brpak | Uncompressed, strictly validated zip variant used to deliver game files |
| MCB | Schema-dependent encoding used for data files inside brarchive since 26.50.x |
| `pack_optimization_version` | Header field of a pack that uses brarchive. Applies only with manifest format 3 |
| `contents.json` | Header file that holds the file list and keys of an encrypted pack |
| `content.zipe` | Empty file; if placed in a pack folder, the engine opens the pack with the encrypted access strategy and treats it as a trusted pack |
| trusted pack | Pack that Ore UI file lookup allows. The encrypted pack access strategy is always trusted |
| `.lang` | Text file of translation keys and values. Placed in `texts/` |
| jsoncpp | The game's JSON parser family. Comments are allowed, trailing commas are errors |
| Molang | Expression language used in animations, rendering, particles and more |
| `.mcfunction` | Function file with one command per line. LF line endings, no leading `/` |
| `tick.json` | File that lists functions to run every tick. They run at 0,0,0 |
| `.mcstructure` | Structure file. Format version 2 was introduced in 26.50.24 |
| Marketplace | Official store. Vanilla files are forbidden, only stable APIs are allowed |
| GDK | Basis of Windows builds since 1.21.120. The `com.mojang` path changed |
