This section collects the basics that every area of Bedrock add-on work runs into first. It covers where packs are placed, how to write `manifest.json`, why `format_version` differs per file, how a server sends packs down, and how the game version has changed over the years. Most "pack does not load" problems come from the manifest (`format_version` 2/3, `min_engine_version`, module versions) and from caches. This section gathers those causes in one place.

The baseline date is 2026-11-13. The game is covered up to the 26.60 stable release (2026-10-28), the 26.61 ~ 26.63 hotfixes and the 26.70 Preview. The evidence is community records from 2025-10-22 ~ 2026-11-13 (Source: private research), Bedrock Wiki (Source: bedrock-wiki) and Microsoft Learn (Source: ms-learn).

## Verification level notation

Marks such as `{vanilla}`, `{code}`, `{working pack}` and `{measured}` next to a rule show the kind of evidence. Items that come from community records carry *(confirmed)*, *(single report)* or *(conflicting)*. *(conflicting)* means the reports disagree, and in that case the latest report takes priority.
