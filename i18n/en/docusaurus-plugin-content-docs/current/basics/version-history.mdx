These are release/Preview facts collected from the versions notes of every topic (scripting, blocks, entities, graphics, UI, worldgen, packs). Dates are the dates of the reports, and exact release dates were matched against the Editor release mapping and npm publish dates. Version numbers from some sources are estimates. The version scheme and date table are in [versions.mdx](versions.mdx). (Source: private research)

## Before 2025-10 (background facts)

- **1.16.100**: a bug where sign blocks turned into other blocks was fixed in the 1.16.110 Preview, but the build from before the fix shipped as the release (a historical example).
- **1.17**: a claim (disputed) that Ender Dragon style long-distance rendering using runtime identifiers was patched.
- **1.18.30**: editing the camera file in resource packs was removed. The Deferred Lighting Shader (mcpedl) works only up to 1.18.30 because of RenderDragon.
- **1.19.50**: new `execute` syntax. Needs manifest `min_engine_version` >= [1,19,50].
- **1.20.50**: the method of enlarging structure block size by editing NBT was patched. Item tags need item format >= 1.20.50.
- **1.20.80**: script dynamic import support, `query.armor_damage_slot` added, item `category` format changed.
- **1.21**: jigsaw `max_depth` 7 -> 20 (Trial Chambers).
- **1.21.20**: a mention that old add-ons broke when Holiday Creator Features was removed (*conflicting* with the 1.21.90 ~ 1.21.100 description below).
- **1.21.44**: report of a change in item pickup when mobGriefing is off.
- **1.21.50.26 (Preview)**: first public look at jigsaw structures.
- **1.21.80**: TAAU became much blurrier than in 1.21.70 and below.
- **1.21.90**: corresponds to Script API 2.0.0 (some remember the 2.0.0 stable release as ~1.21.100, *conflicting*), `Player.isOp` removed and a permission level API added, `faceLocation` meaning changed (relative to the world origin corner), block custom components v2 and `destruction_particles` (block format 1.21.90), in 2.0 `worldInitialize` -> `system.beforeEvents.startup`, `runCommandAsync`, `ItemUseOn`, `world.events` and `player.velocity` removed, top-level module code is read-only (use `system.run`), `applyKnockback` changed to `({x,z}, vertical)`.
- **1.21.90 ~ 1.21.100**: old block JSON (events, `minecraft:on_placed`, legacy components) broke because Holiday Creator Features was removed. Around 1.21.100 the last layout change of jigsaw JSON (projection moved inside the element), and the pause screen player list moved to Ore UI.
- **1.21.110**: weighted texture variations (blocks), material instance texture variation, biome behavior format 1.21.110, and manifest v3 pack settings appeared in the Preview.
- **1.21.114**: store version for some users (1.21.114.1), `@minecraft/server` 2.2.0 stable, custom biomes generate stably without a toggle (`replace_biomes` needed). The last UWP stable releases for servers are 1.21.94 and .114 UWP.

## 2025-10 ~ 2025-12: 1.21.120, 1.21.130 (Mounts of Mayhem)

- **Preview 1.21.130.20~24 (from 2025-10-22)**: experimental `minecraft:connection_rule`, connection trait, `minecraft:has_fence_connections` tag (custom fences/stairs), multiple collision boxes (up to 16), custom stairs/`minecraft:support` (Upcoming Creator Features toggle), `blockDestructionSource` in the block destruction event, entity bounding box methods, `Dimension.getGeneratedStructures`. `@minecraft/server-graphics` in 1.21.130-beta.22 (control VV from scripts). A forced update dialog in the Preview.
- **Preview 1.21.120.24 (2025-10-24)**: the Upcoming Creator Features requirement was removed from `minecraft:redstone_producer`. Left-click detection (`swingSource` "Attack" of `playerSwingStart`) is Preview/beta only.
- **1.21.120 release (2025-10-28/29)**: Windows moved to the GDK (path change, performance reactions mixed, accessibility fade/dithering added, UI settings reset, input lag complaints). The manifest dependency `"beta"` resolves automatically to the latest compatible beta. `@minecraft/server` 2.3.0 stable (2025-10-29), `getAABB()` (another report says `Entity.getAABB` is from 2.4.0). `query.is_pack_setting_enabled` left experimental, `World.getPackSettings` (beta). Custom components V1 (`minecraft:custom_components`) deprecated. Camera `attach_to_entity`/`detach_from_entity` (fixed_boom, follow_orbit presets, https://feedback.minecraft.net/hc/en-us/articles/40566672351885-Minecraft-1-21-120-Bedrock). Colored point lights moved to the `local_lighting` folder (format 1.21.120). Block `emissive` material instance parameter and `alpha_masked_tint`. New item components in the 1.21.120 format work after retail. JSON UI `$is_big_screen` (new pause screen), some string multiplication tricks removed, a report that edits to start_screen.json do not apply. Jigsaw left experimental and became the official structure placement system (1.21.12x). RTX point lights broke, and the `scale` component of animal entities was removed so the heads of chickens and others overridden by packs became big. Stencil outlines partly work in VV. Linux/mac mcpelauncher could not run the latest release. Editor v1.1.5. GDK details: `.msixvc` package, a black window for 5 ~ 20 minutes on first run, mouse not captured, broken Game Bar recording, memory leak, 30% CPU in menus, the double-click import popup disappearing, a close-range translucent dithering accessibility setting, black background for title/action bar, UI scale change (MCPE-33349), MCPE-230623, a bug of fire-resistant items being lost fixed, Bedrock Launcher not supported (details in [versions.mdx](versions.mdx)).
- **1.21.121 / 1.21.122 (2025-11)**: 1.21.122 fixed the mouse bug MCPE-230832 (reproduction reports remain). Cannot import while running (MCPE-227874), missing exe icon, alt-tab glitch, Android failing to join a Realm that has old-block-format add-ons. The latest format at that time was 1.21.120.
- **Previews/hotfixes from late 2025-10 to November**: in the 2025-11-04 Preview, JSON UI `%.<n>s` behavior changed (custom health bars broke) and the material index water was updated. 2025-11-05 report of `query.self`/`get_nearby_entities` removal. 2025-11-11 Preview: a new way to fetch element bindings, static light (VV only). Preview 1.21.130 added the ticking area manager (Script API) and `server` 2.5.0-beta.1.21.130-preview.26. In 2025-11 jigsaw processors `minecraft:protected_blocks`, `minecraft:block_ignore` and `minecraft:capped` were allowed (undocumented), jigsaw always generates before features (same as Java), and right after the structure_set multi-structure bug was fixed there was a crash with a particular .mcstructure (MCPE-232661). Chain was renamed to `iron_chain`. After the 2025-11 update, double-click import needs the game closed and the packcache location changed.
- **1.21.123**: blocks with a `tick` component placed during worldgen by jigsaw (repeating command blocks and so on) now tick. The VV black sky bug was a problem of an earlier version. 1.21.124: block flower_pottable/embedded_visual, the last version where the Android structure export workaround worked. As of 2025-12-06 the stable release was 1.21.124.
- **2025-12-03 Preview 26.0.23**: PC keyboard input events, QuickJS update (`FinalizationRegistry`, `WeakRef`). 2025-12-04 Preview: biome water color in VV water, a fix for water disappearing vs fog, improved colored lighting. 2025-12-05 the Preview number changed to 1.26.0 and the year-based 26.x version scheme was announced (https://www.minecraft.net/en-us/article/minecraft-new-version-numbering-system). The announcement itself circulated first in community chat on 2025-12-02, and build 1.26.0.24 was mentioned around then.
- **1.21.130 release (2025-12-09, Mounts of Mayhem drop)**: spear, `kinetic_weapon`/`piercing_weapon`, `swing_duration`, `minecraft:is_spear` tag, enchantment slot `melee_spear`. New variables/animations were added to client player.entity.json so old copies broke (`v.melee_spear_equipped` unknown variable). The player model change broke outline templates. The new pause menu made the `/scoreboard objectives setdisplay list` display disappear, and the old execute syntax in script `runCommand` stopped working. Android structure export removed. Multiple collision boxes (format 1.21.130). Reference page https://learn.microsoft.com/en-us/minecraft/creator/documents/update1.21.130 . Editor v1.2.0. `@minecraft/server` 2.4.0 stable (2025-12-11), `@minecraft/server-graphics` 1.0.0-beta on 2025-12-15. Item event components, `minecraft:explodable` and `minecraft:render_offsets` removed. New blocks/items must be added manually to the Chest UI texture map. Spear textures are in `textures/items/spear/`. Additional reports: critical sound when not a critical hit, the `attack_interval is disabled (max <= 0)` log on hostile mobs, connection control block components, cooldown component, Editor tools disappearing in jigsaw worldgen packs, a shield first-person bug, broken icon and hand animation, broken hit animation because of an attack query change. The problem of beta API packs not loading on Realms/servers after 1.21.13x (unresolved).
- **2025-12 other**: jigsaw became official (non-experimental). Custom Nether biomes are Preview only (2026-01-06), and End biomes cannot be overridden. A bug where terrain_matching pieces overlap rigid pieces, and the only vanilla structures that can be overridden are the Trial Chambers and Trail Ruins. Biome JSON needs format 1.21.120+ and a nested `surface_builder.builder`. A light leak fix Preview strengthened sky light attenuation on the ground, and point light shadows under Y31 disappeared (recurred until 2026-07). The `entityHurt` beforeEvent exists only in the 2.6.0-beta of Preview 26.0.

- **1.21.131 / 1.21.132**: report of player.entity.json breaking (1.21.131), 1.21.132 was the stable release on 2026-02-07 and Hive server textures broke. Beta 2.5.0-beta.1.21.132-stable on 2026-01-31.

Blocks: custom stairs in the stable release (vanilla connection is a beta API), the connection trait broke multiplayer (no longer needed in Preview 26.10.20), improved ambient occlusion for custom blocks (disputed), some models rendered black (hotfix 2026-02-25), redstone power block API and redstone custom component events stabilized, `minecraft:connection_rule`, corner/cardinal connection traits, `redstone_consumer`/`onRedstoneUpdate`. Items: the >16x16 texture and `minecraft:damage` display bug (MCPE-180073) fixed (needs item format 1.26.0, https://wiki.bedrock.dev/items/item-format-history#_1-26-0), behavior of hiding in creative, the new `minecraft:food` format has no effects field. Custom camera splines (`camera/splines`). The RP breakage of `/reload all` fixed. Add-on format_version `1.26.0`, texture set `1.26.10`. After the 2026-02 update, adding a new function/script file needs a world reload. Around the 2026-02 stable release, inventory/crafting screen controls moved to a shared UI file and heavily modified inventory screens broke (server_form and NPC screens stayed the same), UI scale options -1/0 -> -2/-1/0, `collection_index` shifted by form header/label/divider (use `collection_panel`). Damage sensor `deals_damage` became the strings `"yes"`/`"no"`/`"no_but_side_effects_apply"`. A report in 2026-02 of the mob aggression setting changing. A promise to fix game exit problems. 3 RTX bugs (screenshots, point lights) fixed between 1.21.130 and 26.0.27, and about 50% of the RTX point light problem fixed in 1.21.130. Additional 2026-02 reports: block shadow change, Xbox crash, JSON/texture reset, Nether custom biome bug, missing creative textures in 1.26.10.20, "26.1" notation, breakage of 1.21-era experimental add-ons, old RPs broken by 1.26.0 UI changes, arrow damage not proportional to speed. On 2026-02-24 `@minecraft/server-admin` was disabled on Realms.
- **Script API (2026-02)**: `@minecraft/server` 2.5.0 stable (2026-02-10), `world.beforeEvents.entityHurt` usable in the stable release with the Beta APIs toggle (2.6.0-beta, 2026-02-10). New/beta events such as `PlayerSwingStart`, `EntityPickupItem`, `PressurePlatePushBeforeEvent`, `BeforeChatSend`, `playerButtonInput` and `Entity.target`, `getWeather` beta vs `setWeather` stable. ModalFormData element options became an options object. MCPE-230568 (player selector fails in custom commands for non-ops) unresolved since 2025-11.
- **2026-02-03 Preview 1.26.10.21**: DDUI introduced (server-ui 2.1.0-beta, server 2.7.0-beta). Preview 26.10.23: new Describe accessibility key (TTS). 26.10.24: fix for placing multi-block parts through commands. 26.10 Preview: `ambient_occlusion: false` turns off AO of custom blocks completely. 2026-02-13 server-admin scripting changes blocked transfer on Realms (https://help.minecraft.net/hc/en-us/articles/43490711924109-Update-Changes-to-Server-Admin-Scripting-Module). 2026-02-18 announcement of Java's move to Vulkan (VV for Java).
