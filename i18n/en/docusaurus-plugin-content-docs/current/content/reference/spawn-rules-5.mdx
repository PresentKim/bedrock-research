# Spawn rule reference (5/5)

This page excerpts the reference from MS Learn (MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0). Relative links in the original are removed.

(Source: ms-learn, `creator/Reference/Content/SpawnRulesReference/Examples/SpawnRulesList.md`)


### Spawn Rules Documentation

| Spawn Rules | Description |
|:-----|:----------|
| Spawn BiomeConditions| Defines the conditions under which an entity can spawn, including biome filters, brightness, height, and herd settings. |
| Spawn BrightnessFilter| Restricts mob spawning based on light level at the spawn location. |
| Spawn DelayFilter| Delays entity spawning by a configurable amount of time after spawn conditions are met. |
| Spawn DensityLimit| Limits how many of this entity type can exist in an area, with separate caps for surface and underground spawning. |
| Spawn Description| The description block that identifies which entity these spawn rules apply to, via the entity identifier (e.g., 'minecraft:zombie'). |
| Spawn DifficultyFilter| Restricts mob spawning to specific difficulty levels (Peaceful, Easy, Normal, Hard). |
| Spawn DistanceFilter| Controls spawning based on distance from the nearest player. |
| Spawn HeightFilter| Restricts entity spawning to specific Y-coordinate ranges. |
| Spawn Herd| Configures group spawning behavior, including minimum and maximum herd size. |
| Spawn MobEventFilter| Controls spawning based on whether a specific mob event is active. |
| Spawn PermuteType| Weighted spawn permutation that selects which entity variant to spawn. |
| Spawn PlayerInVillageFilter| Restricts spawning based on whether a player is within village boundaries. |
| Spawn Rules| Defines the complete spawn rules for an entity type, including population control group, spawn conditions (biome, light, difficulty, etc.), and herd configuration. |
| spawn_rules_document| A spawn rules definition document for Minecraft Bedrock Edition. |
| spawn_rules_header| Defines the header fields for a spawn_rules document. |
| Spawn Weight| Defines the relative probability of this entity spawning compared to other entities in the same biome and spawn pool. |
| Spawn WorldAgeFilter| Restricts spawning based on how long the world has existed (measured in ticks). |

#### Internal/Deprecated Components
These components are either deprecated or internal to Minecraft and not usable in custom content.

| Spawn Rules | Description |
|:-----|:----------|
| spawn_spawnaboveblockfilter| Filters spawning based on blocks above the spawn location. |
