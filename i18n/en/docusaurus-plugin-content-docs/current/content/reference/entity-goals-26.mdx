## minecraft&#58;behavior.offer_flower

(Source: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_offer_flower.md`)

> [!Note]
> Requires a flower item to be held by the entity.

> [!Note]
> Can only be used on the following type of entity:
