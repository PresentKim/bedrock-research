## minecraft&#58;behavior.ranged_attack

(Source: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_ranged_attack.md`)

Allows an entity to attack by using ranged shots. "charge_shoot_trigger" must be greater than 0 to enable charged up burst-shot attacks. Requires minecraft:shooter to define projectile behaviour.

#### attack_interval

Reload-time range (in seconds), when not using a charged shot. Reload-time range scales with target-distance.  Check that the limits imposed on the range (minimum, maximum and maximum distance between values) are respected.

#### in_range_movement_mode

Controls how the entity moves while its target is within the configured attack range. "hold_position" makes the entity stop and hold its position while facing and attacking the target. "follow_target" makes the entity continue moving toward the target while attacking, stopping just outside the minimum attack range.

## minecraft&#58;behavior.roar

(Source: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_roar.md`)

Allows this entity to roar at another entity based on data in `minecraft:anger_level`. Once the anger threshold specified in `minecraft:anger_level` has been reached, this entity will roar for the specified amount of time, look at the other entity, apply anger boost towards it, and finally target it.

> [!Note]
> Requires the following component in order to work properly:
> 
> * Anger Level (minecraft:anger_level)
> 

### Entity Roar Behavior Properties

| Name | Default Value | Type | Description | Example Values |

| control_flags | [] | Control Flags choices |  |  |
| duration | 0 | Decimal number | The amount of time to roar for. | Warden: `4.2` |
| priority | 0 | Integer number | As priority approaches 0, the priority is increased. The higher the priority, the sooner this behavior will be executed as a goal. | Warden: `2` |
