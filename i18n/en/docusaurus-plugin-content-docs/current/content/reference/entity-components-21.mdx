## minecraft&#58;tick_world

(Source: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_tick_world.md`)

Defines if the entity ticks the world and the radius around it to tick.

### Entity Tick World Properties

| Name | Default Value | Type | Description |
| --- | --- | --- | --- |
| distance_to_players | 128 | Decimal number | The distance at which the closest player has to be before this entity despawns. This option will be ignored if never_despawn is true. Value must be &gt;= 128. |
| never_despawn | true | Boolean true/false | If true, this entity will not despawn even if players are far away. If false, distance_to_players will be used to determine when to despawn. |
| radius | 2 | Integer number | The area around the entity to tick. Value must be &gt;= 2. Value must be &lt;= 6. |

#### Entity ActorDefinitionTrigger
Triggers an entity event when specified conditions are met. Events activate component groups that change entity behavior—transforming villagers into zombie villagers, switching mobs to aggressive mode, or triggering growth stages. Combine with filters to create conditional state machines that respond to gameplay.

## minecraft&#58;trade_table

(Source: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_trade_table.md`)

Defines this entity's ability to trade with players.

### Entity Trade Table Properties

| Name | Default Value | Type | Description |
| --- | --- | --- | --- |
| convert_trades_economy | false | Boolean true/false | Determines when the mob transforms, if the trades should be converted when the new mob has a economy_trade_table. |
| display_name |  | String | Name to be displayed while trading with this entity. |
| new_screen | false | Boolean true/false | Used to determine if trading with entity opens the new trade screen. |
| persist_trades | false | Boolean true/false | Determines if the trades should persist when the mob transforms. |
| table |  | String | File path relative to the behavior pack root for this entity's trades. |

#### convert_trades_economy

Determines when the mob transforms, if the trades should be converted when the new mob has a economy_trade_table. When the trades are converted, the mob will generate a new trade list with their new trade table, but then it will try to convert any of the same trades over to have the same enchantments and user data. For example, if the original has a Emerald to Enchanted Iron Sword (Sharpness 1), and the new trade also has an Emerald for Enchanted Iron Sword, then the enchantment will be Sharpness 1.

#### persist_trades

Determines if the trades should persist when the mob transforms. This makes it so that the next time the mob is transformed to something with a trade_table or economy_trade_table, then it keeps their trades.

## minecraft&#58;trail

(Source: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_trail.md`)

Causes an entity to leave a trail of blocks as it moves about the world. Obeys Mob Griefing rules.

### Entity Trail Properties

| Name | Default Value | Type | Description |
| --- | --- | --- | --- |
| block_type | air | String | The type of block that is placed. Solid blocks cannot be placed at the entity's position when offset is [0, 0, 0]. |
| extent | 0 | Integer number | Maximum horizontal distance from the center at which blocks can be placed. Value must be &lt;= 16. |
| offset | [0, 0, 0] | Array of numbers | Offset from the entity's position used to determine where trail blocks are placed and placement checks are applied, capped at 16 blocks away. |
| offset (Offset) | *not set* | Offset (Offset) item |  |
| place_only_on_block_position_change | false | Boolean true/false | When true, trail blocks are only placed on ticks where the bottom of the entity moves into a different block position, or where the entity lands (goes from airborne to grounded). |
| placement_checks | block | Placement Checks choices | Controls the checks applied at each trail block placement position before placing the trail block. |
| placement_conditions | [[object Object]] | Array of Placement Conditions items | Conditions that must all be satisfied relative to the trail block placement position. |
| placement_filter (Placement Filter) | &#123;"AND":null,"NOT":null,"OR":null,"all":null,"all_of":null,"any":null,"any_of":null,"none_of":null&#125; | Placement Filter item | One or more conditions that must be met in order to cause the chosen block type to be placed. |
| placement_filter (Alternate 1) | *not set* | Object |  |
| shape | corners | Shape choices | Controls the horizontal placement pattern. 'corners' places four corner blocks, 'square' fills a square, and 'circle' fills a circular disk. Defaults to 'corners'. |
| spawn_filter | *not set* | Minecraft filter | Conditions that must be met for the trail block to be placed. |
| spawn_offset | [0, 0, 0] | x, y, z coordinate array | Offset from the entity's position where the trail block is placed. |

#### offset

Offset from the entity's position used to determine where trail blocks are placed and placement checks are applied, capped at 16 blocks away. X and Z are relative to the entity's orientation and rotate to its nearest cardinal facing; Y is a vertical offset.

#### place_only_on_block_position_change

When true, trail blocks are only placed on ticks where the bottom of the entity moves into a different block position, or where the entity lands (goes from airborne to grounded). Standing still or moving within the same block does not place blocks. Defaults to false.

#### placement_checks

Controls the checks applied at each trail block placement position before placing the trail block. 'none' applies no placement checks, 'block' applies block placement conditions, and 'standard' applies standard block placement rules, including clearance from entities that obblock placement.

#### placement_conditions

Conditions that must all be satisfied relative to the trail block placement position. Block types within one condition are alternatives. When omitted, defaults to [&#123; "y_offset": 0, "block_types": ["minecraft:air"] &#125;]. Value must have at least 1 items.
