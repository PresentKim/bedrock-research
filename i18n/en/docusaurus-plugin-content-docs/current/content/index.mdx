# Add-on content

This section covers the game content that a behavior pack (BP) defines. JSON UI and rendering are in other sections. Here the focus is "what gets defined" and "how far it goes". Every page is written in this order: concept explanation, working examples, rules and community reports. Verification levels are marked `(confirmed)`, `(conflicting)`, `(single report)` and `(unverified)`.

The common premises are as follows.

- A feature is opened by the `format_version` of its file. Raise it to the latest value (entities 1.26.40~1.26.50 as of 2026-08) and turn on the Content Log to check.
- The old event system (item/block events of Holiday Creator Features) is gone. Items and blocks use script custom components (`"ns:comp": {}` + `registerCustomComponent`), and entities use component groups + events.
- Most vanilla content is hardcoded. The range you can fix by overriding vanilla JSON with the same identifier is narrow.
- The evidence is community research (2025-10~2026-11), Bedrock Wiki (0930b39), MS Learn (a9fd1c0) and bedrock-samples (15701fa9).
