# Ore UI and DDUI

Ore UI is the new game UI Mojang built to replace JSON UI. It is written in HTML, JS and CSS and rendered by Coherent Labs' Gameface engine. This section summarizes how far Ore UI can be changed with resource packs and servers, based on results verified on a real client and on what was read from the binary.

## Conclusion in one line

Up to 26.63, if a server sent a resource pack encrypted with a content key (or a pack had an empty `content.zipe`), that pack could replace the HTML, JS and CSS of Ore UI wholesale. In 26.64 Mojang blocked resource pack access to Ore UI for a security reason, and this route is now closed (Source: private research). The only routes a plaintext pack reaches are the button style bridge, `pack://` textures and the DDUI layout (currently blocked). The table below gives the current state of each route.
