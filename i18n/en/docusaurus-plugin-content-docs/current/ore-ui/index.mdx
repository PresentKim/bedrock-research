# Ore UI and DDUI

Ore UI is the new game UI Mojang built to replace JSON UI. It is written in HTML, JS and CSS and rendered by Coherent Labs' Gameface engine. This section summarizes how far Ore UI can be changed with resource packs and servers, based on results verified on a real client and on what was read from the binary.

## Conclusion in one line

If a server sends a resource pack encrypted with a content key (or you put an empty `content.zipe` in a local pack folder), that pack can replace the HTML, JS and CSS of Ore UI wholesale. The only routes a plaintext pack reaches are the button style bridge, `pack://` textures and the DDUI layout (currently blocked).
