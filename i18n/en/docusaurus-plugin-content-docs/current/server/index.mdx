This section covers the server side. Its topics are official BDS operation and configuration, the network protocol (RakNet, NetherNet), how a server sends resource packs, defining custom blocks, items and recipes from server code without a BP (the Dragonfly case), camera, HUD, fake blocks and chunks sent to a single player, and server performance. JSON UI and Ore UI, which run on the client, are covered in other sections; this section explains the channels the server uses to load data into that UI.

## Reading order

If you operate BDS, read server software, performance, and pack delivery in that order. If you build a custom server, start with the protocol basics, then move to resource pack delivery and custom content. The version scheme and pack manifest are in the basics section.
