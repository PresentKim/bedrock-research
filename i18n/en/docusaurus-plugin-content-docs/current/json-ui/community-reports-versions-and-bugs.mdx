This collects the known limits and workarounds from community reports, a timeline of changes by version (1.19.20 ~ 26.70), community tools and material, and questions that still have no answer.

The reliability markers and the source tags at the ends of items are the same as in the header of the community reports and cross-check page: *confirmed* means confirmed by several people, *single report* is one person's report, *unverified* is a guess, and **conflicting** means the reports disagree.

## Known limits and workarounds

- **List of data that cannot be read**: health, effects, player properties, tags, scoreboard values, dynamic properties, Molang, brightness, whether third person, the charge of a held item, GUI scale, parent size, texture size, and the world name (in forms) cannot be read. Workaround: the script sends them as title/actionbar/subtitle/chat/form text and JSON UI parses them.
- **No UI -> script**: the UI cannot call the script. Workarounds: form submit, the item drop mapping (`button.drop_one`/`drop_all`), a chat message + `chatSend`, hotbar slot selection.
- **An open form cannot be updated**: a JSON UI form has to be resent. DDUI is real time but cannot be decorated. Container screens (chest UI) update in real time.
- **Buttons close the form**: `form_button_click` always closes. Workarounds: reopen by recursion, change in-form state with a custom button id (`button.menu_left/right`), and hide flicker by removing screen animations.
- **No custom keybinds or opening screens**: a HUD button cannot open a form or NPC dialogue. A custom button cannot open a custom screen (button ids are hardcoded). A custom screen cannot be made, and instead a hidden panel inside an existing screen is revealed with `#toggle_state` + `#visible`.
- **No rotation, no randomness, no `Includes`**: there is no Molang visibility either. Workarounds: pre-rotated textures, flipbooks, player.json/paperdoll models, GeoUI.
- **Crash pitfalls**: wrong values in size/offset bindings, string division, literal real-number division, arithmetic on a title without a prefix, appending `= #text` to `('§' + #text)` (crash reports), `and` inline in `binding_name` on mobile, and big images. Windows and Android die on different wrong expressions. There is also a report that Android died from a title-splitting UI.
- **Collisions between packs**: the title/actionbar are shared resources. Use a shared queue convention (for example the UI Queue add-on `/scriptevent ui_load:<id> <message>`) or set pack priority. For `modifications`, only the upper pack wins. Compatibility of non-form custom UI is poor. So there are cases of avoiding it with script cameras and particles instead of editing player.json/UI.
- **Form lag**: reduce it with grids, `binding_condition: once`, creating 0/1 with a factory, `ignored`, page splitting, lazy loading of tabs and merging elements.
- **Hidden-slot text substitute**: chest UI has no arbitrary labels, so carry text and values in the name, lore and durability of hidden items (heavy).
- **PC/mobile differences**: HUD buttons are touch only. Moving while a form is open also works only on touch. A mixed custom hotbar behaves differently on mobile and desktop (unresolved).
- **No links**: add-ons cannot open clickable links. Show a QR code image with JSON UI (qrcode-monkey.com).
- **A trading villager replacement mod**: impossible because the screen closes when the UI refreshes.
- **Duplicate child name warning**: the duplicate child control name warning in `how_to_play_screen.json` will become an error. The hud_screen of old packs gives parse errors. When scripts were active, the HUD "waila" pack gave `JSON UI parse failure - expected a string`.

## Changes by version

- **1.19.20**: the `ignored` property and variable/binding behavior changed without documentation (how operators are supported, variable errors inside the same block).
- **~mid 2025**: `#form_button_contents` appeared and the `control_ids` factory pattern became usable. Form header/label/divider were added in 1.21.x and shifted the button `collection_index`.
- **Late 2025-10**: some string multiplication tricks were removed. The 2025-10-29 release brought a new pause screen and `$is_big_screen`.
- **2025-11-04 preview**: some uses of `%.Ns` (health bar, number display) broke and noxcrew is said to have requested a crash fix. In the 2025-11-11 preview, a feature to fetch bindings from elsewhere appeared (leading to `resolve_ancestor_scope`).
- **1.21.114**: `initial_uv` gave "unknown property" in the `hud` namespace.
- **1.21.120/121 (GDK, 2025-11)**: there is a report that Ore UI may fail to load because of a memory leak. *single report*
- **1.21.123 stable / 1.21.130.26 preview**: multi-value title positioning was confirmed to work.
- **1.21.130 (stable 2025-12-09)**: string multiplication was restricted to the literal `'%.Ns' * #x` (dynamic N, `%X.*Xs`, `%-Xs` and `%Xs` impossible. It was not in the changelog, and one theory says it was because of a crash fix request from a server studio). The `* 1` number conversion broke. The byte boundary of `%.Ns` was "fixed". aux textures/Chest-UI item icons broke (the `% 65536` fix). The `resolve_ancestor_scope` view binding was added (updatedjsonui changelog). In 1.21.13x new subtitles and an image ratio property appeared. `/reload all` and global resource UI reload bugs appeared.
- **1.21.130 / 1.21.132 (Android)**: the pack behavior of overriding JSON UI to turn on the Android structure export button was blocked in 1.21.130, and after the change to Ore UI, such add-ons broke in 1.21.132. In 26.60 a pack appeared that revived "Export world" with the Ore UI bundle .js.
- **2025-12 mid update**: the `(#hud_title_text_string*1)` progress bar stopped and was fixed with `+0`. After the spear update, `live_player_renderer` hid attachables (fixed with layer).
- **2026-01 preview**: Ore UI replaced menus/settings with server treatments. `1 * ('%.1s' * x)` broke. Stack panel `use_priority` appeared. The explicit aux item renderer became odd (1.21.13x/preview).
- **2026-01-29**: the official JSON UI reference was posted on learn.microsoft.com (auto-generated from vanilla examples and sloppy. Mojang said it will polish it).
- **2026-02**: DDUI entered Preview. In stable the inventory/crafting UI was refactored and custom crafting UIs broke. There is a report that the 2026 update broke the old preserved-image setup.
- **2026-04**: DDUI became beta. Reports appeared that `resolve_ancestor_scope` does not work or raises errors in stable. In 2026-04-26 stable, modifying the hud root caused an auto-save animation error.
- **2026-05**: `property_bag_for_children` entered stable (~05-07). In the 1.26.30 line, `(#str * 1)` stopped, so use `(0 + #str)` (reported 05-15). There is a mention that the crosshair renderer was separated from the hud file (05-25). An effects renderer bug appeared.
- **26.30 (stable 2026-06-16)**: DDUI CustomForm became stable. There is a recollection that `%.Ns` behavior changed in 26.30 (a chat prefix `%.6s` check did not match. Cause unconfirmed).
- **26.40**: hiding the world seed became a default feature. `@minecraft/server-ui` preview 2.2.0-beta.1.26.40.
- **26.50**: lang `tile.<id>.tooltip` item tooltips appeared.
- **1.26.52.3**: the `button.sub_command` chat button caused a client crash on third-party servers.
- **1.26.60.28 preview**: DDUI `styleId` appeared (needs a native mode). In 26.70.21, `@minecraft/server-ui` 3.0.0-alpha supports it without a mod.
- **2026-09 (stable, timing unclear)**: there is a report that variables can be multiplied but bare numbers can no longer be multiplied. *single report*
- **2026-09-22 preview**: JSON UI content-log errors increased. The offhand/hotbar was refactored. In the 2026-10-06 preview error logging improved, and on 2026-10-13 the error types changed again. In the preview, custom block entity `container` `title` and custom container `$container_title` appeared.
- **2026-10-15 confirmed**: the crosshair was moved to `ui/hud_crosshair_overlay.json`.
- **26.60 stable (2026-10-27)**: Ore UI loading became faster. `@minecraft/server-ui` stable 2.3.0. There are reports that the enchantment, use and attack damage lines of tooltips all became the same color and that Korean-language line spacing is wide. The Switch 2 received a separately built version from 26.60. [supplement 2026-10-28]
- **26.70.22 preview (2026-10-28)**: item tooltip lang keys became `item.<id>.tooltip` and lines are split with `~LINEBREAK~` (the `tile.` prefix of 26.50 is no longer needed). The key "Close Custom Screens" for force-closing custom DDUI. The "1." prefix was removed from the Ore UI main menu version display (MCPE-243637). The changelog listed the Ore UI internal packages `@mojang/bedrock-core-engine` and `@mojang/react-device-information`. [supplement 2026-10-28]
- **26.62.1 hotfix (2026-11-05)**: the Ore UI hash file names changed (`index-196362d73210d5a80339.js`, `index-8a62c541ed5f344be00f.css`, `menus-theme-ed1e9065b019d5f4427f.css`, `gameplay-theme-922e7c15cd35326d4a6a.css`). [supplement 2026-11-04]
- **26.70.23 preview (2026-11-03)**: the changelog said that `ui/data_driven_container_screen.json` (namespace `data_driven_container`, the custom block entity container UI) is not expected to be modified by creators and backward compatibility is not guaranteed. "Support existing custom Minecraft emoji Unicode code points in Ore UI screens" was included, but there is a report that on most screens other than the save toast (the death screen, the world list) they appear as squares. The `/chat show <global|party|world>` chat channel, the offhand swap key (F), the `offhand_cooldown_renderer` string and the lang `hbui.MainMenu.Discovery.*` appeared. There is a single report that the DDUI panel background disappeared. [supplement 2026-11-03..06]
- **UWP 1.26.6301.0 (reported 2026-11-10)**: the Ore UI bundle name is `gameplay-react-<hash>.js`. Conduit client v0.5.0-beta supports .62/.63.
- **2026-11-12**: a new main menu with Marketplace ads, a Realms banner, servers and recent worlds was spotted (version unknown). *unverified*

## Open questions

- **JSON UI deprecation schedule**: when will JSON UI be removed? Will old JSON UI packs (server forms, HUD) work after the transition to Ore UI? There is no clear Mojang schedule.
- **When DDUI layouts/styles will be published**: the time when creators can write layout files and customize the HUD and containers is undecided.
- **The current state of `resolve_ancestor_scope`**: reports that it works and that it does not are mixed.
- **The exact meaning of string `-`**: does it erase all occurrences or only the first? Under what conditions does the `* 1` conversion work in the current version?
- **Same-name slider problem**: sliders with different `collection_index` behaving like one, and a collision of two sliders.
- **The exact meaning of ancestor/scope and `binding_condition`**: especially `visible`/`always_when_visible`.
- **Why the `mob_effects_renderer` Y offset has no effect**: and the bug where the status effect bar disappears while a title is rendered.
- **Preserved icon flicker**: flicker of preserved icons crossing subtrees, and the bug where a slot with a background image shows only when other slots are filled.
- **`/title @s clear` and the preserved title**: how to clear a preserved title?
- **Grid start position and empty grid scrolling**: how to start a grid from a specific slot, and the problem of the scrollbar showing in a scroll panel that holds an empty grid.
- **Putting a control name into a custom factory's `control_ids` as a variable**, and the problem that using a `#title_text` collection binding in a factory panel creates only one.
- **Changing the chest grid size by container title** (an attempt with `variables` failed).
- **Controller 2D dragging, detecting the last typed character, and identical mobile/desktop mixed hotbar behavior**.
- **Applying a different `.lang` per subpack**.
- **About DDUI**: how to control a slider in real time while fading a DDUI screen, and the dropdown item observable label update bug.
- **How to change the Ore UI play menu with an RP**, editing the death screen's red overlay, hiding the recipe panel by default, hiding name tags behind blocks, and hiding the interaction button/selection outline. All had only questions and no answers.
- **Subtracting from a result that starts with `:`**: after getting `#data` = `:1816` from the title `xTitle:1816`, `(#data - ':')` becomes empty. It seems related to the rule that a result starting with digits is treated as a number, but it was not confirmed. [supplement 2026-10-24]
- **Flash and delay when resending a server form**: why the screens flash in between when resending a form with a modified server_form factory, and what makes a server form open late.
- **Preserving container toggle state**: how to keep a custom toggle state even after closing and reopening a container.
- **The future of the `content.zipe` trust path**: whether and when Mojang will block this path.
- **The `titleraw` `§u` background trick**, the uses of `binding_collection_prefix`/`notify_on_ellipses`, and the use of stack panel `use_priority`.
