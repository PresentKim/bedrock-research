## Concept: how to use this dictionary

The property values of JSON UI (`type`, `anchor_from`, `binding_type` ...) differ between the official schema enums, wiki documents and actual vanilla use. This dictionary counts the values used as literals for each property in the 207 UI files of vanilla 1.26.50.4 and compares them with the official enums. For example, `"type": "panel"` is the most common at 4092 uses, and some values such as `factory` and `collection_panel` are not in the enum but vanilla uses them (**X** in the table). Before using a new value, check in this table that the vanilla count is not 0. Even if a tool (schema checker, autocomplete) flags a value missing from the enum as an error, you can use it if vanilla uses it.



These are the values used **as literals** for each property in the 207 files of the vanilla resource pack `resource_pack/ui` v1.26.50.4 (`46ba6ea`), with their counts (an exhaustive search in this thread; because it is regex-based, some values inside comments may also be counted). The official enums are the values of `forms/ui/ui_element.form.json` in `@minecraft/bedrock-schemas` (the list recorded in BC-facts, the bedrock-core author's measurement record).

How to read
- A value with **X** in the `Official enum` column is used by vanilla but is not in the official enum. You can use it.
- A value with count 0 is only in the official enum and vanilla does not use it. Measure before using it.
- Values not in this table (the `scroll_box` type from external material, `grid_fill_direction: left_to_right`, `resolve_ancestor_scope`, etc.) have no evidence (C-07~C-09 and C-34 of the conflict table).

## B.1 Names not in vanilla (in an external dictionary but VN 0 times)

The following property names are in an external property dictionary (the repository MJ analyzed) but never appear in vanilla 1.26.50.4. Most are "unverified" names from the wiki. Measure before using them.

`resolve_ancestor_scope`, `z_order`, `clip_offset`, `alignment`, `use_place_holder`, `pixel_perfect`, `gradient_direction`, `vr_mode`, `use_uuid`, `use_skin_gui_scale`, `use_player_paperdoll`, `animation_looped`, `precached_grid_item_count`, `gesture_control_enabled`, `toggle_on_hover`, `slider_timeout`, `focus_container_custom_down`, `button_name` (Source: MJ 4.2)

## B.2 Properties vanilla uses but official material lacks

`collection_index`, `localize`, `clip_ratio`, `clip_direction`, `clip_pixelperfect`, `property_bag`, `variables` (and `$variable`), array-form `nineslice_size`, `factory_variables`. `modifications` is in neither official material nor vanilla and is used only by packs. (Source: BC-facts, VN)

The numbers are the final IDs in the merge report, and the strength of evidence follows the verification level of the original proposal. Check before using them.

The remaining extension proposals are an appendix comparing the `$` variable list (JsonEncryptor proposal FILE-29) and the factory list (COL-14/COL-25) against vanilla. They need a vanilla grep comparison and were left out of this scope.
