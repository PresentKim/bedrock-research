# Script API

This section covers the Script API, centered on `@minecraft/server`. It runs from the execution model and module versions through events, entity and world APIs, custom commands, storage, server-only modules, debugging and known limits, based on community research from 2025-10 to 2026-11 and the official documentation.

## Page map

| Page | Contents |
|---|---|
| [Script API overview and execution model](./overview-and-modules.mdx) | Module layout, manifest, TypeScript bundling, initialization order, restricted execution, scheduling, QuickJS runtime |

| [Events and combat](./events.mdx) | `world`/`system` event subscription rules, renamed events, join, interaction, item and combat events |

## Reading order

If you are new, read the overview and the module version page first, then go to the API page that matches the feature you want to build (events, entities, world, commands, storage). If you get stuck, look up the symptom in the workaround table on the last page.
