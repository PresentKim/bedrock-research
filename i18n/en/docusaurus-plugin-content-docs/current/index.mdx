# Bedrock development wiki

This wiki collects the research needed for Minecraft Bedrock Edition development in one place. It centers on JSON UI and also covers Ore UI, server UI, the Script API, add-on content, rendering, servers and protocols, tools, engine internals analysis, and case studies.

The earlier documents were hard to read because they pointed elsewhere with "see this file" references. This wiki excerpts the referenced information into the body and lists the source and license in a table at the bottom of each page. Rule IDs (`LAY-12`, `NB-07`, `C-31`, `D-05`) use the same values as the original material.

## Verification level marks

The `{...}` at the end of a rule or fact is the kind of evidence. The marks differ slightly from page to page, but the meanings are as follows.

| Mark | Meaning | Confidence |
| --- | --- | --- |
| `{measured}` | There is a record measured in game | High |
| `{vanilla}` | Actually used in the vanilla resource pack or data files | High |
| `{working pack}` | A distributed, working pack uses it that way | Medium-high |
| `{code}` | Confirmed by reading source, compiled output, binaries, or type definitions. Game behavior is not guaranteed | Medium |
| `{installed}`, `{verified}`, `{docs}`, `{record}` | Taken from the install folder, repository files, external documents, or records with no measurement conditions | Medium |
| `{inferred}` | Judged from the evidence above | Low |
| `{unverified}`, `{conflict}` | The evidence is unconfirmed or the sources disagree. Measure before use | Needs checking |
| `{needs measurement}` | Not verified in game | Needs checking |

The priority of judgments is `measured` > `vanilla` > `working pack` > `code` > `inferred`. Community reports are marked `(confirmed)`, `(single report)`, and `(conflicting)`. Examples not verified in game are noted separately on the page.

| Vanilla baseline for the guide | Mojang `bedrock-samples` `46ba6ea` (v1.26.50.4, 2026-09-16). Most rules were checked against a full search of the `ui/` files of this version |
| Latest check | `bedrock-samples` `15701fa9`. The version checked again when the wiki was written (2026-11-13) |
| Native binary | Android 1.26.52.3 native client library |
| Community research | 2025-10-22 ~ 2026-10-23 |
| External documents | Bedrock Wiki `0930b39`, MS Learn `a9fd1c0` |

When the version changes, the vanilla comparison is redone. If the version a rule is based on differs from the baseline, the rule states its version.
