# Limits, changes by version, tools, open questions

This is a page for finding workarounds starting from a symptom. Evidence and details are on each topic page (Source: private research).

## Known limits and workarounds

| Limit | Workaround |
| --- | --- |
| Cannot make only part of a block glow without VV | Whole-block light emission, flipbook brightness frames, imitate with entities/particles |
| `entity_emissive_alpha` glow does not work under VV | MER emissive channel + texture_set + pbr capability |
| One add-on turns off world VV | Add `"capabilities": ["pbr"]` to that pack's manifest |
| Auto exposure, shadow resolution and reflection quality cannot be changed by a pack | Edit local game files (your own PC only), compensate with color grading |
| VV tone mapper has no AgX/Lottes | veka.'s reproduced color grading settings, custom material.bin |
| VV settings are needed per biome | Override globally with `minecraft:default_*` identifiers, copy the client_biome for swamp/mesa |
| Flipbook stops at a distance, distant stripes | `num_mip_levels` 0 or 3, square, power-of-two, multiple-of-16 textures |
| Lines on water from the 26.30 padding removal | Define still-water flipbooks as 3 tiles, lower the mip level |
| Under VV, composite (additive) textures show only the top layer | Blocks fixed in 2026-07, items not fixed. Bake into a separate texture |
| No per-block-state local light | Make on/off separate block identifiers |
| Entities cannot be point lights | Use a custom light block |
| Translucent particles are very expensive under VV | Reduce the count, raise opacity, use small particles |
| Ordinary hand items cannot have an outline | Attachable + stencil material + outline model |
| Drawing an entity over a first-person attachable | The stencilRef 2 stencil recipe (the depth section of the materials and shaders page) |
| `light_color_multiplier`/`overlay_color`/`held_item_ignores_lighting` do not work on attachables | Make the attachable itself an emissive material |
| Attachables cannot add new locators, custom locator particles do not work | Reuse the player locator (`lead_hold`), offsets |
| Crash with more than 3 render controller texture arrays | Split into several render controllers |
| Render controller `math.random` flicker | Set once in `initialize`/`pre_animation`, or use a property |
| Large entities vanish when the hitbox is off screen | Enlarge `visible_bounds`, `should_update_bones_and_effects_offscreen`, proxy entity |
| Lag when player geo total exceeds 1.15 MB | Shrink models, minimize bones/groups, minify JSON |
| Shading bug on custom stairs/slabs | `ambient_occlusion` 0, `face_dimming` false, a custom version of the vanilla block |
| Cannot thin underwater fog under VV | Practically none (turn off fog in settings, volumetric block light) |
| VV reflections look pixelated | `texel_size` ~1024 + soft shadows |
| VV has no rough reflections | A high-resolution random-direction normal map (192x192) |
| RTX has no entity PBR/overlay textures | Do overlays with another model/render controller, glow with `charged_creeper` + `light_color_multiplier` |
| Model disappears or is see-through from dithering | Turn it off under Settings > Accessibility, raise the minimum alpha |
| `emitter_rate_manual` memory leak | Always specify `max_particles` (up to 1000) |
| Particles cannot read entity variables | client_sync entity property, MolangVariableMap, temp leaking (unstable) |
| Cannot distribute shaders in a resource pack | Replace material.bin, BetterRenderDragon (local only) |
| Cannot animate item textures | Bone visibility, render controller texture swap, an animated block that cannot be placed |
| Persona skins turn off when the player client entity is modified | Add min engine version, use the latest file of the installed game |
| No black and white filter (blending) | VV color grading saturation |
| Hidden bones also have a large render cost (per-bone cost grew under VV) | Merge bones, deactivate with a render controller |
| Attachable locators do not work | Offset computation, parametric/point emitters, a locator on the player model |
| MER not applied to the player entity | Make the glowing parts an attachable |
| No custom sound from particles (MCPE-101714) | Vanilla sound events, script |
| Texture variants break terrain textures (MCPE-244074) | Remove variants |
| Cannot hide vanilla water under VV | A transparent material drawn over the water (partial workaround) |

## Changes by version

- **1.16**: The mipmap settings file appeared. Around this time the vanilla material inheritance problem was recorded in the wiki.
- **1.17**: A claim that long-distance rendering of the Ender Dragon runtime_identifier was patched (**conflicting**).
- **1.18.30**: The resource pack camera file was removed (one member).
- **1.20.80-1.21.80**: Block light affected volumetric fog. Later deliberately separated.
- **1.21.60+**: An opinion that the custom stairs/slab material instance lighting bug started.
- **1.21.80**: TAAU became blurry. Lighting settings format 1.21.80.
- **1.21.90**: Vanilla VV PBR introduced, also applied to RTX (texture_set shared). Default VV settings in `resource_packs\1.21.90`. Sound attenuation by camera distance. Color grading/fog format 1.21.90.
- **1.21.12x (GDK)**: Wave `sample width` removed, static light Preview.
- **1.21.120**: VV stencil fixed "to some extent". `local_lighting.json` format 1.21.120. Custom block `"emissive": true` format 1.21.120+. render distance fog fixed. RT point lights broken.
- **~2025-10-31 GDK release**: Close-range dithering introduced, screen animation UI lag, UI settings reset.
- **2025-11-04 Preview**: Water change in the materials index (sea foam artifact removed).
- **2025-11 (build)**: Player/attachable locators broken.
- **1.21.130**: RT point lights half fixed. In the showcase, color change by texture swap.
- **2025-12-15 release**: First-person attachable partial alpha cut off at ~50%.
- **26.0.23 (Preview, late 2025-12)**: Atlas corruption where MER shows in new worlds.
- **2026-01**: Dithering extended to hand items. ~2026-01-08 Preview keyframed sky intensity. Around 2026-01-13 Preview fixed the over-16x16 item texture bug. 2026-01-14 Editor per-biome VV settings. ~2026-01-24 full block point lights. 2026-01-27 raster overlay to sRGB. Late January the mesh model Fancy smoothing problem started.
- **26.0 (2026-02-10/11)**: Entity tint/multi-texture, End sky, sun/moon, weather material gamma correction (fixed oversaturated sun/moon with non-ACES tone mappers; entity materials also changed but not in the changelog). Baby mob model change. BetterRTX/RTX PBR broken, BetterRTX restored 2026-02-14.
- **1.26.10**: The AO bug can be avoided with `ambient_occlusion` number 0 and `face_dimming` false. A texture set format 1.26.10 case.
- **26.10 stable (2026-03)**: Static light and colored block light affect volumetric fog. A report that local_lighting does not work in Preview 26.10.x either.
- **26.1x Preview**: VV Nether severe lag.
- **2026-03-11~18 Preview**: `orbital_offset_degrees` always 0 (broken).
- **26.20.x**: BetterRTX preset crash from the material format change. Waxed copper lantern ignores `light_color`. 26.20.21 sync bug mitigated.
- **~2026-04-21 Preview**: Heightmap seams and RTX atlas tracing from the atlas change. Unfixed through 2026-04-30, fixed in the 2026-05-01 Preview. Release unaffected.
- **2026-04-23/24**: Vanilla horses, fish and tropical fish appear pink without add-ons. Texture bugs reported after updating from 1.26.10.26 to 1.26.30.20.
- **2026-04-30 Preview**: fog/lighting keyframes (volumetric density/scattering/absorption). DLSS 310.5.3.
- **Spring 2026 (mentioned 2026-05-01)**: Point lights removed on Android and PS4/Xbox One. Heightmaps broke after the atlas change and Mojang will fix them.
- **2026-05-06 Preview**: RTX new heightmap storage. veka. BetterRTX UV update.
- **2026-05-12 Preview**: TAA jitter fix. An empty `materials.index.json` in the `shaders` folder.
- **2026-05-18 Preview**: Falling blocks shown in RTX.
- **2026-06 update**: Reports of non-power-of-two atlas corruption. `padding` ineffective on the terrain atlas. Changes such as `num_mip_levels` also apply to vanilla.
- **2026-06-10**: RTX code fix reapplied (shader templates need `Support for 26.30.32`).
- **2026-06-18/19**: Outline Template V3 (3.2).
- **2026-06-20**: Point lights and their shadows merged into a single "Point light quality".
- **26.30**: Atlas tile padding removed (MCPE-240144). Grid artifacts on non-power-of-two textures such as 66x66 (not present around 1.26.13).
- **2026-07**: Point light low tier removed, 16/32/64 tiers. Dynamic shadow atlas. Lava point light performance fixed in the 2026-07-10 code review. Block composite texture VV fix by 2026-07-15.
- **26.50**: Lava point light performance improved (~80 fps).
- **2026-08**: Current-gen console point lights 32. 2026-08-06 Preview `WaterSimulation` material.bin.
- **1.26.40/.50**: `item_display_transforms` bug.
- **2026-09-22 Preview**: `transitioning_ambient_scalar` added. Point lights 96 on Series S, 256 on Series X/PC.
- **26.52**: Report that custom panoramas broke.
- **26.60**: Small texture first-load blur, Preview 3D crosshair oddity. The community RenderDragon source reconstruction (RenderDragon2src) was published for 26.60.
- **1.26.60.28**: Shader platform ESSL_320 (separable sampler) added. Possibility of point lights returning on OpenGL ES 3.2 Android.
- **2026-10-20 Preview**: Point light shadows pixel aligned, real time returns (only the near group), self shadowing returns.
- **Preview 1.26.70.21**: The "atomic client entities" gist mentions LOD queries.
- **Late 2026-10 Preview**: Series X point light crash, point light shadows stopping and concentrating on the nearest light.
- **2026-10-31**: Texture variant terrain breakage reported as MCPE-244074.
- **2026-11-04**: Snowstorm 3.3 released.

- The depth-only pass problem where a translucent entity on the water surface erases entities behind it.

- How to change an attachable's color with `color`/`overlay_color`.
- The elytra and cape texture conflict.

- The RAM leak of custom trail particles (emitters suspected of not being deleted).
