This section gathers the tools used for Bedrock add-on and JSON UI development in one place. For each tool it records what it does, how to install and use it, how far it can be trusted (its limits), and its license. The tool repositories were downloaded and their license files and READMEs checked. The commits that were checked are in the source table at the bottom of each page.

## Choosing a tool

| Task | Tool | Page |
|---|---|---|
| Editing and debugging JSON and scripts | VS Code, the Blockception extension, the Mojang debugger, jsonui-lsp | [Editors, language servers and debuggers](./editors-and-lsp.mdx) |
| JSON validation | Blockception schemas, KalmeMarq schemas | [JSON schemas](./schemas.mdx) |
| Building JSON UI screens | JsonForge, EasyUIBuilder, bedrock-json-ui-editor, JsonEncryptor | [JSON UI editors and generators](./json-ui-builders.mdx) |
| Testing JSON UI without the game | JSON UI tester | [JSON UI tester](./jsonui-tester.mdx) |
| Build and deployment | Regolith, jsonte, bedrock-boost, the GDK path | [Build pipelines](./build-pipelines.mdx) |
| Models, animations, textures | Blockbench, Mcblend, Snowstorm | [Modeling and texture tools](./modeling.mdx) |
| Worlds and structures | NBT editors, Editor mode | [World, structure and NBT tools](./world-and-nbt-tools.mdx) |

## How to read

- Each tool section follows the order "what it does, installation and use, limits, license".
- The "Community notes" at the end of a page hold details gathered in the community survey (2025-10-22 to 2026-11-13). The `[uNNN date]` at the end of a line is the anonymous number and date of the conversation it is based on.
- Errors reported by an editor or a schema can be wrong. The final judgment comes from the game's content log.
