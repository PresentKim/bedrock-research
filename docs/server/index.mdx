이 섹션은 서버 쪽을 다룬다. 공식 BDS 운영과 설정, 네트워크 프로토콜(RakNet, NetherNet), 서버가 리소스팩을 내려보내는 방법, BP 없이 서버 코드로 커스텀 블록·아이템·레시피를 정의하는 방식(Dragonfly 사례), 한 플레이어에게만 보내는 카메라·HUD·가짜 블록·청크, 서버 성능이 주제다. 클라이언트에서 도는 JSON UI와 Ore UI는 다른 섹션이 다루고, 여기서는 서버가 그 UI에 데이터를 싣는 통로를 설명한다.

## 읽는 순서

BDS를 운영한다면 서버 소프트웨어, 성능, 팩 전달 순으로 읽는다. 커스텀 서버를 만든다면 프로토콜 기초부터 보고, 리소스팩 전달과 커스텀 콘텐츠로 넘어간다. 버전 체계와 팩 manifest는 기초 섹션에 있다.
