# InvUI 기반 DDUI 모방 구현

서버 폼(DDUI, CustomForm)은 스크립트가 바로 열 수 있지만 모양과 동작이 정해져 있다. 이 기획은 [엔티티 인벤토리로 메뉴 화면 만들기](../entity-inventory-ui.mdx)의 방식(보이지 않는 컨테이너 엔티티의 상자 화면을 리소스 팩으로 다시 그리는 방식)으로 만든 화면이 서버 폼을 대신할 수 있는지 본다. 모양은 [ore-ui-react](https://github.com/PresentKim/ore-ui-react)가 지원하는 Ore UI 컴포넌트를 따른다.

## 1. 출발점

서버 폼을 매끄럽게 대신하려면 적어도 토글과 슬라이더가 되어야 한다. 그래서 입력 시험 팩(IIP)으로 상자 화면에서 글 입력, 토글, 슬라이더를 받을 수 있는지 먼저 보았고, 이어서 Ore UI 컴포넌트를 옮긴 갤러리 시험 팩(IUC)으로 컴포넌트를 하나씩 만들었다. 실측은 모두 모바일 1.26.63, 2026-11-16이다.

## 2. 상자 화면의 입력과 출력

| 방향 | 통로 | 상태 |
| --- | --- | --- |
| 서버로 | 칸 버튼 누름(빠른 이동 매핑, 서버가 비워진 칸을 보고 다시 채운다) | 실측. 누르고 같은 칸에서 뗀 탭만 잡힌다 |
| 서버로 | 손을 뗄 때 눌리는 숨은 global 버튼(슬라이더 값 보내기, INP-37) | 실측 |
| 서버로 | 끌어서 나눠 놓기로 지나간 칸 읽기(INP-39) | 실측. 칸마다 한 번, 처음 지난 순서만 |
| 서버로 | 글 입력칸의 글 | 안 된다. 어떤 바인딩으로도 읽히지 않았다(IIP) |
| 화면으로 | 칸 아이템의 이름(글자), 진짜 아이템(아이콘과 개수) | 실측 |
| 화면 안 | 토글, 체크박스, 슬라이더 값, 애니메이션 | 실측. 서버를 거치지 않는다 |

그 밖의 입력(더블 탭, 한 개씩 옮기기, 버리기, 길게 누르기, 창 밖에 버리기, PC 오른쪽 클릭과 Q, 스와이프)은 갤러리의 InputLab 페이지로 시험하는 중이다 `{미검증}`.

## 3. 하위 기획

| 문서 | 내용 | 예제 애드온 |
| --- | --- | --- |
| [InvUI로 슬라이더 구현하기](./slider.mdx) | 슬라이더 값을 서버로 보내려고 시도한 방법과 결과, 실패 원인을 정리한 회고. 최종 구성은 손을 떼면 숨은 global 단계 버튼이 값을 보내는 슬라이더 | `inventory-ui-slider` |
| [InvUI로 기본 컴포넌트 구현하기](./basic-components.mdx) | 공통 틀과 그리기 규칙, 토글, 체크박스, 버튼, 탭, 아코디언, 드롭다운, 모달, 토스트 등 25개 | `inventory-ui-basic-components` |
| [InvUI로 강화 컴포넌트 구현하기](./enhanced-components.mdx) | 화면 자판 글 입력, 숫자 입력, 키 설정, 색 고르기, 차트, 아이템 격자, 상점, 조합법, 플레이어 카드와 목록, 표, 트리, 카운트다운, 잠금 패턴 등 17개 | `inventory-ui-enhanced-components` |

세 애드온은 이름표와 화면 표식이 달라 함께 켜도 된다. 바닐라 상자 화면을 가리는 수정은 다른 엔티티 인벤토리 예제와 같은 글을 쓴다.

## 4. 남은 일

- 예제 애드온 셋은 갤러리에서 옮긴 최종 구성이다. 세 애드온 모두 v1.0.0을 게임에서 돌렸고(모바일 1.26.63, 2026-11-16), 기본 컴포넌트 25개와 강화 컴포넌트 17개는 기획대로 동작했다. 결과는 각 문서의 컴포넌트 절에 있다.
- 슬라이더 위에서 정확히 손을 뗄 때 값이 가는지는 아직 모른다. 실측한 슬라이더 애드온 v1.0.0은 바닐라 드래그 매핑이었고, 영상으로는 손을 뗀 자리가 슬라이더 위인지 바로 아래인지 가릴 수 없다. 드래그 매핑을 `consume_event: false`로 바꾼 v1.0.1은 실측하지 않았다. 서버의 탭 거르기도 게임에서 따로 확인하지 않았다([슬라이더 2.10절, 2.11절](./slider.mdx)).
- InputLab의 입력 후보 실측.
- 여러 플레이어와 다른 기기(PC, 콘솔)는 시험하지 않았다.

## 관련 규칙

| 규칙 | 내용 |
| --- | --- |
| LAY-58 | 레이어 합이 같은 바탕이 글자를 가릴 수 있다 |
| INP-37 | 손을 떼면 값을 보내는 슬라이더 |
| INP-38 | `consume_event: false`가 듣는 경우와 듣지 않는 경우 |
| INP-39 | 끌어서 나눠 놓기로 지나간 칸 읽기 |
