기획 문서는 한 가지 화면이나 기법을 실제로 만들며 JSON UI 규칙을 게임에서 확인한 기록이다. 문서마다 목표, 구성, 실측 결과, 남은 일을 적고, 대부분은 바로 가져와 켜 볼 수 있는 예제 애드온을 붙인다. 규칙의 근거 수준은 [규칙 ID 전체표](../reference/rules.mdx)의 범례를 따른다.

## 예제 애드온

각 애드온은 문서 안의 내려받기 상자에서 받는다. 테스트 아이템은 크리에이티브 인벤토리에 있고, 서버 폼 예제끼리와 엔티티 인벤토리 예제끼리는 같은 월드에 함께 켜도 된다(각 문서의 안내). 동작 범위와 잰 버전은 각 문서의 실측 기록을 본다.

| 애드온 | 보여 주는 것 | 문서 |
| --- | --- | --- |
| `json-ui-performance` | 화면 라우터와 2열 grid로 그린 서버 폼 버튼 목록 | [grid 버튼 목록](./json-ui-performance/grid-button-list.mdx) |
| `collection-view-order` | `always`가 있는 목록과 없는 목록의 비교 | [always 없이 첫 화면 채우기](./json-ui-performance/collection-view-order.mdx) |
| `hud-expression-cost` | HUD 칸 식 하나를 함께 쓸 때와 칸마다 고정 식을 쓸 때의 비용 비교 | [바인딩 계산식 캐싱](./json-ui-performance/binding-expression-caching.mdx) |
| `server-form-research-screen`, `server-form-research-screen-texture` | 서버 폼 하나의 탭과 아이템 선택(숫자 아이템 ID 판, 텍스처 경로 판) | [연구 화면](./server-form-research-screen.mdx) |
| `entity-menu-lab`, `entity-research-screen`, `entity-2048`, `entity-matchmaking`, `entity-matchmaking-figures` | 엔티티 인벤토리 화면으로 만든 메뉴, 연구 화면, 2048, 매치메이킹 | [엔티티 인벤토리로 메뉴 화면 만들기](./invui/entity-inventory-ui.mdx) |
| `touch-probes`, `json-ui-claims` | 키와 터치 입력이 화면에 들어오는지 재는 창 | [사용자 입력 가로채기](./invui/input-interception.mdx) |
| `inventory-ui-slider` | 엔티티 상자 화면의 슬라이더 | [슬라이더](./invui/ddui/slider.mdx) |
| `inventory-ui-basic-components` | 엔티티 상자 화면의 기본 컴포넌트 25종 | [기본 컴포넌트](./invui/ddui/basic-components.mdx) |
| `inventory-ui-enhanced-components` | 엔티티 상자 화면의 강화 컴포넌트 17종 | [강화 컴포넌트](./invui/ddui/enhanced-components.mdx) |
| `json-ui-claims` | 미검증 JSON UI 주장을 재는 창 | [미검증 JSON UI 주장 실측](./json-ui-claims.mdx), [구조물 렌더러](./structure-renderer.mdx) |
| `item-icon-slots`, `item-aux-probe`, `item-aux-probe-extra` | 실제 인벤토리 칸으로 그린 아이템 아이콘과 숫자 아이템 ID 범위 | [아이템 숫자 ID](./item-aux-id.mdx) |
