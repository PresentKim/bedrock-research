# Ore UI·DDUI

Ore UI는 Mojang이 JSON UI를 대체하려고 새로 만든 게임 UI다. HTML·JS·CSS로 쓰이고 Coherent Labs의 Gameface 엔진이 그린다. 이 섹션은 Ore UI를 리소스팩과 서버로 어디까지 바꿀 수 있는지를, 실제 클라이언트에서 확인한 결과와 바이너리에서 읽은 내용으로 정리한다.

## 한 줄 결론

26.63까지는 서버가 리소스팩을 콘텐츠 키로 암호화해 보내면(또는 팩에 빈 `content.zipe`를 두면), 그 팩으로 Ore UI의 HTML·JS·CSS를 통째로 바꿀 수 있었다. 26.64에서 Mojang이 보안 문제로 리소스팩의 Ore UI 접근을 막아 지금은 이 길이 닫혔다(출처: 비공개 조사). 평문 팩으로 닿는 길은 버튼 스타일 다리, `pack://` 텍스처, DDUI 레이아웃(지금은 막힘)뿐이다. 길마다 지금 상태는 아래 표에 있다.

## 지금 되는 것

각 페이지가 적은 내용만 옮겼다. "다시 시험하지 않음"은 페이지가 그렇게 적은 것이고, "기록 없음"은 26.64 이후 판에서 시험한 기록이 이 위키에 없다는 뜻이다.

## 표기

- `{실측}` 게임에서 확인했다.
- `{코드}` 바이너리나 JS 번들에서 읽었다.
- `{설치본}` 설치 폴더에서 읽었다.
- `{추론}` 위 근거로 판단했다.
- `{문서}` 외부 문서에서 가져왔다.
- 근거가 없는 것은 "확인 안 됨"으로 적는다.
