# Ore UI·DDUI

Ore UI는 Mojang이 JSON UI를 대체하려고 새로 만든 게임 UI다. HTML·JS·CSS로 쓰이고 Coherent Labs의 Gameface 엔진이 그린다. 이 섹션은 Ore UI를 리소스팩과 서버로 어디까지 바꿀 수 있는지를, 실제 클라이언트에서 확인한 결과와 바이너리에서 읽은 내용으로 정리한다.

## 한 줄 결론

서버가 리소스팩을 콘텐츠 키로 암호화해 보내면(또는 로컬 팩 폴더에 빈 `content.zipe`를 두면), 그 팩으로 Ore UI의 HTML·JS·CSS를 통째로 바꿀 수 있다. 평문 팩으로 닿는 길은 버튼 스타일 다리, `pack://` 텍스처, DDUI 레이아웃(지금은 막힘)뿐이다.

## 표기

- `{실측}` 게임에서 확인했다.
- `{코드}` 바이너리나 JS 번들에서 읽었다.
- `{설치본}` 설치 폴더에서 읽었다.
- `{추론}` 위 근거로 판단했다.
- `{문서}` 외부 문서에서 가져왔다.
- 근거가 없는 것은 "확인 안 됨"으로 적는다.
