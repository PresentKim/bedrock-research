# 마인크래프트 UI 스타일 지침 (서버 주도 DDUI)

서버가 그리는 DDUI 화면([DDUI 가이드](./ddui-server-guide.mdx))의 모양 규칙이다. 목표는 **서버가 이미 쓰는 JSON UI 서버 폼(`server_form.json`을 고친 팩)을 거의 그대로 옮기는 것**이다. 그래서 JSON UI 화면과 Ore UI 화면이 한 게임 안에서 구별되지 않는다. 디자인 시스템은 `oui-mc.css`, 렌더러는 `oui-ddui.js`다. 아래에서 "폼 팩"은 그 JSON UI 폼을 꾸미는 서버 리소스팩이다. (출처: repo-ore-ui-loading)

## 1. 원칙

1. **JSON UI와 같은 텍스처, 같은 크기를 쓴다.** 창, 버튼, 탭, 칸은 바닐라와 폼 팩의 nine-slice 텍스처를 `border-image`로 그린다. 색을 CSS로 흉내 내지 않는다.
2. **크기는 GUI 픽셀로 쓴다.** 폼 팩 JSON UI 파일의 숫자를 그대로 옮긴다.
3. **반응형은 GUI 배율이 맡는다.** 창은 JSON UI 폼과 같은 고정 크기다. 화면 크기에 따라 게임의 GUI 배율이 바뀌면 `rem`이 따라 바뀌어 JSON UI처럼 통째로 커지고 작아진다. 배치를 다시 짜지 않는다.
4. **아이템이 주인공이다.** 아이템은 칸에 넣고, 이름과 설명은 툴팁으로 보인다.
5. **값만 바꾼다.** 화면 구조는 이동할 때만 보낸다. 그 안의 변화는 영역(`region`)과 값으로 보낸다.

## 2. 단위

개념: JSON UI는 GUI 픽셀로 크기를 정한다. Ore UI는 `html` 글자 크기를 **5 × GUI 배율 px**로 둔다(실측). 그래서 1 GUI 픽셀(`u`)은 **`0.2rem`**이다.

```css
/* 18u 칸 = 3.6rem */
.mc-slot { width: 3.6rem; height: 3.6rem; }
```

- CSS에는 계산한 `rem` 값을 바로 쓴다(18u는 `3.6rem`).
- 서버(Go)는 `u(n)`으로 크기를 보낸다(`fmt.Sprintf("%.1frem", n*0.2)`).
- Gameface는 여러 값을 받는 단축 속성(`padding: a b` 등) 안의 `calc()`와 `inset` 그림자를 무시했다(실측). 여백은 한 방향씩 쓴다.
- 그림은 `pack://경로.png?filtering=point`로 흐리지 않게 그린다. 신뢰되지 않은 팩의 텍스처도 이 경로로 읽힌다.

## 3. 텍스처

| 부품 | 텍스처 | nine-slice |
| --- | --- | --- |
| 창 | 바닐라 `textures/ui/dialog_background_opaque` | 4 |
| 도구 막대 | 바닐라 `textures/ui/toolbar_background` | 4 |
| 닫기 | 바닐라 `textures/ui/close_button_default_light` (JSON UI `common.light_close_button`이 쓰는 것) | 없음 |
| 탭 | 바닐라 `TabTopBack`, `TabTopBackHover`, `TabTopFront` | 4 |
| 버튼 | 폼 팩의 버튼 텍스처(보통, 호버, 누름) | 3 |
| 아이콘 버튼 호버/누름 | 폼 팩의 평면 호버·누름 텍스처 | 없음 |
| 패널 | 폼 팩의 패널 텍스처 | 없음 |
| 칸 | 바닐라 `cell_image` (10×10을 2px씩 자른다) | 2 |
| 고른 칸 | 폼 팩의 고른 칸 텍스처 | 없음 |
| 화살표 | 바닐라 `arrow_large`, 넘기기는 폼 팩의 왼쪽·오른쪽 화살표 | 없음 |

- 고른 칸 텍스처가 가운데가 불투명하면 JSON UI처럼 **아이콘 아래**에 깐다. 위에 두면 아이콘이 가려졌다(실측).
- 바닐라 `close_button_default`는 `pack://`로 읽히지 않았다. `_light`는 읽혔다(실측).
- 아이템 아이콘은 모두 엔진이 그리는 `aux:AuxId`다. 바닐라와 커스텀 아이템·블록이 같다([아이콘](./geo-item-and-containers.mdx)). `geo:`·`tex:`는 서버에 없는 아이템의 대체다.
- 칸 장식 등급처럼 JSON UI가 툴팁 앞 표식으로 고르던 것은 같은 표식을 읽어 고른다([인벤토리형 메뉴](../server-ui/inventory-menus.mdx)).

## 4. 글

| 쓰임 | 크기 | 색 |
| --- | --- | --- |
| 창 제목 | 1.4rem, 위에서 6u, 가운데 | `#404040` |
| 본문(창 위) | 1.4rem | `#333333` |
| 작은 글(상세, 카드·버튼 이름; JSON UI의 0.8배) | 1.12rem | 창 위 `#333333`, 버튼 위 `#f2f2f7` |
| 머리글(JSON UI의 0.7배) | 0.98rem | `#4d4d4d` |
| 칸 개수(0.75배) | 오른쪽 아래 | 흰 글 |

글꼴은 Ore UI 기본(Minecraft Seven, 한글은 Noto Sans KR)을 그대로 쓴다.

### `§` 색 코드

서버 문구의 `§` 색은 보통 **어두운 바탕 기준**이다(채팅과 툴팁이 어둡다). 렌더러는 창 위에 바로 그리는 글(`ink: "panel"`, 창 안의 기본값)을 아래 표처럼 바꾼다. JSON UI 폼에서 밝은 창 위 글을 바꾸던 규칙과 같게 둔다.

| 원래 | 창 위 | 원래 | 창 위 |
| --- | --- | --- | --- |
| `§f` | `§0` | `§a` | `§2` |
| `§7` | `§8` | `§b` | `§3` |
| `§8` | `§7` | `§c` | `§4` |
| `§e` | `§1` | `§d` | `§5` |
| `§6` | `§4` | | |

버튼 위 글, 칸 개수, 툴팁은 어두운 바탕이라 바꾸지 않는다(`ink: "dark"`). 영역(`region`)은 만들어질 때의 바탕을 기억해 다시 그려도 같은 규칙을 쓴다. `§k`는 그리지 않는다.

| --- | --- | --- |
| 화면 | `mc-screen` | 창을 가운데 둔다 |

## 6. 반응형

- 모든 크기가 `rem`이라 GUI 배율을 따라간다. 게임은 창 크기에 맞춰 GUI 배율을 고르므로 작은 화면에서는 JSON UI처럼 창 전체가 작아진다.
- 창 크기는 바꾸지 않는다. 내용이 넘치면 `mc-content` 안쪽이 스크롤되고 스크롤 막대가 보인다. Gameface는 스크롤 막대를 그리지 않으므로 렌더러가 그린다.
- 내용에 맞춰 창 크기가 바뀌면 Gameface가 클릭을 바뀌기 전 자리로 판정해 엉뚱한 칸이 눌렸다(실측: 검색 결과가 481개에서 1개로 줄며 창이 줄어든 뒤 결과 칸을 누르자 전에 그 자리에 있던 다른 아이템이 열림). 고정 크기는 이것도 막는다.
- 렌더러는 화면 너비를 재서 `body`에 `mc-w-s`/`mc-w-m`/`mc-w-l`을 붙인다(Gameface는 `@media`를 쓰지 않는다). GUI 배율로 모자라는 화면이 생기면 이것으로 배치를 바꾼다.

## 7. Gameface에서 지킬 것

- `min-width: 0`이 듣지 않는다. 늘어나는(`flex-grow`) 칸에 긴 글을 넣으면 칸이 창 밖까지 넓어졌다(실측). 글이 들어가는 칸은 너비를 고정한다.
- 한 줄(`mc-row`)에 버튼 여럿을 두면 버튼이 좁아져 글이 한 글자씩 세로로 꺾였다(실측). 글이 긴 버튼은 한 줄에 하나만 둔다.
- 음수 `z-index`는 배경 전용 자식에만 준다. 도구 막대 전체에 `z-index: -1`을 주자 그림은 보였지만 안의 버튼이 하나도 눌리지 않았다(실측). 배경을 `mc-toolbar-bg`, `mc-tab-bg`로 따로 두면 버튼이 눌린다.
- 버튼 글은 `span`에 넣는다. 묶인 글이 바뀌어도 아이콘이 지워지지 않는다.
- 클릭은 `mousedown`으로 받는다(`div`에 `click`이 오지 않는다).

## 8. 동작 규칙

- 칸은 링크가 있을 때만 눌린다. 도구 막대의 뒤로 버튼은 온 곳으로 돌아간다(브라우저 기록처럼 최대 32단계). 기록이 없으면 뒤로 버튼을 그리지 않는다.
- 탭과 카드 이동은 기록을 새로 시작한다.
- 화면 제목은 "상위 · 하위"다.
- Esc는 닫기와 같다.
- 성공·실패는 알림 줄에 짧게 쓰고 화면은 그대로 둔다.

## 9. 금지

- CSS로 색, 그라데이션, 둥근 모서리를 만들어 텍스처를 흉내 내지 않는다.
- JSON UI 폼에 없는 크기를 쓰지 않는다.
- 같은 정보를 칸과 글로 두 번 쓰지 않는다(카드 이름은 예외).
