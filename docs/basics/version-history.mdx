모든 주제(스크립트, 블록, 엔티티, 그래픽, UI, 월드젠, 팩)의 versions 노트에서 모은 릴리스/프리뷰 사실이다. 날짜는 보고 시점이며, 정확한 릴리스일은 Editor 릴리스 매핑과 npm 게시일을 기준으로 맞췄다. 일부 출처의 버전 번호는 추정치다. 버전 체계와 날짜표는 [versions.mdx](versions.mdx)에 있다. (출처: 비공개 조사)

## 2025-10 이전(배경 사실)

- **1.16.100**: 표지판 블록이 다른 블록으로 바뀌는 버그가 1.16.110 프리뷰에서 고쳐졌지만 수정 전 빌드가 릴리스로 나갔다(역사적 예).
- **1.17**: 런타임 식별자를 이용한 엔더 드래곤식 원거리 렌더링이 패치되었다는 주장(논쟁 중).
- **1.18.30**: 리소스팩의 카메라 파일 편집 제거. Deferred Lighting Shader(mcpedl)는 RenderDragon 때문에 1.18.30까지만 동작.
- **1.19.50**: 새 `execute` 문법. manifest `min_engine_version` >= [1,19,50] 필요.
- **1.20.50**: NBT 편집으로 구조물 블록 크기를 늘리는 방법 패치. 아이템 태그는 아이템 format >= 1.20.50.
- **1.20.80**: 스크립트 동적 import 지원, `query.armor_damage_slot` 추가, 아이템 `category` 형식 변경.
- **1.21**: 지그소 `max_depth` 7 → 20(시련의 방).
- **1.21.20**: Holiday Creator Features 제거로 옛 애드온이 깨졌다는 언급이 있다(아래 1.21.90 ~ 1.21.100 서술과 *(상충)*).
- **1.21.44**: mobGriefing off 시 아이템 줍기 변경 보고.
- **1.21.50.26 (프리뷰)**: 지그소 구조물 첫 공개.
- **1.21.80**: TAAU가 1.21.70 이하보다 훨씬 흐려짐.
- **1.21.90**: Script API 2.0.0에 대응(일부는 2.0.0 안정판을 ~1.21.100으로 기억, *conflicting*), `Player.isOp` 제거·권한 레벨 API 추가, `faceLocation` 의미 변경(월드 원점 모서리 기준), 블록 커스텀 컴포넌트 v2와 `destruction_particles`(블록 format 1.21.90), 2.0에서 `worldInitialize` → `system.beforeEvents.startup`, `runCommandAsync`·`ItemUseOn`·`world.events`·`player.velocity` 제거, 최상위 모듈 코드는 읽기 전용(`system.run` 사용), `applyKnockback`이 `({x,z}, vertical)`로 변경.
- **1.21.90 ~ 1.21.100**: Holiday Creator Features 제거로 옛 블록 JSON(events, `minecraft:on_placed`, 레거시 컴포넌트) 파손. 1.21.100 무렵 지그소 JSON 마지막 레이아웃 변경(projection이 element 안으로), 일시정지 화면 플레이어 목록이 Ore UI로 이동.
- **1.21.110**: 가중 텍스처 variations(블록), material instance 텍스처 variation, 바이옴 behavior format 1.21.110, 프리뷰에서 manifest v3 pack settings 등장.
- **1.21.114**: 일부 사용자의 스토어 버전(1.21.114.1), `@minecraft/server` 2.2.0 안정판, 커스텀 바이옴이 토글 없이 안정적으로 생성(`replace_biomes` 필요). 서버용 마지막 UWP 안정판은 1.21.94, .114 UWP.

## 2025-10 ~ 2025-12: 1.21.120, 1.21.130 (Mounts of Mayhem)

- **프리뷰 1.21.130.20~24 (2025-10-22~)**: 실험 `minecraft:connection_rule`, connection trait, `minecraft:has_fence_connections` 태그(커스텀 울타리/계단), 다중 충돌 상자(최대 16개), 커스텀 계단/`minecraft:support`(Upcoming Creator Features 토글), 블록 파괴 이벤트의 `blockDestructionSource`, 엔티티 바운딩 박스 메서드, `Dimension.getGeneratedStructures`. 1.21.130-beta.22에 `@minecraft/server-graphics`(스크립트로 VV 제어). 프리뷰에 강제 업데이트 대화상자.
- **프리뷰 1.21.120.24 (2025-10-24)**: `minecraft:redstone_producer`에서 Upcoming Creator Features 요구 제거. 좌클릭 감지(`playerSwingStart`의 `swingSource` "Attack")는 프리뷰/베타 전용.
- **1.21.120 릴리스 (2025-10-28/29)**: Windows가 GDK로 전환(경로 변경, 성능은 사람마다 엇갈림, 접근성 페이드/디더링 추가, UI 설정 초기화, 입력 지연 불만). manifest 의존성 `"beta"`가 최신 호환 베타로 자동 해석. `@minecraft/server` 2.3.0 안정판(2025-10-29), `getAABB()`(별도 보고에서는 `Entity.getAABB`가 2.4.0부터). `query.is_pack_setting_enabled` 실험 해제, `World.getPackSettings`(베타). 커스텀 컴포넌트 V1(`minecraft:custom_components`) deprecated. 카메라 `attach_to_entity`/`detach_from_entity`(fixed_boom, follow_orbit 프리셋, https://feedback.minecraft.net/hc/en-us/articles/40566672351885-Minecraft-1-21-120-Bedrock). 컬러 포인트 라이트가 `local_lighting` 폴더(format 1.21.120)로 이동. 블록 `emissive` material instance 파라미터와 `alpha_masked_tint`. 1.21.120 format의 새 아이템 컴포넌트는 리테일 이후 동작. JSON UI `$is_big_screen`(새 일시정지 화면), 일부 문자열 곱셈 트릭 제거, start_screen.json 편집 미적용 보고. 지그소가 실험 해제되고 정식 구조물 배치 시스템으로(1.21.12x). RTX 포인트 라이트 파손, 동물 엔티티의 `scale` 컴포넌트가 제거되어 닭 등을 덮어쓴 팩의 머리가 커짐. 스텐실 외곽선은 VV에서 부분 동작. Linux/mac mcpelauncher가 최신 릴리스를 실행하지 못함. Editor v1.1.5. GDK 세부: `.msixvc` 패키지, 첫 실행 5 ~ 20분 검은 창, 마우스 미고정, Game Bar 녹화 고장, 메모리 누수, 메뉴 CPU 30%, 더블클릭 임포트 팝업 사라짐, 근접 반투명 디더링 접근성 설정, 제목/액션바 검은 배경, UI 배율 변경(MCPE-33349), MCPE-230623, 내화 아이템 소실 버그 수정, Bedrock Launcher 미지원(자세한 내용은 [versions.mdx](versions.mdx)).
- **1.21.121 / 1.21.122 (2025-11)**: 1.21.122가 마우스 버그 MCPE-230832를 고쳤다(재현 보고는 남음). 실행 중 임포트 불가(MCPE-227874), exe 아이콘 누락, alt-tab 글리치, 오래된 블록 format 애드온이 든 Realm에 Android 접속 실패. 당시 최신 format은 1.21.120.

- **1.21.130 릴리스 (2025-12-09, Mounts of Mayhem 드롭)**: 스피어, `kinetic_weapon`/`piercing_weapon`, `swing_duration`, `minecraft:is_spear` 태그, 마법부여 슬롯 `melee_spear`. client player.entity.json에 새 변수/애니메이션이 추가되어 옛 사본이 깨짐(`v.melee_spear_equipped` unknown variable). 플레이어 모델 변경으로 외곽선 템플릿 파손. 새 일시정지 메뉴로 `/scoreboard objectives setdisplay list` 표시 사라짐, 스크립트 `runCommand`의 옛 execute 문법 중단. Android 구조물 내보내기 제거. 다중 충돌 상자(format 1.21.130). 참고 페이지 https://learn.microsoft.com/en-us/minecraft/creator/documents/update1.21.130 . ## 2026-01 ~ 2026-02: 1.21.131/132, 26.0

- **1.21.131 / 1.21.132**: player.entity.json 파손 보고(1.21.131), 1.21.132가 2026-02-07 안정판이었고 Hive 서버 텍스처가 깨짐. 2026-01-31 베타 2.5.0-beta.1.21.132-stable.
