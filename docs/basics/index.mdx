이 섹션은 Bedrock 애드온을 만들 때 어느 분야에서나 먼저 부딪히는 기초를 모은다. 팩이 어디에 놓이고, `manifest.json`을 어떻게 쓰며, 파일마다 `format_version`이 왜 다르고, 서버가 팩을 어떻게 내려보내며, 게임 버전이 해마다 어떻게 바뀌었는지를 다룬다. "팩이 로드되지 않는다"는 문제의 대부분은 manifest(`format_version` 2/3, `min_engine_version`, 모듈 버전)와 캐시에서 나온다. 그래서 이 섹션은 그 원인을 한곳에 모았다.

기준 시점은 2026-10 말이다. 게임은 26.50 안정판(2026-09-15)과 26.60·26.70 프리뷰까지 반영했다. 근거는 커뮤니티의 2025-10-22 ~ 2026-10-23 기록(출처: 비공개 조사), Bedrock Wiki(출처: bedrock-wiki), Microsoft Learn(출처: ms-learn)이다.

## 검증 수준 표기

본문 규칙 옆의 `{바닐라}`, `{코드}`, `{작동팩}`, `{실측}` 같은 표기는 근거의 종류다. 커뮤니티 기록에서 온 항목에는 *(확인됨)*, *(단일 보고)*, *(상충)*을 붙였다. *(상충)*은 보고끼리 어긋난다는 뜻이고, 이럴 때는 최신 보고를 우선했다.
