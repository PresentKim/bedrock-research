## 26.x 버전 체계

2025-12-05 프리뷰부터 게임 버전 번호가 연도 기반으로 바뀌었다. 1.26.0이던 버전이 "26.0"으로 불린다(공식 발표: minecraft.net의 new-version-numbering-system 기사). 그러나 **내부 표기와 manifest는 여전히 `1.XX.X` 체계**다. 게임 "26.30"은 manifest에서 `[1, 26, 30]`(format 3에서는 `"1.26.30"`)이다. (출처: 비공개 조사)

|---|---|---|---|
| 1.21.120 | 2025-10-28/29 | | Windows GDK 전환 |
| 1.21.130 | 2025-12-09 | Mounts of Mayhem | 스피어 |
| 1.21.132 | 2026-02-07 (안정판) | | |
| 26.0 (= 1.26.0) | 2026-02 (약 02-10) | | 프리뷰 2026-02-03 |

| 26.20 | 2026-05-05 | | |

| 26.30 | 2026-06-16 | Chaos Cube | |
| 26.40 | 2026-08-04 | | 엔티티 format 1.26.40은 게임 26.44 |

- 프리뷰 라인은 안정판보다 한 단계 앞선다. 26.20 안정판일 때 프리뷰는 26.30, 26.30 안정판일 때 26.40 식이다. 2026-10 말 기준 프리뷰는 26.70까지 나왔다.
- 개별 릴리스일은 보고 시점이며, 정확한 날짜는 Editor 릴리스 매핑과 npm 게시일을 기준으로 맞췄다. 일부 출처의 버전 번호는 추정치다.
- 1.21.114(스토어 1.21.114.1, `@minecraft/server` 2.2.0 안정판)가 26.x 이전 마지막 큰 기준점이다. 서버용 마지막 UWP 안정판은 1.21.94, .114 UWP다.

## Windows GDK 전환 (1.21.120)

1.21.120(2025-10-28)에서 Windows 빌드가 UWP에서 GDK로 바뀌어 `com.mojang` 경로가 달라졌다. 성능 반응은 사람마다 엇갈렸고, 접근성 페이드/디더링이 추가됐으며 UI 설정이 초기화됐고 입력 지연 불만이 있었다. Linux/mac용 mcpelauncher는 최신 릴리스를 한동안 실행하지 못했다. (출처: 비공개 조사)

| 용도 | 경로 |
|---|---|
| 팩(공유) | `%AppData%\Minecraft Bedrock\Users\Shared\games\com.mojang` |
| 월드·설정 | `%AppData%\Minecraft Bedrock\Users\<랜덤숫자>\games\com.mojang` |
| 게임 내부 데이터(바닐라) | `C:\XboxGames\Minecraft for Windows\Content\data` |
| 로그 | `%AppData%\Minecraft Bedrock\logs\` (Settings의 Creator 탭에서 켠 경우) |
| Preview 팩 | `%AppData%\Minecraft Bedrock Preview\users\shared\games\com.mojang` |
| Preview 로그 | `%AppData%\Minecraft Bedrock Preview\logs\` |

공유 `com.mojang` 안에 `development_behavior_packs`, `development_resource_packs`, `development_skin_packs`, `behavior_packs`, `resource_packs`가 있다. Microsoft 계정에 로그인하지 않았다면 팩은 `C:\XboxGames\Minecraft for Windows\Content`에 저장된다. 공식 안내는 MS Learn의 GDK Migration 문서다(출처: ms-learn, `Documents/GDKPCProjectFolder.md`).

**마이그레이션 함정**: 팩이 Shared가 아니라 사용자별(랜덤 ID) 폴더로 옮겨진 경우가 있었다. 팩을 Shared `com.mojang`으로 옮기면 해결된다. 1.21.120 이후 업데이트 뒤 일부 사용자에게서 팩이 사라지거나 숨겨진 사례도 같은 방법으로 해결됐다. (출처: 비공개 조사)

- `@minecraft/server-ui` 안정판은 2.0.0이 오래 유지되다 2026-06-21에 2.1.0, 26.50/51에서 2.2.0이 됐다.
- `server-net`, `server-admin`, `server-gametest`, `debug-utilities`(`1.0.0-beta.1.26.3-stable`이 2026-03-08 처음), `diagnostics`는 베타 전용이다.
- 기타 모듈: `@minecraft/common` 1.2.0 → 1.3.0(2026-06-28), `@minecraft/math` 2.2.11 → 2.4.0(전 채널 동일), `@minecraft/vanilla-data` 1.21.120 → 1.26.2 → 1.26.10 → 1.26.32 → 1.26.40(2026-08-16), `@minecraft/server-editor` 0.1.0-beta(2026-07-11 처음), `@minecraft/server-editor-bindings` 0.1.0-beta.
- 베타/프리뷰 문자열은 게임 버전을 품는다: `-beta.<게임버전>-stable` 또는 `-preview.<번호>`. 설치는 `npm i @minecraft/server@<버전>`이다.
- 변경 로그: learn.microsoft.com의 scriptapi/minecraft/server/changelog.

## 릴리스 주기

프리뷰 → 릴리스의 베타 API → 안정 순으로 간다. 프리뷰 마감은 보통 금요일이다. Editor는 26.40부터 Bedrock 버전에 맞춰 번호를 붙이며, 주요 기능은 2릴리스마다 나온다(변경 로그: github.com/Mojang/minecraft-editor의 discussions 268 ~ 352). (출처: 비공개 조사)

- **Editor 버전**: 1.21.120은 v1.1.5, 1.21.130은 v1.2.0, 26.10은 v1.3.0, 26.20 이후는 게임 번호와 같다.
- **피드백 경로**: 프리뷰 변경 로그는 feedback.minecraft.net, 버그는 report.bugs.mojang.com(로그인 필요), 읽기는 mojira.dev 미러다. 2026-09에 옛 문서 서비스가 종료된 뒤 문서 피드백은 `Mojang/bedrock-samples`, `MicrosoftDocs/minecraft-creator` 저장소 또는 커뮤니티 피드백 스레드로 보낸다. Minecraft Feedback 서버에는 Script API 채널이 2026-08-30에 복구됐다.
