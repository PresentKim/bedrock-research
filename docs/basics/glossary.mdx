| 용어 | 뜻 |
|---|---|
| BP (behavior pack, 행동팩) | 서버 쪽 정의와 스크립트를 담는 팩. 모듈 type `data`, `script` |
| RP (resource pack, 리소스팩) | 텍스처, 모델, 사운드, UI 등 클라이언트 자산. 모듈 type `resources` |
| 애드온 (add-on) | BP와 RP의 묶음. `.mcaddon`은 mcpack, mcworld, mctemplate, mceditoraddon을 담는 압축 파일 |
| `.mcpack` | manifest가 루트에 있는 zip 형식 팩 |
| `com.mojang` | 게임이 팩, 월드, 설정을 두는 데이터 폴더. Windows 공유 경로는 `%AppData%\Minecraft Bedrock\Users\Shared\games\com.mojang` |
| `development_*_packs` | 개발 중 팩을 두는 폴더. 월드 사본이 아니라 여기서 작업한다 |
| manifest | 팩 루트의 `manifest.json`. header, modules, dependencies 등 |
| header UUID | 팩의 정체성. BP와 RP는 서로 달라야 하고 업데이트에서도 바꾸지 않는다 |
| module | manifest `modules` 항목. type이 팩 종류를 정한다 |
| `format_version` (manifest) | manifest 문법 버전. 2는 배열 버전, 3은 문자열 버전과 pack settings |
| `format_version` (파일) | 파일 종류 하위 시스템의 문법 버전. 게임 버전이 아니다 |
| `min_engine_version` | 팩이 지원하는 최소 게임 버전. 낮으면 옛 명령어 파서 등 레거시 동작이 켜진다 |
| 26.x 체계 | 2025-12부터 쓰는 연도 기반 게임 버전. 내부와 manifest는 `1.26.x` |
| 프리뷰 (Preview) | 안정판보다 한 라인 앞선 시험 빌드 |
| Beta APIs | 베타 모듈과 기능을 켜는 실험 토글 |
| 서브팩 (subpack) | `subpacks/` 폴더의 변형. 메모리 티어로 기본이 정해진다 |
| `memory_tier` / `memory_performance_tier` | 서브팩 선택 기준. 0.25 GB 단위 / 플랫폼 1~5 |
| pack settings | manifest v3의 `settings`. RP는 Molang, BP는 `world.getPackSettings`로 읽는다 |
| capability | manifest `capabilities`. `pbr`, `raytraced`, `script_eval` 등 |
| Vibrant Visuals (VV) | 물리 기반 렌더링 그래픽 모드. RP에 `pbr` capability가 있어야 유지된다 |
| system packs | BDS 26.30부터 `system_behavior_packs`, `system_resource_packs` 폴더. 모든 월드에 자동 적용 |
| `cdn_config.json` | BDS가 RP를 CDN에서 받게 하는 비공식 설정 파일 |
| BDS | Bedrock Dedicated Server |
| Content Log | Settings > Creator에서 켜는 콘텐츠 오류 로그 |
| `/reload` | 개발 팩의 스크립트와 함수를 다시 읽는다. `/reload all`은 루트 테이블 등도 읽는다 |
| brarchive | 공식 문서 없는 아카이브 컨테이너. JSON 계열 폴더만 묶고 보호 수단이 아니다 |
| brpak | 게임 파일 배포에 쓰는 비압축, 엄격 검증 zip 변형 |
| MCB | 26.50.x부터 brarchive 안 데이터 파일에 쓰이는 스키마 의존 인코딩 |
| `pack_optimization_version` | brarchive 적용 팩의 header 필드. manifest format 3일 때만 적용 |
| `contents.json` | 암호화 팩의 파일 목록과 키를 담은 헤더 파일 |
| `content.zipe` | 팩 폴더에 두면 엔진이 암호화 접근 전략으로 열어 신뢰 팩으로 취급하는 빈 파일 |
| 신뢰된 팩 (trusted pack) | Ore UI 파일 조회가 허용하는 팩. 암호화 팩 접근 전략은 언제나 신뢰된다 |
| `.lang` | 번역 키와 값의 텍스트 파일. `texts/`에 둔다 |
| jsoncpp | 게임 JSON 파서 계열. 주석은 되고 뒤따르는 쉼표는 오류 |
| Molang | 애니메이션·렌더·파티클 등에서 쓰는 식 언어 |
| `.mcfunction` | 한 줄에 명령 하나인 함수 파일. LF 줄바꿈, 앞에 `/` 없음 |
| `tick.json` | 매 틱 실행할 함수를 나열하는 파일. 0,0,0에서 실행된다 |
| `.mcstructure` | 구조물 파일. 형식 버전 2는 26.50.24에서 도입 |
| Marketplace | 공식 상점. 바닐라 파일 포함 금지, 안정 API만 허용 |
| GDK | 1.21.120부터 Windows 빌드의 기반. `com.mojang` 경로가 바뀌었다 |
