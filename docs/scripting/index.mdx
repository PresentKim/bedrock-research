# Script API

이 섹션은 `@minecraft/server`를 중심으로 한 Script API를 다룬다. 실행 모델과 모듈 버전부터 이벤트, 엔티티·월드 API, 커스텀 커맨드, 저장, 서버 전용 모듈, 디버깅, 알려진 제한까지 2025-10 ~ 2026-10 커뮤니티 조사와 공식 문서를 근거로 정리했다.

## 읽는 순서

처음이면 개요와 모듈 버전 페이지를 먼저 읽고, 만들려는 기능에 맞는 API 페이지(이벤트, 엔티티, 월드, 커맨드, 저장)로 간다. 막히면 마지막 페이지의 제한별 우회법 표에서 증상을 찾는다.
