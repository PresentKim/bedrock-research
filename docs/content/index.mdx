# 애드온 콘텐츠

이 섹션은 비헤이비어 팩(BP)이 정의하는 게임 콘텐츠를 다룬다. JSON UI와 렌더링은 다른 섹션에 있고, 여기서는 "무엇을 정의하는가"와 "어디까지 되는가"에 집중한다. 모든 페이지는 개념 설명, 동작하는 예제, 규칙과 커뮤니티 보고 순서로 쓰며 검증 수준을 `(confirmed)`, `(conflicting)`, `(single report)`, `(unverified)`로 표시한다.

공통 전제는 다음과 같다.

- 기능은 해당 파일의 `format_version`이 연다. 최신 값(2026-08 기준 엔티티 1.26.40~1.26.50)으로 올리고 Content Log를 켜서 확인한다.
- 옛 이벤트 시스템(Holiday Creator Features의 아이템/블록 이벤트)은 사라졌다. 아이템과 블록은 스크립트 커스텀 컴포넌트(`"ns:comp": {}` + `registerCustomComponent`)를 쓰고 엔티티는 컴포넌트 그룹 + 이벤트를 쓴다.
- 바닐라 콘텐츠의 대부분은 하드코딩이다. 바닐라 JSON을 같은 식별자로 덮어써 고칠 수 있는 범위는 좁다.
- 근거 자료는 커뮤니티 조사(2025-10~2026-10), Bedrock Wiki(0930b39), MS Learn(a9fd1c0), bedrock-samples(15701fa9)다.
