# 엔티티 AI 목표 레퍼런스 (1/41)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 AI 목표(behavior) 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;behavior.admire_item

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_admire_item.md`)

몹이 감상 대상으로 설정된 아이템을 감상하게 한다.

Enables the mob to admire items that have been configured as admirable.

> [!Note]
> In format version 1.26.20, `sound_interval` must be specified as a Float Range object (an object with `range_min` / `range_max`). Legacy scalar or array forms no longer parse.

> [!Note]
> Requires the following component in order to work properly:
> 
> * Admire Item (minecraft:admire_item)
>

## minecraft&#58;behavior.aquatic_charge_attack

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_aquatic_charge_attack.md`)

수중 몹이 대상에게 넉백을 주며 돌진하게 한다. 오버슈트와 쿨다운 설정이 있다.
