# 엔티티 컴포넌트 레퍼런스 (13/23)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 컴포넌트 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;player.saturation

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_player.saturation.md`)

플레이어의 포화도(식량 요구)를 정의한다.

Defines the player's need for food.

### Player Saturation Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| max | *not set* | Integer number | 플레이어 포화도의 최대값. | Player: `20` |
| value | *not set* | Integer number | 플레이어 포화도의 초기값. | Player: `5` |

### 예시

##### [Player](https://github.com/Mojang/bedrock-samples/tree/preview/behavior_pack/entities/player.json)


```json
"minecraft:player.saturation": {
  "max": 20,
  "value": 5
}
```
