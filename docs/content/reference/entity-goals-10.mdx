# 엔티티 AI 목표 레퍼런스 (10/41)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 AI 목표(behavior) 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;behavior.defend_village_target

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_defend_village_target.md`)

마을에 머물며 공격자로부터 마을을 지키게 한다. 평판이 나쁜 플레이어는 필터와 상관없이 공격한다.

Allows the entity to stay in a village and defend the village from aggressors. If a player is in bad standing with the village this goal will cause the entity to attack the player regardless of filter conditions.

> [!Note]
> This behavior is typically used with the minecraft:dweller component which defines the entity's role in a village. See iron_golem.json for a complete example.

> [!Note]
> In 1.26.0 the schema is stricter and rejects invalid JSON for this behavior.

### 예시

##### [Iron Golem](https://github.com/Mojang/bedrock-samples/tree/preview/behavior_pack/entities/iron_golem.json)


```json
"minecraft:behavior.defend_village_target": {
  "must_reach": true,
  "entity_types": [
    {
      "filters": {
        "AND": [
          {
            "OR": [
              {
                "test": "is_family",
                "subject": 1,
                "operator": 0,
                "value": "mob"
              },
              {
                "test": "is_family",
                "subject": 1,
                "operator": 0,
                "value": "player"
              }
            ]
          }
        ]
      }
    }
  ],
  "priority": 1
}
```
