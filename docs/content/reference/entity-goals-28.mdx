# 엔티티 AI 목표 레퍼런스 (28/41)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 AI 목표(behavior) 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;behavior.pet_sleep_with_owner

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_pet_sleep_with_owner.md`)

반려 몹이 잠자는 주인과 함께 침대 위로 올라가게 한다. 길들여 주인이 있어야 한다.

Allows the pet mob to move onto a bed with its owner while sleeping.

> [!Note]
> Requires a player to be set as the tame owner via taming (or the `tame` command, or the tame API on EntityTameableComponent) in order to work properly.

### Pet Sleep With Owner Behavior Properties

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| goal_radius | 0.5 | Decimal number | 몹이 목표에 도달했다고 보는 블록 거리. AI가 특정 지점에 닿으려 앞뒤로 흔들리는 것을 막는 '여유'다. |
| priority | *not set* | Integer number | 0에 가까울수록 우선순위가 높아진다. 우선순위가 높을수록 이 행동(목표)이 더 먼저 실행된다. |
| search_height | 1 | Integer number | 반려 동물이 주인과 함께 자려면 주인으로부터 있을 수 있는 높이(블록). |
| search_range | 0 | Integer number | 반려 동물이 주인과 함께 자려면 주인으로부터 있을 수 있는 거리(블록). |
| speed_multiplier | 1 | Decimal number | 이 AI 목표를 쓸 때의 몹 이동 속도 배율. |
