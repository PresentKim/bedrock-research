## minecraft&#58;is_stackable

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_is_stackable.md`)

같은 엔티티끼리 수직·수평으로 충돌할 수 있게 한다. 양쪽 모두 `collision_box`가 필요하다.

Allows instances of this entity to have vertical and horizontal collisions with each other. For a collision to occur, both instances must have a "minecraft:collision_box" component.
Stackable behavior is closely related to collidable behavior. While the "minecraft:is_stackable" component describes how an entity interacts with others of its own kind, the "minecraft:is_collidable" component governs how other mobs interact with the component's owner.

## minecraft&#58;jump.dynamic

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_jump.dynamic.md`)

### Entity Dynamic Jump Properties

| 이름 | 기본값 | 유형 | 설명 |

## minecraft&#58;knockback_resistance

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_knockback_resistance.md`)

근접 공격의 넉백에 대한 저항을 정한다. 0.0은 저항 없음, 1.0은 완전 면역이다.

Determines an entity's resistance to knockback from melee attacks. A value of 0.0 means no resistance, while 1.0 provides full immunity to knockback (like iron golems).

> [!Note]
> In format version 1.26.20, `value` now accepts negative numbers down to a minimum of `-2`. Negative values amplify knockback applied to the entity instead of diminishing it.

### Alternate Simple Representations

## minecraft&#58;leashable

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_leashable.md`)

이 몹을 다른 대상에 끈으로 묶는 방식을 설명한다.

Describes how this mob can be leashed to other items.

> [!Note]
> In 1.21.90, the `can_be_cut` root field and the `spring_type` and `rotation_adjustment` fields within `presets` were added.

> [!Note]
> From 1.21.80 onward, supports multiple presets via the `presets` array. Each preset has its own `filter`, `hard_distance`, `soft_distance`, and `max_distance` — replacing the flat root fields previously used.

### Leashable Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| can_be_cut | true | Boolean true/false | true이면 플레이어가 엔티티에 가위를 사용해 들어오는 끈과 나가는 끈을 모두 끊을 수 있다. 형식 버전 1.21.90 이상이 필요하다. |  |
| can_be_stolen | false | Boolean true/false | true이면 이미 다른 엔티티에 묶여 있어도 플레이어가 이 엔티티를 묶을 수 있다. |  |
| hard_distance | 6 | Integer number | 끈이 팽팽해져 움직임을 제한하는 블록 거리. |  |
| max_distance | 0 | Integer number | 끈이 끊어지는 블록 거리. |  |
| on_leash | *not set* | Object | 이 엔티티가 묶였을 때 호출할 이벤트. event와 target 속성을 가진 객체 또는 단순한 이벤트 문자열을 쓸 수 있다. |  |
| on_leash (as String) | *not set* | String |  |  |
| on_unleash | *not set* | Object | 이 엔티티의 끈이 풀렸을 때 호출할 이벤트. event와 target 속성을 가진 객체 또는 단순한 이벤트 문자열을 쓸 수 있다. |  |
| on_unleash (as String) | *not set* | String |  |  |
| on_unleash_interact_only | false | Boolean true/false | true이면 플레이어가 직접 상호작용한 경우가 아닌 이유로 엔티티의 끈이 풀릴 때 "on_unleash"가 발생하지 않는다. |  |
| presets | *not set* | Array of Presets items | 다른 엔티티에 묶였을 때 이 엔티티의 동작을 정의한다. "filter" 조건을 만족하는 첫 프리셋이 적용되며, 맞는 것이 없으면 기본 설정이 쓰인다. | Boat: `[{"filter":{"subject":"other","test":"is_family","value":"happy_ghast"},"rotation_adjustment":90,"spring_type":"quad_dampened"},{"hard_distance":4,"rotation_adjustment":90,"soft_distance":2}]` |
| soft_distance | 4 | Integer number | 이 엔티티를 묶은 엔티티 가까이 두려는 '스프링' 효과가 작동하기 시작하는 블록 거리. |  |
| unleash_on_removal | true | Boolean true/false | true이면 이 컴포넌트가 제거될 때 엔티티의 끈이 풀린다. 기본값은 true다. 형식 버전 1.26.30 이상이 필요하다. |  |

#### Presets
Defines how this entity behaves when leashed to another entity. The first preset which "filter" conditions are met will be applied; if none match, a default configuration is used instead.


##### Presets Properties

**JSON path:** `presets`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| filter | *not set* | Minecraft filter | 이 프리셋이 적용되기 위해 충족해야 하는 조건. |
| hard_distance | 7 | Decimal number | 엔티티가 스프링 같은 힘으로 끈 주인 쪽으로 당겨지기 시작하는 거리(블록). |
| max_distance | 12 | Decimal number | 끈이 끊어지는 블록 거리. |
| rotation_adjustment | 0 | Decimal number | "spring_type"이 "dampened"나 "quad_dampened"일 때 엔티티가 평형에 이르는 회전을 조정한다. |
| soft_distance | 4 | Decimal number | 엔티티가 가능하면 끈 주인 쪽으로 경로 탐색을 시작하는 거리(블록). |
| spring_type | dampened | String | 엔티티를 끈 주인 쪽으로 당기는 스프링 같은 힘의 종류를 정의한다. "bouncy"는 매우 탄성이 큰 스프링을 흉내 내며, 묶인 엔티티가 공중에 떠 있으면 평형에 이르지 않는다. |

##### hard_distance

Distance (in blocks) over which the entity starts being pulled towards the leash holder with a spring-like force. Entities can enter and stay in vehicles if the leash is stretched under this distance, but will dismount once it exceeds it.

##### spring_type

Defines the type of spring-like force that pulls the entity towards its leash holder: - "bouncy": Simulates a highly elastic spring that never reaches an equilibrium if the leashed entity is suspended mid-air. - "dampened": Simulates a dampened spring attached to the front of the leashed entity's collision. It reaches an equilibrium if the entity is suspended mid-air and aligns with the movement direction. - "quad_dampened": Simulates four dampened springs connected to the center of each side of the entities' collisions. It reaches an equilibrium if the entity is suspended mid-air and gradually aligns with the leash holder over time.


### 예시

##### [Allay](https://github.com/Mojang/bedrock-samples/tree/preview/behavior_pack/entities/allay.json)


```json
"minecraft:leashable": {}
```

##### [Boat](https://github.com/Mojang/bedrock-samples/tree/preview/behavior_pack/entities/boat.json)


```json
"minecraft:leashable": {
  "presets": [
    {
      "filter": {
        "subject": "other",
        "test": "is_family",
        "value": "happy_ghast"
      },
      "rotation_adjustment": 90,
      "spring_type": "quad_dampened"
    },
    {
      "hard_distance": 4,
      "rotation_adjustment": 90,
      "soft_distance": 2
    }
  ]
}
```

##### [Chicken](https://github.com/Mojang/bedrock-samples/tree/preview/behavior_pack/entities/chicken.json)


```json
"minecraft:leashable": {
  "unleash_on_removal": false
}
```

## minecraft&#58;leashable_to

#### field_of_view

Defines, in degrees, the width of the field of view for entities looking at the owner entity. If "scale_fov_by_distance" is set to true, this value corresponds to the field of view at a distance of one block between the entities.

#### scale_fov_by_distance

When true, the field of view narrows as the distance between the owner entity and the entity looking at it increases. This ensures that the width of the view cone remains somewhat constant towards the owner entity position, regardless of distance.
