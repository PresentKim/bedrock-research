# 엔티티 AI 목표 레퍼런스 (38/41)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 AI 목표(behavior) 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;behavior.teleport_to_owner

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_teleport_to_owner.md`)

주인에게 순간이동하게 한다. 형식 버전 1.21.20 이상이 필요하다.

Allows an entity to teleport to its owner.

> [!Note]
> This item requires a format version of at least 1.21.20.

### Entity Teleport To Owner Behavior Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| control_flags | [] | Control Flags choices |  |  |
| cooldown | 1 | Decimal number | 엔티티가 다시 순간이동을 시도할 수 있기까지 지나야 하는 시간(초). |  |
