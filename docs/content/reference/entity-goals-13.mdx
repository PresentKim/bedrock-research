## minecraft&#58;behavior.drink_potion

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_drink_potion.md`)

지정한 환경 조건에서 포션을 마시게 한다.

Allows the mob to drink potions based on specified environment conditions.
