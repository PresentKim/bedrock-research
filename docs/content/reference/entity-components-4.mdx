# 엔티티 컴포넌트 레퍼런스 (4/23)

## minecraft&#58;breathable

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_breathable.md`)

엔티티가 숨 쉴 수 있는 블록을 정하고 질식하게 만든다.

Defines what blocks this entity can breathe in and gives them the ability to suffocate.

### Breathable Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| breathe_blocks | *not set* | Array of strings | 위에서 고른 항목 외에 이 엔티티가 숨 쉴 수 있는 블록 목록. |  |
| breathes_air | true | Boolean true/false | 설정하면 이 엔티티가 공기 중에서 숨 쉴 수 있다. |  |
| breathes_lava | true | Boolean true/false | 설정하면 이 엔티티가 용암 속에서 숨 쉴 수 있다. |  |
| breathes_solids | false | Boolean true/false | 설정하면 이 엔티티가 고체 블록 속에서 숨 쉴 수 있다. |  |
| breathes_water | false | Boolean true/false | 설정하면 이 엔티티가 물속에서 숨 쉴 수 있다. | Bogged: `true` |
| can_dehydrate | false | Boolean true/false | true이면 물에서만 숨 쉬는 엔티티(예: 물고기)가 물 밖에서 탈수 피해를 입는다. 형식 버전 1.21.130 이상이 필요하다. |  |
| generates_bubbles | true | Boolean true/false | 설정하면 이 엔티티가 물속에서 기포가 보인다. |  |
| inhale_time | 0 | Decimal number | 숨을 최대치까지 회복하는 데 걸리는 시간(초). |  |
| non_breathe_blocks | *not set* | Array of strings | 위에서 고른 항목 외에 이 엔티티가 숨 쉴 수 없는 블록 목록. |  |
| suffocate_time | -20 | Integer number | 질식 피해 사이의 시간(초). |  |
| suffocateTime | *not set* | Decimal number |  |  |
| total_supply | 15 | Integer number | 엔티티가 숨을 참을 수 있는 시간(초). | Bat: `15` |
| totalSupply | *not set* | Decimal number |  | Allay: `15` |

## minecraft&#58;breedable

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_breedable.md`)

엔티티가 번식용 사랑 상태에 들어가는 방법을 정한다. 보통 `behavior.breed`와 함께 쓴다.

Allows an entity to establish a way to get into the love state used for breeding.

> [!Note]
> This component is commonly used in conjunction with the 'minecraft:behavior.breed' component.

> [!Note]
> In 1.21.130 the `transform_to_item` field on each entry of `breed_items` was renamed to `result_item`. The new field is defined per-item, so different breed items can transform into different result items on use.

> [!Note]
> In 1.26.0 the offspring-related fields were split out into the separate `minecraft:offspring_data` component. `minecraft:breedable` now contains only love-state, taming/health requirements, and pregnancy-flow data; the new `minecraft:offspring_data` component is required to actually spawn the child entity.

### Breedable Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| allow_sitting | false | Boolean true/false | true이면 엔티티가 앉아 있는 동안에도 번식할 수 있다. |  |
| blend_attributes | true | Boolean true/false | true이면 번식 후 새끼가 부모의 속성을 섞어 갖는다. 예를 들어 말은 체력, 이동 속도, jump_strength가 섞인다. |  |
| breed_cooldown | 60 | Decimal number | 엔티티가 다시 번식할 수 있기까지의 시간(초). |  |

| deny_parents_variant | *not set* | Deny Parents Variant item | 같은 변종인 부모의 새끼가 그 변종을 거부하고 주어진 범위에서 무작위 변종을 택할 확률을 정한다. |  |
| environment_requirements | *not set* | Array of Environment Requirements items | 엔티티를 '사랑' 상태로 만들기 위해 근처에 필요한 블록 조건 목록. |  |
| extra_baby_chance | 0 | Percent Range | 새끼가 최대 16마리까지 스폰될 확률. |  |
| inherit_tamed | *not set* | Boolean true/false | true이면 부모가 길들여져 있을 때 새끼도 자동으로 길들여진다. |  |
| love_filters | *not set* | Minecraft filter | 사랑에 빠지려 할 때 실행할 필터. |  |
| mutation_factor | *not set* | Mutation Factor item | 새끼가 부모의 변이 하나를 물려받지 않을 가능성을 정한다. |  |
| require_full_health | false | Boolean true/false | true이면 번식하기 전에 엔티티의 체력이 가득 차 있어야 한다. |  |
| require_tame | true | Boolean true/false | true이면 번식하기 전에 엔티티가 먼저 길들여져 있어야 한다. | Llama: `true` |

#### combine_parent_colors

If true and no color mutation occurs, the baby's `minecraft:color` is set to a blend of the parents' colors (following DyeItem combination rules). If the parents' colors aren't compatible, the baby inherits one parent's color at random. This item requires a format version of at least 1.21.60.

## minecraft&#58;buoyant

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_buoyant.md`)

엔티티가 지정한 액체 블록 위에 뜨게 한다.

Enables an entity to float on the specified liquid blocks.

> [!Note]
> In 1.26.10 the `simulate_waves` boolean was replaced with the `movement_type` string field (`waves` / `bobbing` / `none`). `big_wave_probability` and `big_wave_speed` only apply when `movement_type` is `waves`.

### Entity Buoyant Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| apply_gravity | true | Boolean true/false | 매 틱 중력을 적용한다. "movement_type"의 영향이 커지지만 액체 밖에서도 중력이 더 세게 적용된다. |  |
| base_buoyancy | 1 | Decimal number | 엔티티가 얼마나 뜰지 계산하는 데 쓰는 기본 부력. |  |
| big_wave_probability | 0.029999999329447746 | Decimal number | 엔티티에 큰 파도가 칠 확률. "movement_type"이 "waves"일 때만 쓴다. |  |
| big_wave_speed | 10 | Decimal number | 큰 파도를 만들 때 속도에 곱하는 배수. "big_wave_probability"에 따라 발생한다. |  |
| can_auto_step_from_liquid | false | Boolean true/false | 액체 블록에 밀착해 밀릴 때 인접한 고체 블록 위로 올라설 수 있는지 여부. 형식 버전 1.26.10 이상이 필요하다. |  |
| drag_down_on_buoyancy_removed | 0 | Decimal number | 컴포넌트가 제거될 때 엔티티가 아래로 끌려 내려가는 정도. |  |
| liquid_blocks (Liquid Blocks) | [] | Array of Liquid Blocks items | 이 엔티티가 뜰 수 있는 블록 목록. 액체 블록이어야 한다. | Xp Orb: `["minecraft:flowing_water","minecraft:water"]` |
| liquid_blocks (as String) | *not set* | String |  |  |
| liquid_blocks (as Object) | *not set* | Object |  |  |
| movement_type | waves | Movement Type choices | 엔티티에 적용되는 수직 이동의 종류. |  |

#### movement_type

Type of vertical movement applied to the entity. `waves` simulates wave movement based on the entity's speed (default). `bobbing` moves the entity up and down at a constant pace. `none` disables wave movement. Replaces the previous `simulate_waves` boolean. This item requires a format version of at least 1.26.10.

## minecraft&#58;burns_in_daylight

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_burns_in_daylight.md`)

직사광선을 받으면 불 피해를 입게 한다. 좀비, 스켈레톤, 팬텀 같은 언데드가 쓴다.

Specifies that this entity takes fire damage when exposed to direct sunlight. This component is used by undead mobs like zombies, skeletons, and phantoms. The entity will catch fire when in sunlight unless it is wearing armor in the protection slot, standing in water, or in a shaded area.

#### protection_slot

The equipment slot that provides protection from burning in sunlight. If armor is equipped in this slot, the entity will not burn. Commonly set to 'slot.armor.head' for helmets or 'slot.armor.body' for horse armor. This item requires a format version of at least 1.21.130.

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_cannot_be_attacked.md`)

When set, blocks entities from attacking the owner entity unless they have the "minecraft:ignore_cannot_be_attacked" component.

> [!Note]
> This item requires a format version of at least 1.21.50.
