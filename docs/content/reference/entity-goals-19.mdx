# 엔티티 AI 목표 레퍼런스 (19/41)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 AI 목표(behavior) 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;behavior.go_home

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_go_home.md`)

스폰된 위치로 되돌아가게 한다.

Allows the mob to move back to the position they were spawned.

#### Entity ActorDefinitionTrigger
Triggers an entity event when specified conditions are met. Events activate component groups that change entity behavior—transforming villagers into zombie villagers, switching mobs to aggressive mode, or triggering growth stages. Combine with filters to create conditional state machines that respond to gameplay.

## minecraft&#58;behavior.harvest_farm_block

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_harvest_farm_block.md`)

위에 공기가 있는 농지를 찾아 인벤토리의 씨앗을 심게 한다.

Allows the entity to search within an area for farmland with air above it. If found, the entity will replace the air block by planting a seed item from its inventory on the farmland block. This goal will not execute if the entity does not have an item in its inventory.

> [!Note]
> Requires the following components in order to work properly:
> 
> * Inventory (minecraft:inventory)
> * Navigation (minecraft:navigation)
>

#### search_count

The number of randomly selected blocks each tick that the mob will check within its search range and height for a valid block to move to. A value of 0 will have the mob check every block within range in one tick.
