# 엔티티 컴포넌트 레퍼런스 (19/23)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 컴포넌트 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;tamemount

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_tamemount.md`)

엔티티가 물속 또는 지상에서 무리를 지어 움직이게 한다(원문 설명 그대로).

Allows entities to flock in groups in water or not.

#### Entity ActorDefinitionTrigger
Triggers an entity event when specified conditions are met. Events activate component groups that change entity behavior—transforming villagers into zombie villagers, switching mobs to aggressive mode, or triggering growth stages. Combine with filters to create conditional state machines that respond to gameplay.

## minecraft&#58;target_nearby_sensor

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_target_nearby_sensor.md`)

엔티티가 다른 엔티티를 보거나 감지해 대상으로 삼을 수 있는 범위를 정의한다.

Defines the entity's range within which it can see or sense other entities to target them.

### Target Nearby Sensor Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| inside_range | 1 | Decimal number | 다른 엔티티를 'inside' 범위에 있다고 보는 최대 블록 거리. | Blaze: `2`, Drowned: `3` |
| must_see | false | Boolean true/false | 'inside' 이벤트가 발생하려면 다른 엔티티가 보여야 하는지 여부. | Blaze: `true` |
| on_inside_range | *not set* | Object | 엔티티가 inside 범위에 들어왔을 때 호출할 이벤트. event와 target 속성을 가진 객체 또는 단순한 이벤트 문자열을 쓸 수 있다. | Blaze: `{"event":"switch_to_melee","target":"self"}`, Drowned: `{"event":"minecraft:switch_to_melee","target":"self"}` |
| on_inside_range (as String) | *not set* | String |  |  |
| on_outside_range | *not set* | Object | 엔티티가 outside 범위 밖으로 나갔을 때 호출할 이벤트. event와 target 속성을 가진 객체 또는 단순한 이벤트 문자열을 쓸 수 있다. | Blaze: `{"event":"switch_to_ranged","target":"self"}`, Drowned: `{"event":"minecraft:switch_to_ranged","target":"self"}` |
| on_outside_range (as String) | *not set* | String |  |  |
| on_vision_lost_inside_range | *not set* | Minecraft Event Trigger | 엔티티가 시야 범위를 벗어났을 때 호출할 이벤트. 'event'로 이벤트 이름을, 'target'으로 이벤트 대상을 지정할 수 있다. |  |
| outside_range | 5 | Decimal number | 다른 엔티티를 'outside' 범위에 있다고 보는 최대 블록 거리. | Blaze: `3`, Drowned: `5` |

### 예시

##### [Blaze](https://github.com/Mojang/bedrock-samples/tree/preview/behavior_pack/entities/blaze.json)


```json
"minecraft:target_nearby_sensor": {
  "on_inside_range": {
    "event": "switch_to_melee",
    "target": "self"
  },
  "inside_range": 2,
  "must_see": true,
  "outside_range": 3,
  "on_outside_range": {
    "event": "switch_to_ranged",
    "target": "self"
  }
}
```
