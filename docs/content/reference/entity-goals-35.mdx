## minecraft&#58;behavior.stroll_towards_village

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_stroll_towards_village.md`)

탐색 범위 안에서 마을의 무작위 위치로 이동하게 한다.

Allows the mob to move into a random location within a village within the search range.
