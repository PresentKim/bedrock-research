## minecraft&#58;combat_regeneration

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_combat_regeneration.md`)

이 엔티티의 공격 대상을 죽인 몹에게 재생 I을 주고 채굴 피로를 없앤다.

Gives `Regeneration I` and removes `Mining Fatigue` from the mob that kills the entity's attack target.

### Combat Regeneration Properties

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |

| apply_to_self | false | Boolean true/false | 몹이 대상을 죽였을 때 자신에게 전투 버프를 줄지 정한다. |

## minecraft&#58;conditional_bandwidth_optimization

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_conditional_bandwidth_optimization.md`)

엔티티의 조건부 공간 갱신 대역폭 최적화를 정의한다.

Defines the Conditional Spatial Update Bandwidth Optimizations of this entity.

### Conditional Bandwidth Optimization Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| conditional_values | *not set* | Array of Conditional Values items | 조건부 대역폭 최적화 값을 담은 객체. |  |
| default_values | *not set* | Default Values item | 기본 대역폭 최적화 값을 담은 객체. | Arrow: `{"max_dropped_ticks":7,"max_optimized_distance":80,"use_motion_prediction_hints":true}` |

#### Conditional Values
The object containing the conditional bandwidth optimization values.


##### Conditional Values Properties

**JSON path:** `conditional_values`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| conditional_values | *not set* | Minecraft filter | 이 최적화 값이 쓰이기 위해 충족해야 하는 조건. |
| max_dropped_ticks | 10 | Integer number | 최적화 값과 관련해, 공간 갱신 패킷을 보내지 않을 수 있는 최대 틱 수. 값은 0 이상이어야 한다. |
| max_optimized_distance | 80 | Decimal number | 대역폭 최적화에서 고려하는 최대 거리. |
| use_motion_prediction_hints | false | Boolean true/false | true이면 패킷 생략 간격 동안 더 작은 이동 패킷을 보낸다. 최적화 없이 보낼 때와 패킷 수는 같지만 데이터는 훨씬 적다. |

##### max_optimized_distance

The maximum distance considered during bandwidth optimizations. Any value below the max is interpolated to find optimization, and any value greater than or equal to this max results in max optimization.

##### use_motion_prediction_hints

When set to true, smaller motion packets will be sent during drop packet intervals, resulting in the same amount of packets being sent as without optimizations but with much less data being sent. This should be used when actors are travelling very quickly or teleporting to prevent visual oddities.


#### Default Values

##### Default Values Properties

**JSON path:** `default_values`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| max_dropped_ticks | 10 | Integer number | 공간 갱신 패킷을 보내지 않을 수 있는 최대 틱 수. |
| max_optimized_distance | 80 | Decimal number | 대역폭 최적화에서 고려하는 최대 거리. |
| use_motion_prediction_hints | false | Boolean true/false | true이면 패킷 생략 간격 동안 더 작은 이동 패킷을 보낸다. |

### Entity Dash Action Properties

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| can_dash_underwater | false | Boolean true/false | 엔티티가 물속에서 돌진할 수 있는지 여부. |
| cooldown_time | 1 | Decimal number | 돌진 쿨다운(초). |
| direction | entity | Direction choices | 운동량을 'entity'와 'passenger' 중 어느 쪽 방향으로 적용할지 정한다. |
| horizontal_momentum | 1 | Decimal number | 돌진의 수평 운동량. |
| vertical_momentum | 1 | Decimal number | 돌진의 수직 운동량. |

#### direction

Should the momentum be applied in the direction of the 'entity' or 'passenger'. When 'entity' is used the momentum is applied horizontally according to the direction the entity is looking, using only the entity's yaw. When 'passenger' is used the momentum will be applied in the direction the controlling passenger is looking, using the passenger's pitch and yaw.


#### Direction choices

| 값 | 제목 | 설명 |
| --- | --- | --- |
| entity | Entity |  |
| passenger | Passenger |  |

## minecraft&#58;entity_armor_equipment_slot_mapping

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_entity_armor_equipment_slot_mapping.md`)

`equippable`의 두 번째 슬롯에 장착한 아이템이 어느 방어구 슬롯에 해당하는지 정의한다.

It defines to which armor slot an item equipped to 'minecraft:equippable''s second slot should be equipped to. It is automatically applied to all entities for worlds with a version greater than or equal to 1.21.10. For older worlds, 'slot.armor.torso' will be used. It is strongly advised not to explicitly use this component, as no backwards compatibility for it will be provided.

### Entity Armor Equipment Slot Mapping Properties

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| armor_slot | *not set* | String | 'minecraft:equippable'의 두 번째 슬롯에 장착한 아이템이 들어가야 하는 방어구 슬롯. |

#### armor_slot

The armor slot an item equipped to 'minecraft:equippable''s second slot should be equipped to. It defaults to 'slot.armor.torso' for entities with a format version prior to 1.21.10, and to 'slot.armor.body' otherwise.
