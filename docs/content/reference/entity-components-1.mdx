# 엔티티 컴포넌트 레퍼런스 (1/23)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 컴포넌트 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;addrider

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_addrider.md`)

엔티티에 탑승자를 추가한다. 1.21.130부터 `riders` 배열을 받는다.

Adds a rider to the entity.

> [!Note]
> From 1.21.130, this component accepts an array of riders via the `riders` field (each with mandatory `entity_type` and optional `spawn_event`). The legacy single `entity_type` / `spawn_event` form remains supported for backward compatibility.

> [!Note]
> This item requires a format version of at least 1.8.0.

> [!Note]
> Requires the following component in order to work properly:
> 
> * Rideable (minecraft:rideable)
> 

### Add Rider Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| entity_type | *not set* | String from a list of choices | 탑승자로 맞이할 엔티티 종류. |  |
| riders | [] | Array of Riders items | 엔티티에 추가할 탑승자 목록. "minecraft:rideable"의 "seat_count"만큼만 스폰할 수 있다. | Cave Spider: `[{"entity_type":"minecraft:bogged"}]`, `[{"entity_type":"minecraft:wither_skeleton"}]` |
| spawn_event | *not set* | Minecraft Event Reference | 탑승자가 생겼을 때 발생시킬 이벤트. |  |

#### Entity Rider Data
List of riders to be added to the entity. Must have no more riders than "minecraft:rideable" has "seat_count".


##### Entity Rider Data Properties

**JSON path:** `riders`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| entity_type | *not set* | String | 이 엔티티를 탈 엔티티 종류. |
| spawn_event |  | String | 탑승 엔티티가 만들어질 때 쓸 스폰 이벤트. |

## minecraft&#58;ageable

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_ageable.md`)

엔티티가 자라는 타이머를 추가한다. feed_items에 적은 아이템을 주면 앞당길 수 있다.

Adds a timer for the entity to grow up. It can be accelerated by giving the entity the items it likes as defined by feed_items.

> [!Note]
> In 1.21.130 the `transform_to_item` field on each entry of `feed_items` was renamed to `result_item`. The new field is defined per-item, so different feed items can transform into different result items on use.

#### pause_growth

Event triggered when a baby entity's growth is paused (via a `pause_growth_items` feed). Can be an object with `event` and `target` properties, or a simple event string. This item requires a format version of at least 1.26.10.

#### reset_growth

Event triggered when a baby entity's growth is reset (via a `reset_growth_items` feed). Can be an object with `event` and `target` properties, or a simple event string. This item requires a format version of at least 1.26.10.

##### Ageable Feed Item Properties

| item | *not set* | String | 아이템 식별자. |

## minecraft&#58;ambient_sound_interval

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_ambient_sound_interval.md`)

엔티티가 환경음을 내는 간격을 정한다.

Delay for an entity playing its sound.

### Ambient Sound Interval Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| event_name | ambient | String | 환경음으로 재생할 레벨 사운드 이벤트. | Allay: `"ambient"` |
| event_names | *not set* | Array of Event Names items | 조건에 따라 고르는 동적 레벨 사운드 이벤트 목록. 순서대로 평가하며 먼저 맞는 것이 쓰인다. 모두 거짓이면 'event_name'이 우선한다. | Allay: `[{"condition":"query.is_using_item","event_name":"ambient.tame"},{"condition":"!query.is_using_item","event_name":"ambient"}]`, Breeze: `[{"condition":"!query.is_on_ground","event_name":"ambient.in.air"}]` |
| range | 16 | Decimal number | 환경음 지연 시간에 무작위로 더하는 최대 시간(초). |  |
| value | 8 | Decimal number | 엔티티가 환경음을 다시 내기 전까지의 최소 시간(초). |  |

#### Event Names
List of dynamic level sound events, with conditions for choosing between them. Evaluated in order, first one wins. If none evaluate to true, 'event_name' will take precedence.


##### Event Names Properties

**JSON path:** `event_names`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| condition | *not set* | String | 해당 환경음이 선택되기 위해 만족해야 하는 조건. |
| event_name | *not set* | String | 환경음으로 재생할 레벨 사운드 이벤트. |
