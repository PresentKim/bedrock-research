# 엔티티 AI 목표 레퍼런스 (22/41)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 AI 목표(behavior) 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;behavior.leap_at_target

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_leap_at_target.md`)

몬스터가 대상에게 뛰어올라 공격하게 한다. 적대적인 몹만 쓸 수 있고 대상이 필요하다.

Allows monsters to jump at and attack their target. Can only be used by hostile mobs.

> [!Note]
> Requires a target in order to work properly. Entities can generate targets via one of the following behaviors:
> 
> * Nearest Attackable Target Behavior (minecraft:behavior.nearest_attackable_target)
> * Hurt By Target Behavior (minecraft:behavior.hurt_by_target)

| priority | 0 | Integer number | 0에 가까울수록 우선순위가 높아진다. 우선순위가 높을수록 이 행동(목표)이 더 먼저 실행된다. | Cave Spider: `4` |

## minecraft&#58;behavior.look_at_entity
