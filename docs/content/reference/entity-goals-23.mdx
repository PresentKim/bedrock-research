# 엔티티 AI 목표 레퍼런스 (23/41)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 AI 목표(behavior) 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;behavior.melee_attack

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_melee_attack.md`)

근접 공격으로 피해를 주게 한다. 대상이 필요하다.

Allows an entity to deal damage through a melee attack.

> [!Note]
> In 1.26.0 the schema is stricter and rejects invalid JSON for this behavior.

> [!Note]
> Requires a target in order to work properly. Entities can generate targets via one of the following behaviors:
> 
> * Nearest Attackable Target Behavior (minecraft:behavior.nearest_attackable_target)
> * Hurt By Target Behavior (minecraft:behavior.hurt_by_target)
> [!Note]
> Requires the following component in order to work properly:
> 
> * Attack (minecraft:attack)
>

## minecraft&#58;behavior.move_around_target

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_move_around_target.md`)

대상 주위를 움직이게 한다. 너무 가까우면 멀어지고 너무 멀면 다가간다.

Allows an entity to move around a target.If the entity is too close(i.e.closer than destination range min and height difference limit) it will try to move away from its target.If the entity is too far away from its target it will try to move closer to a random position within the destination range.A randomized amount of those positions will be behind the target, and the spread can be tweaked with 'destination_pos_spread_degrees'.

> [!Note]
> In format version 1.26.20, `destination_position_range` must be specified as a Float Range object (an object with `range_min` / `range_max`). Legacy scalar or array forms no longer parse.

> [!Note]
> This item requires a format version of at least 1.21.30.

#### destination_pos_spread_degrees

This angle (in degrees) is used for controlling the spread when picking a destination position behind the target. A zero spread angle means the destination position will be straight behind the target with no variance. A 90 degree spread angle means the destination position can be up to 45 degrees to the left and to the right of the position straight behind the target's view direction.

#### height_difference_limit

Distance in height (in blocks) between the owner entity and the target has to be less than this value when owner checks if it is too close and should move away from the target. This value needs to be bigger than zero for the move away logic to trigger.

```json
  "destination_pos_spread_degrees": 360,
  "destination_position_range": {
    "min": 4,
    "max": 8
  },
  "priority": 3,
  "filters": {
    "all_of": [
      {
        "test": "on_ground",
        "value": true
      },
      {
        "operator": "<=",
        "test": "target_distance",
        "subject": "self",
        "value": 24
      }
    ]
  },
  "height_difference_limit": 0,
  "movement_speed": 1.2
}
```
