# 엔티티 AI 목표 레퍼런스 (4/41)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 AI 목표(behavior) 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;behavior.barter

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_barter.md`)

몹이 물물교환 화폐로 설정된 아이템으로 거래하게 한다. `barter` 컴포넌트와 함께 쓴다.

Enables the mob to barter for items that have been configured as barter currency. Must be used in combination with the barter component.

> [!Note]
> Requires the `minecraft:barter` component and `barter_table` loot table in order to work properly.

> [!Note]
> Requires the following component in order to work properly:
> 
> * Barter (minecraft:barter)
>

## minecraft&#58;behavior.breed

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_breed.md`)

몹이 다른 몹과 번식하게 한다. `breedable` 컴포넌트가 필요하다.

Allows this mob to breed with other mobs.

> [!Note]
> Requires the following component in order to work properly:
> 
> * Breedable (minecraft:breedable)
> 

### Entity Breed Behavior Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| control_flags | [] | Control Flags choices |  |  |
| priority | 0 | Integer number | 0에 가까울수록 우선순위가 높아진다. 우선순위가 높을수록 이 행동(목표)이 더 먼저 실행된다. | Chicken: `3`, Frog: `4` |
| speed_multiplier | 1 | Decimal number | 이 AI 목표를 쓸 때 몹에 적용되는 이동 속도 배율. | Chicken: `1`, Goat: `0.6` |
