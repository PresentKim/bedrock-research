# 엔티티 컴포넌트 레퍼런스 (18/23)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 컴포넌트 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;shooter

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_shooter.md`)

엔티티의 원거리 공격 동작을 정의한다. `behavior.ranged_attack`이 쏠 투사체를 이 컴포넌트에서 정한다.

Defines the entity's ranged attack behavior. The "minecraft:behavior.ranged_attack" goal uses this component to determine which projectiles to shoot.

> [!Note]
> Ammunition used by minecraft:shooter must have the minecraft:projectile component in order to function properly.

> [!Note]
> Expanded in 1.19.60: the `projectiles` list can now specify multiple projectile definitions with condition filters, and `power`, `magic`, and `sound` are exposed for per-shooter customization.

### Shooter Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| aux_val | -1 | Integer number | 기본 투사체가 적중 시 적용할 포션 효과의 ID. | Bogged: `26` |
| def | *not set* | String | 원거리 공격의 기본 투사체로 쓸 액터 정의. 투사체로 쏘려면 액터 정의에 projectile 컴포넌트가 있어야 한다. | Blaze: `"minecraft:small_fireball"`, Bogged: `"minecraft:arrow"`, Drowned: `"minecraft:thrown_trident"` |
| magic | false | Boolean true/false | 설정하면 투사체가 마법으로 표시되고, 원거리 공격 목표가 다른 마법 목표(예: drink_potion)와 동시에 실행되지 않는다. |  |
| power | 0 | Decimal number | 투사체가 발사되는 속도. 위력이 0이면 기본 투사체 투척 위력으로 대체된다. 형식 버전 1.19.60 이상이 필요하다. |  |
| projectiles | *not set* | Array of objects | 발사자가 쓸 수 있는 투사체 목록. |  |
| sound | *not set* | String | 발사자가 투사체를 쏠 때 재생되는 소리. | Bogged: `"bow"`, Drowned: `"item.trident.throw"` |

#### magic

If set, the projectiles are flagged as magic and the ranged attack goal will not run at the same time as other magic goals (for example, drink_potion). This item requires a format version of at least 1.19.60.

#### projectiles

List of projectiles that can be used by the shooter. Each entry can specify its own projectile definition and condition filters; entries are evaluated in order and the first match is used. This item requires a format version of at least 1.19.60.

## minecraft&#58;spawn_on_death

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_spawn_on_death.md`)

엔티티가 죽을 때 엔티티를 스폰하는 컴포넌트다. 1.26.20에서 추가되었다.

Component for spawning entities when an entity perishes.

> [!Note]
> Added in 1.26.20. Spawns one or more entities when the owning entity perishes. `entity_to_spawn` defaults to the owning entity, `spawn_method` defaults to `spawned` (also accepts `born` and `summoned`), `spawn_amount` defaults to 1, `inherit_parent_name` defaults to true, and `additional_spawn_range` adds optional random offset. `filters` gates whether the spawn is triggered at all.

> [!Note]
> This item requires a format version of at least 1.26.20.

## minecraft&#58;spell_effects

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_spell_effects.md`)

엔티티가 자신에게 상태 효과를 추가하거나 제거하게 한다.

Allows an entity to add or remove status effects from itself. Similarly to `addrider`, this component performs a one-time operation on the entity when added. Removing the component will not change the entity's current effects. Adding different versions of the component multiple times will perform each one in turn. Once the component has been added, it will not provide any further functionality. There is one exception to this behavior: if this component is present on a player, its effects will be re-applied every time the player enters the world. To avoid this, remove the component shortly after adding it, or add an empty component to replace it.

### Entity Spell Effects Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| add_effects | [] | Array of Add Effects items | 이 엔티티에 추가할 효과 목록. | Player: `[{"display_on_screen_animation":true,"duration":30,"effect":"raid_omen"}]` |
| remove_effects | [] | Array of strings | 이 컴포넌트를 추가한 뒤 엔티티에서 제거할 효과의 식별자. | Player: `"bad_omen"` |

> From 1.21.130, each entry in `tame_items` accepts an optional `result_item` field. On a successful tame interaction, the consumed item is replaced in the player's inventory with the specified item.

### Tameable Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| probability | 1 | Decimal number | 아이템을 쓸 때마다 엔티티를 길들일 확률(0.0~1.0). 1.0이 100%다. | Parrot: `0.33` |
| tame_event | *not set* | Object | 엔티티가 길들여졌을 때 발생시킬 이벤트. event와 target 속성을 가진 객체 또는 단순한 이벤트 문자열을 쓸 수 있다. | Parrot: `{"event":"minecraft:on_tame","target":"self"}` |
| tame_event (as String) | *not set* | String |  |  |
| tame_items | *not set* | Array of strings | 이 엔티티를 길들이는 데 쓸 수 있는 아이템 목록. | Parrot: `["wheat_seeds","pumpkin_seeds","melon_seeds","beetroot_seeds","pitcher_pod","torchflower_seeds"]` |
| tameItems | *not set* | String |  |  |

### 예시

##### [Parrot](https://github.com/Mojang/bedrock-samples/tree/preview/behavior_pack/entities/parrot.json)


```json
"minecraft:tameable": {
  "probability": 0.33,
  "tame_items": [
    "wheat_seeds",
    "pumpkin_seeds",
    "melon_seeds",
    "beetroot_seeds",
    "pitcher_pod",
    "torchflower_seeds"
  ],
  "tame_event": {
    "event": "minecraft:on_tame",
    "target": "self"
  }
}
```
