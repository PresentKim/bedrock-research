# 엔티티 컴포넌트 레퍼런스 (11/23)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 컴포넌트 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;managed_wandering_trader

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_managed_wandering_trader.md`)

> * Wandering Trader (minecraft:wandering_trader)

## minecraft&#58;mob_effect

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_mob_effect.md`)

범위 안에 들어온 엔티티에게 몹 효과를 적용하는 컴포넌트다.

A component that applies a mob effect to entities that get within range.

### Mob Effect Properties

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| ambient | false | Boolean true/false | true이면 효과가 (신호기나 컨듀잇처럼) 주변 효과 배경으로 렌더링되고 만료가 가까워져도 깜박이지 않는다. 형식 버전 1.21.130 이상이 필요하다. |
| cooldown_time | 0 | Integer number | 효과를 적용하는 간격(초). |
| effect_range | 0.2 | Decimal number | 몹 효과가 적용되려면 적대적인 엔티티가 얼마나 가까이 있어야 하는지. |
| effect_time | 10 | Integer number | 적용된 몹 효과가 지속되는 시간(초). "infinite"로도 설정할 수 있다. |
| entity_filter | *not set* | Minecraft filter | 몹 효과를 적용할 수 있는 유효한 엔티티 집합. |
| mob_effect | *not set* | String | 이 엔티티의 효과 범위에 들어온 엔티티에게 적용되는 몹 효과. |

## minecraft&#58;movement

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_movement.md`)

엔티티의 기본 이동 속도를 정의한다.

Defines the base movement speed of an entity. Typical values: creeper (0.2), cow (0.25), zombie baby (0.35).

### Movement Properties

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| max | *not set* | Decimal number | 이 엔티티가 가질 수 있는 최대 이동 속도. |
| value | *not set* | Decimal number | 기본 이동 속도 값. 높을수록 빠르게 움직인다. 숫자 하나 또는 range_min과 range_max를 가진 범위 객체를 쓸 수 있다. |
| value (as Object) | *not set* | Value item |  |

#### Value

##### Value Properties

**JSON path:** `value`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| range_max | *not set* | Decimal number | 최대 이동 속도. |
| range_min | *not set* | Decimal number | 최소 이동 속도. |
