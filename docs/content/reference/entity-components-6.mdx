# 엔티티 컴포넌트 레퍼런스 (6/23)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 컴포넌트 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;entity_sensor

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_entity_sensor.md`)

여러 하위 감지기를 가지며, 범위 안의 다른 엔티티가 조건을 만족하면 각각 이벤트를 발생시킨다.

A component that owns multiple subsensors, each one firing an event when a set of conditions are met by other entities within the defined range.

### Entity Sensor Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| find_players_only | false | Boolean true/false | 모든 하위 감지기가 플레이어만 감지하도록 제한한다. |  |
| relative_range | true | Boolean true/false | true이면 하위 감지기의 범위가 엔티티의 크기에 더해진다. |  |
| subsensors | *not set* | Array of Subsensors items | 엔티티를 감지하고 모든 조건이 충족되면 이벤트를 내보내는 하위 감지기 목록. | Parrot: `[{"event":"minecraft:on_riding_player","event_filters":{"all_of":[{"test":"is_riding","operator":"equals","subject":"self","value":true},{"test":"has_component","operator":"equals","subject":"self","value":"minecraft:behavior.look_at_player"}]},"range":[2,2]}]`, `[{"event":"minecraft:on_not_riding_player","event_filters":{"all_of":[{"test":"is_riding","operator":"equals","subject":"self","value":false},{"test":"has_component","operator":"not","subject":"self","value":"minecraft:behavior.look_at_player"}]},"range":[2,2]}]` |

#### Subsensors
The list of subsensors which sense for entities and emit events when all their conditions are met.


##### Subsensors Properties

**JSON path:** `subsensors`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| cooldown | -1 | Decimal number | 하위 감지기가 다시 엔티티를 감지하기까지 지나야 하는 시간(초). |
| event | *not set* | Minecraft Event Trigger | 조건이 충족되었을 때 발생시킬 이벤트. |
| event_filters | *not set* | Minecraft filter | 이벤트를 발생시키기 위해 충족해야 하는 조건 집합. |
| maximum_count | -1 | Integer number | 이벤트를 보내기 위해 필터 조건을 통과해야 하는 엔티티의 최대 수. |
| minimum_count | 1 | Integer number | 이벤트를 보내기 위해 필터 조건을 통과해야 하는 엔티티의 최소 수. |
| range | [10, 10] | a, b coordinate array | 다른 엔티티가 이 엔티티로부터 떨어져 있으면서 필터 검사를 받을 수 있는 최대 수평·수직 거리. |
| require_all | false | Boolean true/false | true이면 이벤트를 보내기 위해 근처의 모든 엔티티가 필터 조건을 통과해야 한다. |
| y_offset | 0 | Decimal number | 다른 엔티티와의 거리를 계산할 때 엔티티 위치에 적용하는 수직 오프셋. |

##### cooldown

How many seconds should elapse before the subsensor can once again sense for entities. The cooldown is applied on top of the base 1 tick (0.05 seconds) delay. Negative values will result in no cooldown being used.

## minecraft&#58;environment_sensor

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_environment_sensor.md`)

환경 조건에 따라 작동하는 트리거를 만든다.

Creates a trigger based on environment conditions.

### Environment Sensor Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| triggers | *not set* | Array of objects | 환경 조건이 필터 기준과 맞을 때 실행되는 트리거 목록. 트리거 객체의 배열이나 하나의 트리거 객체를 쓸 수 있다. | Breeze: `[{"event":"minecraft:stop_playing_idle_ground_sound","filters":{"all_of":[{"subject":"self","test":"on_ground","value":true},{"subject":"self","test":"has_target","value":true},{"domain":"minecraft:is_playing_idle_ground_sound","operator":"==","test":"bool_property"}]}},{"event":"minecraft:start_playing_idle_ground_sound","filters":{"all_of":[{"domain":"minecraft:is_playing_idle_ground_sound","operator":"!=","test":"bool_property"},{"any_of":[{"subject":"self","test":"on_ground","value":false},{"subject":"self","test":"has_target","value":false}]}]}}]`, Cave Spider: `{"event":"minecraft:become_neutral","filters":{"operator":">","test":"is_brightness","value":0.49}}`, `{"event":"minecraft:become_hostile","filters":{"operator":"<","test":"is_brightness","value":0.49}}` |
| triggers (as Object) | *not set* | Object |  |  |

            "value": true

            "test": "bool_property"

      }

      "event": "minecraft:start_playing_idle_ground_sound",

            "operator": "!=",
            "test": "bool_property"
          },
          {
            "any_of": [
              {
                "subject": "self",
                "test": "on_ground",
                "value": false
              },
              {
                "subject": "self",

                "value": false
              }

          }

  ]

## minecraft&#58;equippable

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_equippable.md`)

엔티티에 아이템을 장착하는 동작을 정의한다.

Defines an entity's behavior for having items equipped to it.

> [!Note]
> In 1.26.0, `on_equip` and `on_unequip` events on each slot no longer fire on world load; they now run only as a result of an in-game equip or unequip interaction.

### Equippable Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| slots | *not set* | Array of Slots items | 슬롯과 그 슬롯에 장착할 수 있는 아이템 목록. | Llama: `[{"slot":1,"item":"carpet","accepted_items":["carpet"]}]` |

#### Slots
List of slots and the item that can be equipped.


##### Slots Properties

**JSON path:** `slots`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| accepted_items | *not set* | Array of strings | 이 슬롯에 들어갈 수 있는 아이템 목록. |
| interact_text | *not set* | String | 터치스크린 조작 시 엔티티에 이 아이템을 장착할 수 있을 때 표시할 텍스트. |
| item | *not set* | String | 이 슬롯에 장착할 수 있는 아이템의 식별자. |
| on_equip | *not set* | Minecraft Event Trigger | 엔티티가 이 아이템을 장착했을 때 발생시킬 이벤트. |
| on_unequip | *not set* | Minecraft Event Trigger | 이 아이템이 엔티티에서 제거될 때 발생시킬 이벤트. |
| slot | 0 | Integer number | 이 슬롯의 슬롯 번호. |

### 예시

##### [Llama](https://github.com/Mojang/bedrock-samples/tree/preview/behavior_pack/entities/llama.json)


```json
"minecraft:equippable": {
  "slots": [
    {
      "slot": 1,
      "item": "carpet",
      "accepted_items": [
        "carpet"
      ]
    }
  ]
}
```
