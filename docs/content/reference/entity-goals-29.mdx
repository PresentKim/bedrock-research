## minecraft&#58;behavior.raid_garden

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityGoals/minecraftBehavior_raid_garden.md`)

배가 찰 때까지 농장의 작물을 먹어 치우게 한다.

Allows the mob to eat/raid crops out of farms until they are full.

### Entity Raid Garden Behavior Properties

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| blocks | [] | Array of strings | 몹이 먹거나 약탈하려고 찾는 블록. |
| control_flags | [] | Control Flags choices |  |
| eat_delay | 2 | Integer number | 먹거나 약탈하는 사이의 시간(초). |
| full_delay | 100 | Integer number | 최대량을 먹은 뒤 이 몹이 다시 먹거나 약탈하고 싶어지기까지의 시간(초). |
| goal_radius | 0.5 | Decimal number | 몹이 목표에 도달했다고 보는 블록 거리. AI가 특정 지점에 닿으려 앞뒤로 흔들리는 것을 막는 '여유'다. 값은 0보다 커야 한다. |
| initial_eat_delay | 0 | Integer number | 먹거나 약탈할 곳에 도착한 뒤 먹기 시작하기까지의 시간(초). |
| max_to_eat | 6 | Integer number | 이 엔티티가 먹거나 약탈하려는 작물의 최대 개수. 0 이하이면 최대가 없다. |
| priority | 0 | Integer number | 0에 가까울수록 우선순위가 높아진다. 우선순위가 높을수록 이 행동(목표)이 더 먼저 실행된다. |
| search_height | 1 | Integer number | 몹이 먹을 작물을 찾는 높이(블록). 값은 0보다 커야 한다. |
| search_range | 0 | Integer number | 몹이 먹을 작물을 찾는 거리(블록). 값은 0보다 커야 한다. |
| speed_multiplier | 1 | Decimal number | 이 목표를 쓸 때의 몹 이동 속도 배율. |
