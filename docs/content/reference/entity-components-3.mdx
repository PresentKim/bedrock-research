# 엔티티 컴포넌트 레퍼런스 (3/23)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 컴포넌트 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;area_attack

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_area_attack.md`)

범위 안에 들어온 엔티티에게 피해를 주는 컴포넌트다.

A component that does damage to entities that get within range.

### Area Attack Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| cause | *not set* | String from a list of choices | 피해 범위에 들어온 엔티티에게 주는 피해의 종류. | Magma Cube: `"entity_attack"` |
| damage_cooldown | 0 | Decimal number | 이 엔티티가 대상을 공격할 수 있는 간격의 쿨다운(초). | Magma Cube: `0.5` |
| damage_per_tick | 2 | Integer number | 피해 범위에 들어온 엔티티에게 틱마다 주는 피해량. | Magma Cube: `6`, `4`, `3` |
| damage_range | 0.2 | Decimal number | 피해를 적용하려면 적대적인 엔티티가 얼마나 가까이 있어야 하는지. | Magma Cube: `0.15` |
| death_message_override | *not set* | String | 범위 공격으로 엔티티가 죽을 때 사망 메시지로 쓸 번역 키. 비어 있으면 피해 원인의 기본 사망 메시지를 쓴다. |  |
| entity_filter | *not set* | Minecraft filter | 범위 안에 있을 때 피해를 줄 수 있는 유효한 엔티티 집합. | Magma Cube: `{"any_of":[{"subject":"other","test":"is_family","value":"player"},{"subject":"other","test":"is_family","value":"irongolem"}]}`, Slime: `{"any_of":[{"subject":"other","test":"is_family","value":"player"},{"subject":"other","test":"is_family","value":"irongolem"},{"subject":"other","test":"is_family","value":"snowgolem"}]}` |
| play_attack_sound | true | Boolean true/false | 엔티티가 대상을 공격할 때 공격 소리를 재생할지 여부. |  |
| use_self_as_damage_source | true | Boolean true/false | 엔티티를 범위 피해의 가해자로 볼지 여부. |  |

#### cause

The type of damage that is applied to entities that enter the damage range. A list of available damage sources can be found at Entity Damage Sources located in the Vanilla Listings Documentation.

#### use_self_as_damage_source

Whether the entity is treated as the source of the area damage. When true (default), other entities can retaliate against the attacking entity. Set to false to apply damage without making the attacker a valid retaliation target. This item requires a format version of at least 1.26.30.

## minecraft&#58;attack

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_attack.md`)

엔티티의 근접 공격 피해량과 적중 시 부여할 상태 효과를 정의한다.

Defines an entity's melee attack damage and any additional status effects applied on hit. Typical damage values range from 3 (zombie, creeper) to 7-21 (iron golem).

### Entity Attack Properties

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| damage | &#123;"max":0,"min":0&#125; | Range of floats | 근접 공격이 주는 무작위 피해량의 범위. |
| damage (Damage) | *not set* | Damage (Damage) item |  |
| effect_amplifier | 0 | Integer number | 피해를 입은 엔티티에게 적용되는 상태 이상의 증폭 수준(포션 단계). |
| effect_duration | 0 | Decimal number | 피해를 입은 엔티티에게 적용되는 상태 이상의 지속 시간(초). |
| effect_name |  | String | 이 엔티티의 근접 공격을 받은 엔티티에게 적용할 상태 이상의 식별자. |

#### damage

Range of the random amount of damage the melee attack deals. A negative value can heal the entity instead of hurting it. Can be a number, an array [min, max], or an object with range_min and range_max properties.

#### effect_amplifier

Amplifier level (potion tier) of the status ailment applied to the damaged entity. Higher values increase the strength of the effect. Fixed in format version 1.26.30: `effect_amplifier` is now actually applied to the inflicted status effect, so amplifier-sensitive effects such as Hunger now scale correctly when triggered by a mob's melee attack. Prior versions silently ignored this value.

## minecraft&#58;body_rotation_axis_aligned

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_body_rotation_axis_aligned.md`)

몸이 현재 방향에서 가장 가까운 기준 방향(동서남북)에 맞게 자동으로 회전하게 한다.

Causes the entity's body to automatically rotate to align with the nearest cardinal direction based on its current facing direction.
Combining this with the "minecraft:body_rotation_blocked" component will cause the entity to align to the nearest cardinal direction and remain fixed in that orientation, regardless of future changes in its facing direction.
