# 엔티티 컴포넌트 레퍼런스 (12/23)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 컴포넌트 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;navigation.generic

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_navigation.generic.md`)

걷기, 헤엄, 비행, 오르기, 블록 오르내리기를 모두 포함한 경로를 만들게 한다.

Allows this entity to generate paths by walking, swimming, flying and/or climbing around and jumping up and down a block.

### Generic Navigation Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| avoid_damage_blocks | false | Boolean true/false | 경로를 찾을 때 피해를 주는 블록을 피하도록 길 찾기에 알린다. | Frog: `true` |
| avoid_portals | false | Boolean true/false | 경로를 찾을 때 (네더 포털 같은) 포털을 피하도록 길 찾기에 알린다. |  |
| avoid_sun | false | Boolean true/false | 경로를 만들 때 햇빛에 노출된 칸을 피할지 정한다. |  |
| avoid_water | false | Boolean true/false | 경로를 만들 때 물을 피하도록 길 찾기에 알린다. |  |
| blocks_to_avoid | *not set* | Array of strings | 경로를 만들 때 피할 블록을 길 찾기에 알린다. |  |
| can_breach | false | Boolean true/false | (돌고래처럼) 물 밖으로 뛰어오를 수 있는지 길 찾기에 알린다. | Elder Guardian: `true` |
| can_break_doors | false | Boolean true/false | 닫힌 문을 부수고 지나가는 경로를 만들 수 있다고 길 찾기에 알린다. |  |
| can_jump | true | Boolean true/false | 블록 위로 뛰어오를 수 있는지 길 찾기에 알린다. |  |
| can_open_doors | false | Boolean true/false | AI가 문을 열 것이라 가정하고 닫힌 문을 지나는 경로를 만들 수 있다고 길 찾기에 알린다. |  |
| can_open_iron_doors | false | Boolean true/false | AI가 문을 열 것이라 가정하고 닫힌 철문을 지나는 경로를 만들 수 있다고 길 찾기에 알린다. |  |
| can_pass_doors | true | Boolean true/false | 문을 지나는 경로를 만들 수 있는지 여부. |  |
| can_path_from_air | false | Boolean true/false | 공중에 있을 때도 경로 탐색을 시작할 수 있다고 길 찾기에 알린다. |  |
| can_path_over_lava | false | Boolean true/false | 용암 표면 위를 이동할 수 있는지 길 찾기에 알린다. |  |
| can_path_over_water | false | Boolean true/false | 물 표면 위를 이동할 수 있는지 길 찾기에 알린다. | Frog: `true` |
| can_sink | true | Boolean true/false | 물속에서 중력에 끌려 내려가는지 길 찾기에 알린다. |  |
| can_swim | false | Boolean true/false | 물속 어디든 경로를 만들 수 있는지, 그 경로에서 수영 애니메이션을 재생하는지 길 찾기에 알린다. | Elder Guardian: `true` |
| can_walk | true | Boolean true/false | 물 밖 지면 위를 걸을 수 있는지 길 찾기에 알린다. | Frog: `true` |
| can_walk_in_lava | false | Boolean true/false | 지면을 걷듯 용암 속을 이동할 수 있는지 길 찾기에 알린다. |  |
| is_amphibious | false | Boolean true/false | 물속 바닥 위를 걸을 수 있는지 길 찾기에 알린다. | Elder Guardian: `true` |
| using_door_annotation | *not set* | String |  | Elder Guardian: `true` |

### 예시

##### [Elder Guardian](https://github.com/Mojang/bedrock-samples/tree/preview/behavior_pack/entities/elder_guardian.json)
