# 엔티티 컴포넌트 레퍼런스 (8/23)

MS Learn(MicrosoftDocs/minecraft-creator a9fd1c0, CC BY 4.0)의 컴포넌트 문서를 옮긴 쪽이다. 설명은 한국어로 옮기고 ID, 속성 이름, 유형, 기본값, JSON은 원문 그대로 두었다. 전체 목록은 [색인](./entity-index.mdx)에 있다.

## minecraft&#58;genetics

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_genetics.md`)

몹의 유전자와 대립유전자가 자손에게 전달되고 발현되는 방식을 정의한다.

Defines the way a mob's genes and alleles are passed on to its offspring, and how those traits manifest in the child. Compatible parent genes are crossed together, the alleles are handed down from the parents to the child, and any matching genetic variants fire off JSON events to modify the child and express the traits.

### Genetics Properties

| 이름 | 기본값 | 유형 | 설명 | 예시 값 |
| --- | --- | --- | --- | --- |
| genes | *not set* | Array of Genes items | 이 엔티티가 가졌고 번식할 때 짝과 교배하는 유전자 목록. | Goat: `[{"name":"goat_variant","use_simplified_breeding":true,"allele_range":{"range_min":1,"range_max":100},"genetic_variants":[{"main_allele":{"range_min":1,"range_max":2},"birth_event":{"event":"minecraft:born_screamer","target":"self"}},{"main_allele":{"range_min":3,"range_max":100},"birth_event":{"event":"minecraft:born_default","target":"self"}}]}]` |
| mutation_rate | 0.03125 | Decimal number | 출생 시 대립유전자가 부모의 것 대신 무작위 값으로 바뀔 확률. | Goat: `0.02` |

#### Genes
The list of genes that this entity has and will cross with a partner during breeding.


##### Genes Properties

**JSON path:** `genes`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| allele_range | *not set* | Integer number | 이 유전자의 양의 정수 대립유전자 값 범위. |
| allele_range (as Object) | *not set* | Allele Range item |  |
| genetic_variants | *not set* | Array of Genetic Variants items | 이 유전자의 유전 변이 목록. 특정 대립유전자 조합을 검사하고 모두 만족하면 이벤트를 발생시킨다. |
| mutation_rate | -1 | Decimal number | 이 값이 음수가 아니면, 출생 시 대립유전자가 부모의 것 대신 무작위로 바뀔 이 유전자의 확률을 덮어쓴다. |
| name | *not set* | String | 유전자의 이름. |
| use_simplified_breeding | *not set* | Boolean true/false | true이면 번식으로 스폰된 몹이 부모의 주 대립유전자에서 주 대립유전자를, 숨은 대립유전자에서 숨은 대립유전자를 항상 물려받는다. |

##### allele_range

The range of positive integer allele values for this gene. Spawned mobs will have a random number in this range assigned to them. Can be a single integer or an object with range_min and range_max properties.

##### mutation_rate

If this value is non-negative, overrides the chance for this gene that an allele will be replaced with a random one instead of the parent's allele during birth. Non-negative values greater than `1` will be the same as the value `1`.

        "range_min": 1,
        "range_max": 100

        {

          },

## minecraft&#58;home

(출처: ms-learn, `creator/Reference/Content/EntityReference/Examples/EntityComponents/minecraftComponent_home.md`)

엔티티가 스폰될 때의 집 위치를 저장한다. 벌이 벌집으로 돌아가는 동작에 쓴다.

Saves a home position for when the entity is spawned. This component allows entities like bees to remember and return to a specific location such as a hive or nest.

### Entity Home Properties

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| home_block_list | [] | Array of strings | 유효한 집으로 볼 수 있는 블록의 선택적 목록. |
| restriction_radius | 0 | Integer number | 집을 기준으로 엔티티가 제한되는 선택적 반경. |
| restriction_type | none | Restriction Type choices | 엔티티가 집 위치에 제한되는 방식을 정의한다. |

#### home_block_list

Optional list of blocks that can be considered a valid home. If no such block longer exists at that position, the home restriction is removed. Example syntax: minecraft:sand. Not supported: minecraft:sand:1.

#### restriction_type

Defines how the entity will be restricted to its home position. Valid values are: 'none' (no restriction), 'random_movement' (restricts random wandering to be near home), and 'all_movement' (restricts all movement to be near home, though entities can always move closer to home if they are too far away). This item requires a format version of at least 1.21.40.


#### Restriction Type choices

| 값 | 제목 | 설명 |
| --- | --- | --- |
| all_movement | All movement |  |
| none | None |  |
| random_movement | Random movement |  |

#### Damage Conditions
List of damage conditions that when met can cause damage to the entity.


##### Damage Conditions Properties

**JSON path:** `damage_conditions`

| 이름 | 기본값 | 유형 | 설명 |
| --- | --- | --- | --- |
| cause | *not set* | String | 엔티티에게 가해지는 피해의 종류. 여러 방어구와 주문이 이를 보고 엔티티가 면역인지 판단한다. |
| damage_per_tick | 1 | Integer number | 조건이 충족되는 동안 틱마다 주는 피해량. |
| filters | *not set* | Minecraft filter | 엔티티가 정의된 피해를 입기 전에 만족해야 하는 조건 집합. |
