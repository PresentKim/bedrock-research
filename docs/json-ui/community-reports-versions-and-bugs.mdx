커뮤니티 보고 중 알려진 제한과 우회법, 버전별 변화 연표(1.19.20 ~ 26.70), 커뮤니티 도구와 자료, 아직 답이 없는 질문을 모았다.

신뢰 표시와 `` 형태의 출처 표기는 커뮤니티 보고와 대조 페이지의 머리말과 같다: *confirmed*는 여러 사람이 확인, *single report*는 한 사람의 보고, *unverified*는 추측, **conflicting**은 보고가 엇갈림이다.

## 알려진 제한과 우회법

- **데이터 읽기 불가 목록**: 체력, 효과, 플레이어 property, tag, scoreboard 값, dynamic property, Molang, 밝기, 3인칭 여부, 들고 있는 아이템의 충전, GUI 스케일, 부모 크기, 텍스처 크기, 월드 이름(폼)을 읽을 수 없다. 우회: 스크립트가 title/actionbar/subtitle/chat/폼 텍스트로 보내고 JSON UI가 파싱한다.
- **UI→스크립트 불가**: UI에서 스크립트를 부를 수 없다. 우회: 폼 submit, 아이템 드롭 매핑(`button.drop_one`/`drop_all`), 채팅 메시지 + `chatSend`, 핫바 슬롯 선택.
- **열린 폼 갱신 불가**: JSON UI 폼은 다시 보내야 한다. DDUI는 실시간이지만 꾸밀 수 없다. 컨테이너 화면(chest UI)은 실시간으로 갱신된다.
- **버튼은 폼을 닫는다**: `form_button_click`은 항상 닫는다. 우회: 재귀로 다시 열기, 커스텀 button id(`button.menu_left/right`)로 폼 안 상태 변경, 화면 애니메이션 제거로 깜빡임 숨기기.
- **커스텀 키바인드나 화면 열기 불가**: HUD 버튼에서 폼이나 NPC 대화를 열 수 없다. 커스텀 버튼으로 커스텀 화면을 열 수 없다(button id 하드코딩). 커스텀 화면은 만들 수 없고 기존 화면 안에 숨긴 패널을 `#toggle_state` + `#visible`로 드러낸다.
- **회전 불가, 무작위 불가, `Includes` 없음**: Molang visibility도 없다. 우회: 미리 회전한 텍스처, flipbook, player.json/paperdoll 모델, GeoUI.
- **크래시 함정**: 크기/offset 바인딩에 잘못된 값, 문자열 나눗셈, 리터럴 실수 나눗셈, prefix 없는 title에 산술, `('§' + #text)`에 `= #text`를 더 붙이기(크래시 보고), 모바일 `binding_name` 안 `and`, 큰 이미지가 있다. Windows와 Android는 서로 다른 잘못된 식에서 죽는다. title-splitting UI로 Android가 죽었다는 보고도 있다.
- **팩 간 충돌**: title/actionbar는 공유 자원이다. 공유 큐 관례를 쓰거나(예: UI Queue 애드온 `/scriptevent ui_load:<id> <message>`) 팩 우선순위를 정한다. `modifications`는 위 팩만 이긴다. 비폼 커스텀 UI 호환성은 나쁘다. 그래서 player.json/UI 편집 대신 스크립트 카메라와 파티클로 피하는 사례가 있다.
- **폼 렉**: grid, `binding_condition: once`, factory 0/1 생성, `ignored`, 페이지 분할, 탭 지연 로드, 요소 합치기로 줄인다.
- **Hidden-slot 텍스트 대체**: chest UI에는 임의 라벨이 없으니 숨긴 아이템의 이름, lore, 내구도로 텍스트와 값을 나른다(무거움).
- **PC/모바일 차이**: HUD 버튼은 터치 전용이다. 폼을 연 채 이동하는 것도 터치에서만 된다. 혼합 커스텀 핫바는 모바일과 데스크톱에서 다르게 동작한다(미해결).
- **링크 불가**: 애드온은 클릭 가능한 링크를 열 수 없다. JSON UI로 QR 코드 이미지를 보인다(qrcode-monkey.com).
- **거래 주민 교체 모드**: UI가 새로 고쳐지면서 화면이 닫혀 불가능하다.
- **중복 자식 이름 경고**: `how_to_play_screen.json`의 중복 자식 컨트롤 이름 경고는 앞으로 오류가 된다. 오래된 팩의 hud_screen은 파싱 오류를 낸다. 스크립트가 활성일 때 HUD "waila" 팩이 `JSON UI parse failure - expected a string`을 냈다.

## 버전별 변화

- **1.19.20**: `ignored` 속성과 변수/바인딩 동작이 문서 없이 바뀌었다(연산자 지원 방식, 같은 블록 안 변수 오류).
- **~2025 중반**: `#form_button_contents`가 생겼고 `control_ids` factory 패턴을 쓸 수 있게 됐다. 1.21.x에 폼 header/label/divider가 추가되면서 버튼 `collection_index`가 밀렸다.
- **2025-10 말**: 일부 문자열 곱셈 트릭이 제거됐다. 2025-10-29 릴리스에서 새 pause 화면과 `$is_big_screen`이 생겼다.
- **2025-11-04 preview**: `%.Ns`의 일부 용도(체력 바, 숫자 표시)가 깨졌고 noxcrew가 크래시 수정을 요청했다고 한다. 2025-11-11 preview에서 다른 곳의 바인딩을 가져오는 기능이 생겼다(`resolve_ancestor_scope`로 이어짐).
- **1.21.114**: `hud` namespace에서 `initial_uv`가 "unknown property"를 냈다.
- **1.21.120/121 (GDK, 2025-11)**: 메모리 누수로 Ore UI가 로드되지 않을 수 있다는 보고가 있다. *single report*
- **1.21.123 stable / 1.21.130.26 preview**: 다중 값 title 위치 지정이 동작함이 확인됐다.
- **1.21.130 (stable 2025-12-09)**: 문자열 곱셈이 리터럴 `'%.Ns' * #x`로 제한됐다(동적 N, `%X.*Xs`, `%-Xs`, `%Xs` 불가. changelog에 없었고 서버 스튜디오의 크래시 수정 요청 때문이라는 설). `* 1` 숫자 변환이 깨졌다. `%.Ns`의 바이트 경계가 "수정"됐다. aux 텍스처/Chest-UI 아이템 아이콘이 깨졌다(`% 65536` 수정). `resolve_ancestor_scope` view binding이 추가됐다(updatedjsonui changelog). 1.21.13x에 새 자막과 이미지 비율 속성이 생겼다. `/reload all`과 전역 리소스 UI 리로드 버그가 생겼다.
- **1.21.130 / 1.21.132 (Android)**: JSON UI를 덮어써 Android 구조물 내보내기 버튼을 켜던 팩 동작이 1.21.130에서 막혔고, Ore UI로 바뀐 뒤 1.21.132에서 이런 애드온이 깨졌다. 26.60에서는 Ore UI 번들 .js로 "Export world"를 되살린 팩이 나왔다.
- **2025-12 중순 업데이트**: `(#hud_title_text_string*1)` 진행바가 멈췄고 `+0`으로 고쳤다. 스피어 업데이트 뒤 `live_player_renderer`가 attachable을 숨겼다(layer로 수정).
- **2026-01 preview**: Ore UI가 서버 treatments로 메뉴/설정을 대체했다. `1 * ('%.1s' * x)`가 깨졌다. stack panel `use_priority`가 생겼다. 명시 aux 아이템 렌더러가 이상해졌다(1.21.13x/preview).
- **2026-01-29**: 공식 JSON UI 레퍼런스가 learn.microsoft.com에 올라왔다(바닐라 예제에서 자동 생성되어 엉성함. Mojang이 다듬겠다고 함).
- **2026-02**: DDUI가 Preview에 들어왔다. stable에서 인벤토리/제작 UI가 리팩터링돼 커스텀 제작 UI가 깨졌다. 2026년 업데이트로 예전 preserved-image 구성이 깨졌다는 보고가 있다.
- **2026-04**: DDUI가 beta가 됐다. `resolve_ancestor_scope`가 stable에서 동작하지 않거나 오류를 낸다는 보고가 나왔다. 2026-04-26 stable에서 hud root를 수정하면 auto-save 애니메이션 오류가 났다.
- **2026-05**: `property_bag_for_children`이 stable에 들어왔다(~05-07). 1.26.30 계열에서 `(#str * 1)`이 멈췄으니 `(0 + #str)`을 쓴다(05-15 보고). 조준점 렌더러가 hud 파일에서 분리됐다는 언급이 있다(05-25). 효과 렌더러 버그가 생겼다.
- **26.30 (stable 2026-06-16)**: DDUI CustomForm이 stable이 됐다. 26.30에서 `%.Ns` 동작이 바뀌었다는 회상이 있다(chat prefix `%.6s` 검사가 안 맞음. 원인 미확인).
- **26.40**: 월드 시드 숨기기가 기본 기능이 됐다. `@minecraft/server-ui` preview 2.2.0-beta.1.26.40.
- **26.50**: lang `tile.<id>.tooltip` 아이템 툴팁이 생겼다.
- **1.26.52.3**: `button.sub_command` 채팅 버튼이 서드파티 서버에서 클라이언트 크래시를 냈다.
- **1.26.60.28 preview**: DDUI `styleId`가 생겼다(네이티브 모드 필요). 26.70.21에서는 `@minecraft/server-ui` 3.0.0-alpha가 모드 없이 지원한다.
- **2026-09 (stable, 시점 불명확)**: 변수는 곱할 수 있지만 맨 숫자는 곱할 수 없게 됐다는 보고가 있다. *single report*
- **2026-09-22 preview**: JSON UI content-log 오류가 늘었다. offhand/핫바가 리팩터링됐다. 2026-10-06 preview에서 오류 로깅이 개선됐고, 2026-10-13에 오류 타입이 다시 바뀌었다. preview에서 커스텀 블록 엔티티 `container` `title`과 커스텀 컨테이너 `$container_title`이 생겼다.
- **2026-10-15 확인**: 조준점이 `ui/hud_crosshair_overlay.json`으로 옮겨졌다.
- **26.60 stable (2026-10-27)**: Ore UI 로딩이 빨라졌다. `@minecraft/server-ui` stable 2.3.0. 툴팁의 마법, 용도, 공격력 줄이 모두 같은 색이 되고 한국어 줄 간격이 넓다는 보고가 있다. Switch 2는 26.60부터 따로 빌드된 판을 받았다. [보충 2026-10-28]
- **26.70.22 preview (2026-10-28)**: 아이템 툴팁 lang 키가 `item.<id>.tooltip`이 되고 `~LINEBREAK~`로 줄을 나눈다(26.50의 `tile.` prefix가 필요 없어짐). 커스텀 DDUI 강제 닫기 키 "Close Custom Screens". Ore UI 메인 메뉴 버전 표시의 "1." prefix 제거(MCPE-243637). 체인지로그에 Ore UI 내부 패키지 `@mojang/bedrock-core-engine`, `@mojang/react-device-information`이 나왔다. [보충 2026-10-28]
- **26.62.1 hotfix (2026-11-05)**: Ore UI 해시 파일 이름이 바뀌었다(`index-196362d73210d5a80339.js`, `index-8a62c541ed5f344be00f.css`, `menus-theme-ed1e9065b019d5f4427f.css`, `gameplay-theme-922e7c15cd35326d4a6a.css`). [보충 2026-11-04]
- **26.70.23 preview (2026-11-03)**: 체인지로그가 `ui/data_driven_container_screen.json`(namespace `data_driven_container`, 커스텀 블록 엔티티 컨테이너 UI)을 크리에이터가 고치지 않을 것으로 보고 하위 호환을 보장하지 않는다고 했다. "Support existing custom Minecraft emoji Unicode code points in Ore UI screens"가 들어갔지만 저장 토스트 외 대부분 화면(사망 화면, 월드 목록)에서는 네모로 나온다는 보고가 있다. `/chat show <global|party|world>` 채팅 채널, 오프핸드 스왑 키(F), `offhand_cooldown_renderer` 문자열, lang `hbui.MainMenu.Discovery.*`가 생겼다. DDUI 패널 배경이 사라졌다는 단일 보고가 있다. [보충 2026-11-03..06]
- **UWP 1.26.6301.0 (2026-11-10 보고)**: Ore UI 번들 이름이 `gameplay-react-<hash>.js`다. Conduit 클라이언트 v0.5.0-beta가 .62/.63을 지원한다.

## 미해결 질문

- **JSON UI 폐기 일정**: JSON UI는 언제 제거되는가? 예전 JSON UI 팩(서버 폼, HUD)은 Ore UI 전환 뒤에도 동작하는가? 명확한 Mojang 일정은 없다.
- **DDUI 레이아웃/스타일 공개 시점**: 크리에이터가 레이아웃 파일을 쓰고 HUD와 컨테이너를 커스터마이즈할 수 있는 시기는 미정이다.
- **`resolve_ancestor_scope`의 현재 상태**: 동작한다는 보고와 안 한다는 보고가 섞여 있다.
- **문자열 `-`의 정확한 의미**: 모든 출현을 지우는가, 첫 출현만 지우는가? `* 1` 변환이 현재 버전에서 어떤 조건에서 동작하는가?
- **같은 이름 slider 문제**: `collection_index`가 다른 slider가 하나처럼 동작하는 문제와 두 slider 충돌.
- **ancestor/scope와 `binding_condition`의 정확한 의미**: 특히 `visible`/`always_when_visible`.
- **mob_effects_renderer Y offset이 안 먹는 이유**: 그리고 title 렌더 때 상태 효과 바가 사라지는 버그.
- **preserved 아이콘 깜빡임**: 서브트리를 가로지르는 preserved 아이콘 깜빡임과 배경 이미지 있는 슬롯이 다른 슬롯이 채워졌을 때만 보이는 버그.
- **`/title @s clear`와 preserved title**: preserved title을 지우는 방법은?
- **grid 시작 위치와 빈 grid 스크롤**: grid를 특정 슬롯부터 시작하는 방법, 빈 grid가 든 스크롤 패널에 스크롤바가 보이는 문제.
- **커스텀 factory `control_ids`에 변수로 컨트롤 이름 넣기**, 그리고 factory 패널에서 `#title_text` collection 바인딩을 쓰면 하나만 생성되는 문제.
- **컨테이너 제목으로 chest grid 크기 바꾸기** (`variables` 시도가 실패함).
- **컨트롤러 2D 드래그, 마지막 입력 문자 감지, 같은 모바일/데스크톱 혼합 핫바 동작**.
- **subpack마다 다른 `.lang` 적용**.
- **DDUI 관련**: DDUI 화면을 페이드하면서 slider를 실시간으로 제어하는 방법, dropdown 항목 observable label 갱신 버그.
- **Ore UI 플레이 메뉴를 RP로 바꾸는 방법**, 사망 화면 빨간 오버레이 편집, 레시피 패널 기본 숨기기, 블록 뒤 이름표 숨기기, 상호작용 버튼/선택 외곽선 숨기기. 모두 질문만 있고 답이 없었다.
- **`:`로 시작하는 결과에서 빼기**: title `xTitle:1816`에서 `#data` = `:1816`을 얻은 뒤 `(#data - ':')`가 빈 값이 된다. 숫자로 시작하는 결과가 숫자로 취급되는 규칙과 관련 있어 보이지만 확인되지 않았다. [보충 2026-10-24]
- **서버 폼 다시 보내기의 번쩍임과 지연**: 수정한 server_form factory로 폼을 다시 보낼 때 화면 사이가 번쩍이는 이유, 서버 폼이 늦게 열리는 요인.
- **컨테이너 toggle 상태 보존**: 컨테이너를 닫았다 열어도 커스텀 toggle 상태를 남기는 방법.
- **`content.zipe` 신뢰 경로의 앞날**: Mojang이 이 경로를 막을지, 언제 막을지.
- **`titleraw` `§u` 배경 트릭**, `binding_collection_prefix`/`notify_on_ellipses`의 용도, stack panel `use_priority`의 용도.
