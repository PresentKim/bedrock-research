## 개념: 이 사전의 쓰임

JSON UI의 속성 값(`type`, `anchor_from`, `binding_type` …)은 공식 스키마의 enum, 위키 문서, 바닐라 실제 사용이 서로 다르다. 이 사전은 바닐라 1.26.50.4의 UI 파일 207개에서 각 속성에 리터럴로 쓰인 값과 횟수를 세고 공식 enum과 대조한 것이다. 예를 들어 `"type": "panel"`은 4092회로 가장 흔하고, `factory`·`collection_panel`처럼 enum에 없지만 바닐라가 쓰는 값(표의 **X**)도 있다. 새 값을 쓰기 전에 이 표에서 바닐라 횟수가 0이 아닌지 본다. 도구(스키마 검사기, 자동 완성)가 enum에 없는 값을 오류로 표시해도 바닐라가 쓰면 쓸 수 있다.



바닐라 리소스팩 `resource_pack/ui` v1.26.50.4(`46ba6ea`) 207개 파일에서 각 속성에 **리터럴로** 쓰인 값과 횟수다(이번 스레드 전수 검색, 정규식 기준이라 주석 안의 값도 일부 셀 수 있다). 공식 enum은 `@minecraft/bedrock-schemas`의 `forms/ui/ui_element.form.json` 값이다(bedrock-core 저자의 실측 기록 BC-facts에 적힌 목록).

읽는 법
- `공식 enum` 칸이 **X**인 값은 바닐라가 쓰지만 공식 enum에 없다. 쓸 수 있다.
- 횟수가 0인 값은 공식 enum에만 있고 바닐라는 쓰지 않는다. 쓰기 전에 실측한다.
- 이 표에 없는 값(외부 자료의 `scroll_box` 타입, `grid_fill_direction: left_to_right`, `resolve_ancestor_scope` 등)은 근거가 없다(충돌 판정표의 C-07~C-09, C-34).

## B.1 바닐라에 없는 이름 (외부 사전에 있으나 VN 0회)

다음 속성 이름은 한 외부 속성 사전(MJ가 분석한 저장소)에 있지만 바닐라 1.26.50.4에는 한 번도 나오지 않는다. 대부분 위키에서 온 "미확인" 이름이다. 쓰기 전에 실측한다.

`resolve_ancestor_scope`, `z_order`, `clip_offset`, `alignment`, `use_place_holder`, `pixel_perfect`, `gradient_direction`, `vr_mode`, `use_uuid`, `use_skin_gui_scale`, `use_player_paperdoll`, `animation_looped`, `precached_grid_item_count`, `gesture_control_enabled`, `toggle_on_hover`, `slider_timeout`, `focus_container_custom_down`, `button_name` (출처: MJ 4.2)

## B.2 바닐라가 쓰지만 공식 자료에 없는 속성

`collection_index`, `localize`, `clip_ratio`, `clip_direction`, `clip_pixelperfect`, `property_bag`, `variables`(와 `$변수`), 배열형 `nineslice_size`, `factory_variables`. `modifications`는 공식 자료에도 바닐라에도 없고 팩만 쓴다. (출처: BC-facts, VN)

## 반영안(미적용)

아래는 추가 자료 조사(survey)에서 나온 규칙 제안이다. 병합 보고서에는 번호가 매겨져 있지만 위 본문의 규칙집에는 아직 반영하지 않았다. 번호는 병합 보고서의 최종 ID이고, 근거 강도는 제안 원문의 검증 수준을 따른다. 쓰기 전에 확인한다.

- **[부록B 보강안(미적용)]** 값 사전에 `clip_direction`, `input_mode_condition` 표와 "바닐라에 없는 이름" 절(B.1)을 병합 보고서가 더했다(이 페이지에는 이미 들어 있다). 남은 확장 제안은 `$` 변수 목록(JsonEncryptor 제안 FILE-29)과 팩토리 목록(COL-14/COL-25)의 바닐라 대조 부록이다. 바닐라 grep 대조 작업이 필요해 이번 범위 밖으로 남겼다.
