# 엔진 내부

이 섹션은 Android 1.26.52.3 네이티브 클라이언트 라이브러리를 분석해 읽은 결과(`NB-01`~`NB-22`)를 모은다. 다른 출처에서 확인할 수 없던 엔진 동작을 `{코드}` 수준으로 적었다. 바이너리와 분석 결과 자체는 싣지 않는다.

## 페이지 지도

| 페이지 | 내용 |
|---|---|
| [JSON UI 엔진 발견](./json-ui-engine-findings.mdx) | `modifications`, 팩토리, 컬렉션, 바인딩, `ignored`, 색표, 하이퍼링크, 종이 인형 |
| [Ore UI 엔진 발견](./ore-ui-engine-findings.mdx) | Ore UI 파일 요청의 팩 조회와 신뢰 판정, 암호화 팩, 버튼 다리, DDUI, `geo-item` 아이콘 |
| [발견 색인](./findings-index.mdx) | NB-01~22 목록, 영향받는 가이드 규칙, 다시 확인한 것과 남은 것 |
