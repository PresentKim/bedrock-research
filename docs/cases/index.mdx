# 사례 연구

이 섹션은 실제 팩, 라이브러리, 도구, 문서를 하나씩 분석한 기록이다. 각 사례는 무엇을 하는지, 어떤 기법이 쓸 만한지, 가이드 규칙과 어디서 다른지, 라이선스가 무엇인지를 적는다. 규칙의 근거로 쓰인 출처가 어떻게 검증되었는지를 확인하려면 해당 사례를 본다.

## 페이지 지도
