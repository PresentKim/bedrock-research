## 무엇인가

JSON UI 테스터는 게임을 켜지 않고 리소스팩의 JSON UI를 돌려 보는 실험 도구다. 이 저장소의 엔진 근거(가이드 규칙, 엔진 동작 분석 `NB`, Cinnabar 재구성 `CN`)를 JavaScript로 다시 구현했고, 브라우저 GUI와 명령줄(`cli.mjs`) 두 가지로 쓴다. 바닐라 기준은 v1.26.50.4(`bedrock-samples` `46ba6ea`)다. **결과는 게임 동작이 아니다.** 엔진 규칙을 문서에서 옮긴 모델이라 규칙이 틀렸거나 아직 모르는 곳에서는 게임과 다르다. 최종 확인은 게임에서 한다(출처: tool-jsonui-tester, `README.md`). 라이선스는 이 프로젝트 자료다.

## 확인된 능력

| 확인한 것 | 결과 |
|---|---|
| 식 평가기 | Cinnabar 평가기 실행 결과 42건이 모두 같은 값. 바이트 자르기, 사슬 비교, `* 1`이 빈 문자열이 되는 것, `0.3`이 정수 0인 것, `%`·`>=`가 null이 되는 것 포함 |
| 크기 식 | Cinnabar 크기 식 결과 16건과 같다(`"100c%"`가 부모 %, `"10"`이 0, `50%cm`이 최대 자식) |
| 바닐라 전체 로드 | `ui/` 207개 파일, 정의 6,276개를 0.3초에 읽는다 |
| 바닐라 화면 해석 | `server_form.third_party_server_screen`(컨트롤 107개), `hud.hud_screen`(748개), `chest.small_chest_screen`(223개)을 해석 오류 0건으로 만든다 |
| 서버 폼 흉내 | 제목, 본문, 버튼을 주면 바닐라 레이아웃대로 제자리에 놓인다(창 225x200이 화면 가운데) |
| 버튼 누름 | 버튼 자신에 `collection_details`가 있으면 `selection = N`, 없으면 `canceled`(COL-04)로 답한다 |
| 시간 흐름 | `once`, `visibility_changed`를 틱 단위로 흉내 내 preserved title 래치가 동작한다 |

## 설치와 사용

Node 20 이상이 필요하고 외부 패키지는 없다(`package.json`은 `"type": "module"`, 테스트는 `node --test`).

### GUI

```bash
node jsonui-tester/serve.mjs            # 브라우저에서 http://localhost:5178
node jsonui-tester/serve.mjs 5179 --no-vanilla   # 바닐라를 GitHub에서 받는 모드
VANILLA=<resource_pack 경로> node jsonui-tester/serve.mjs   # 바닐라 폴더 지정
```

서버는 저장소 옆의 `bedrock-samples/resource_pack`을 자동으로 찾는다. 정적 호스팅에서는 바닐라를 GitHub(`Mojang/bedrock-samples`)에서 직접 받는다(UI 파일 207개를 처음에, 텍스처는 쓸 때). 화면 구성은 다음과 같다.

| 영역 | 하는 일 |
|---|---|
| 위 막대 | 엔진 모델(실측 우선 / CN 그대로), 플랫폼(데스크톱 / 휴대폰), 화면 크기, 배율, 윤곽·숨은 컨트롤 보기, "모르는 전역 `#visible`을 false로" |
| 왼쪽 "팩" | 바닐라, 내 리소스팩 폴더, 예제 팩을 넣고 순서를 바꾼다(위가 먼저 병합) |
| 왼쪽 "파일" | 읽은 UI 파일을 고쳐 바로 적용한다(Ctrl+Enter) |
| 가운데 | 화면. 컨트롤을 누르면 고르고, 버튼·토글이면 엔진 응답을 흉내 낸다. 호버도 된다 |
| "처음부터 다시" / "다음 틱" | 트리를 새로 만든다 / 상태를 유지한 채 호스트 데이터를 다시 보낸다 |
| 오른쪽 "호스트" | 서버 폼(제목, 본문, 버튼), HUD(타이틀, 부제, 액션바), 상자(이름, 칸), 직접 JSON |
| 오른쪽 "검사" | 컨트롤 트리, 정의 사슬, 사각형, 레이어, 속성 주머니, 바인딩, `$` 변수, 해석된 속성, 진단 |
| 오른쪽 "진단" | 엔진 오류 문구와 가이드 규칙 ID가 붙은 경고. 누르면 그 컨트롤로 간다 |
| 오른쪽 "식 실험" | 식과 속성 주머니를 넣으면 값과 함정을 바로 보여 준다 |

### 명령줄

```bash
node jsonui-tester/cli.mjs --vanilla ../bedrock-samples/resource_pack --pack ./my_rp \
  --root server_form.third_party_server_screen --title "myui:v1 상점" --buttons "사과;빵"
```

진단과 보이는 라벨(글자, 위치)을 출력하고 `error` 진단이 있으면 종료 코드 1을 낸다. `--json`은 JSON 출력, `--cn`은 CN 모델, `--host hud --hud-title T --actionbar A`는 HUD 모드다. CI나 AI 에이전트가 팩을 고친 뒤 정적 시뮬레이션으로 쓸 수 있다.

### 테스트

```bash
cd jsonui-tester && npm test    # 80건: 식 50, 크기·JSON 21, 정의 해석 8, 래치 1
```

배포는 `.github/workflows/jsonui-tester.yml`이 `main`에 올라올 때마다 테스트를 돌리고 저장소가 공개일 때만 GUI 파일을 GitHub Pages에 올린다. 무료 요금제는 비공개 저장소에서 Pages를 쓸 수 없다.

## 시제품으로 찾은 것

| 발견 | 내용 |
|---|---|
| 레시피 1의 라벨이 배경 뒤로 갈 수 있다 | `bg@common.common_panel`의 안쪽 `bg_image`가 `layer: 1`이라, layer를 안 준 형제 라벨(layer 0)은 그 아래에 그려진다(LAY-18). 예제 팩은 제목에 `layer: 2`를 줘서 고쳤다 |
| 식 안의 `$변수` 치환 | 근거가 갈린다(BND-33 실측은 치환 안 됨, 커뮤니티 preserved title 패턴은 동작). 테스터는 두 모델을 다 돌리고 실측 우선 모드에서 경고한다 |
| MOD-04 경고는 기반을 끝까지 봐야 한다 | `long_form`의 `bindings`는 기반에 `bindings`가 없어 안전하다. 경고는 모든 파일을 읽은 뒤 기반 사슬을 확인한다 |
| 바닐라의 숨김은 대부분 엔진 전역값이다 | HUD의 `#visible` 플래그를 흉내 데이터가 모르면 전부 보이므로 "모르는 전역 `#visible`을 false로" 옵션(기본 켬)을 둔다 |

## 한계

- 게임이 아니다. 근거가 코드인 규칙(NB, CN)은 그대로, 실측과 다른 곳은 "실측 우선" 모드에서 실측을 따른다(BND-05 배열 전체 버림, MOD-02 다른 경로 무시, EXP-10 리터럴 자르기 없음, BND-33). 둘 다 틀릴 수 있다.
- 엔진 데이터는 흉내다. 화면 컨트롤러가 주는 바인딩은 `src/engine/host.js`의 일부뿐이다. 아이템 렌더러, 종이 인형, 스크롤, 애니메이션, 입력 포커스, 소리는 그리지 않거나 자리표시만 한다.
- 글자 폭은 근사다(ASCII 6px, 넓은 글자 9px, 줄 10px). `%c`로 글자에 맞춘 레이아웃은 몇 픽셀 다를 수 있고, 현지화는 하지 않는다.
- 텍스처는 PNG·JPG만 그린다(TGA 없음). 9-slice는 CSS `border-image`, 틴트는 곱하기 혼합이라 색이 조금 다르다.
- 게임을 죽이는 식(크기 바인딩에 숫자 아닌 값, 문자열 나누기 등)은 진단으로만 알리고 크래시는 흉내 내지 않는다.
- 바닐라 1.26.50.4 구조 기준이다. 다른 버전의 바닐라를 넣으면 그 구조로 돈다.

## 구조

| 파일 | 하는 일 | 근거 규칙 |
|---|---|---|
| `src/engine/expr.js` | 토큰, 우선순위, 타입별 연산, 결과 재해석, 함정 검사 | EXP-*, CN-26~30 |
| `src/engine/jsonc.js` | jsoncpp 규칙(주석 허용, 뒤따르는 쉼표·따옴표 없는 키는 오류) | FILE-30, CN-01~02 |
| `src/engine/size.js` | 크기 식 | LAY-03, LAY-34~37, CN-47 |
| `src/engine/catalog.js` | `_ui_defs` 정렬 로드, 같은 경로 병합, `modifications` 11개 연산 | FILE-20~22, MOD-*, CN-03~13 |
| `src/engine/resolve.js` | `@` 상속, `$` 스코프, `variables`, `ignored` | FILE-*, CN-14~25, NB-10 |
| `src/engine/bind.js` | 속성 주머니, 팩토리·그리드·컬렉션, 바인딩, 버튼·토글 상태 | BND-*, COL-*, INP-* |
| `src/engine/layout.js` | 크기, 앵커, 스택, 그리드, 레이어, 클리핑, 가려짐 검사 | LAY-*, CN-48~50 |
| `src/engine/host.js` | 서버 폼, HUD, 상자 화면 흉내 데이터 | CN-59~60 |
| `src/render.js`, `src/app.js`, `index.html` | 브라우저 GUI | |
| `samples/sample-pack.js` | 예제 팩(가이드 레시피 1·2, preserved title, 놀이터) | PAT-01~02, BND-18 |

## 다음에 할 만한 것

게임 확인 항목을 실제 게임으로 재서 모드 규칙에 반영하고, 엔진 컨트롤러가 주는 전역 바인딩을 화면별로 모으며, 글꼴 메트릭을 바닐라 글리프 폭으로 바꾸고, `anims`를 시간 축으로 재생하는 것이다.
