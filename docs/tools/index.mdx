이 섹션은 베드락 애드온과 JSON UI 개발에 쓰는 도구를 한곳에 모은다. 도구마다 무엇을 하는지, 어떻게 설치하고 쓰는지, 어디까지 믿을 수 있는지(한계), 라이선스가 무엇인지를 적는다. 도구 저장소를 직접 받아 라이선스 파일과 README를 확인했고, 확인한 커밋은 각 페이지 맨 아래 출처 표에 있다.

## 어떤 도구를 고를까

| 하려는 일 | 도구 | 페이지 |
|---|---|---|
| JSON과 스크립트 편집, 디버깅 | VS Code, Blockception 확장, Mojang 디버거, jsonui-lsp | [편집기, 언어 서버, 디버거](./editors-and-lsp.mdx) |
| JSON 검증 | Blockception 스키마, KalmeMarq 스키마 | [JSON 스키마](./schemas.mdx) |
| JSON UI 화면 만들기 | JsonForge, EasyUIBuilder, bedrock-json-ui-editor, JsonEncryptor | [JSON UI 편집기와 생성기](./json-ui-builders.mdx) |
| JSON UI를 게임 없이 시험 | JSON UI 테스터 | [JSON UI 테스터](./jsonui-tester.mdx) |
| 빌드와 배포 | Regolith, jsonte, bedrock-boost, GDK 경로 | [빌드 파이프라인](./build-pipelines.mdx) |
| 모델, 애니메이션, 텍스처 | Blockbench, Mcblend, Snowstorm | [모델링과 텍스처 도구](./modeling.mdx) |
| 월드와 구조물 | NBT 편집기, Editor 모드 | [월드, 구조물, NBT 도구](./world-and-nbt-tools.mdx) |

## 읽는 법

- 각 도구 절은 "하는 일, 설치와 사용, 한계, 라이선스" 순서다.
- 페이지 끝의 "커뮤니티 노트"는 커뮤니티 조사(2025-10-22부터 2026-11-13까지)에서 모은 세부다. 줄 끝의 `[uNNN 날짜]`는 근거가 된 대화의 익명 번호와 날짜다.
- 에디터나 스키마가 낸 오류는 틀릴 수 있다. 최종 판단은 게임의 콘텐츠 로그로 한다.
