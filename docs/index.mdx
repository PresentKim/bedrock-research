# Bedrock 개발 위키

이 위키는 마인크래프트 배드락 에디션 개발에 필요한 조사 결과를 한곳에 모은 것이다. JSON UI를 중심으로 Ore UI, 서버 화면, Script API, 애드온 콘텐츠, 렌더링, 서버·프로토콜, 도구, 엔진 내부 분석, 사례 연구를 다룬다.

예전에는 문서가 "어디를 보라"는 참조로 이어져 있어 읽기 어려웠다. 이 위키는 참조되는 정보를 발췌해 본문에 넣고, 출처와 라이선스를 페이지 하단 표에 적는다. 규칙 ID(`LAY-12`, `NB-07`, `C-31`, `D-05`)는 원자료와 같은 값을 쓴다.

:::caution[라이선스]
이 위키가 쓴 글과 코드는 MIT 라이선스다. 발췌 상자는 그 출처의 라이선스를 따른다. 재배포를 하기 전에 [라이선스 적용 방법](./reference/license.mdx)과 [출처 목록](./reference/sources.mdx)을 확인한다. GPL 자료의 발췌는 블록마다 라이선스를 표시하고 GPL 조건을 그대로 유지한다.
:::

## 검증 수준 표기

규칙과 사실 끝의 `{…}`는 근거의 종류다. 페이지마다 쓰는 표기가 조금씩 다르지만 뜻은 다음과 같다.

| 표기 | 뜻 | 신뢰도 |
| --- | --- | --- |
| `{실측}` | 게임 안에서 측정한 기록이 있다 | 높음 |
| `{바닐라}` | 바닐라 리소스팩이나 데이터 파일에서 실제로 쓰인다 | 높음 |
| `{작동팩}` | 배포되어 동작하는 팩이 그렇게 쓴다 | 중상 |
| `{코드}` | 소스, 컴파일 결과, 바이너리, 타입 정의를 읽어 확인했다. 게임 동작까지는 보장하지 않는다 | 중 |
| `{설치본}`, `{확인}`, `{문서}`, `{기록}` | 설치 폴더, 저장소 파일, 외부 문서, 측정 조건이 남지 않은 기록에서 가져왔다 | 중 |
| `{추론}` | 위 근거들로 판단했다 | 낮음 |
| `{미검증}`, `{충돌}` | 근거가 확인되지 않았거나 출처끼리 다르다. 쓰기 전에 실측한다 | 확인 필요 |
| `{실측 필요}` | 게임에서 확인하지 않았다 | 확인 필요 |

판정 우선순위는 `실측` > `바닐라` > `작동팩` > `코드` > `추론`이다. 커뮤니티 보고는 `(confirmed)`/`(확인됨)`, `(single report)`/`(단일 보고)`, `(conflicting)`/`(상충)`으로 표시한다. 게임에서 확인하지 않은 예제는 페이지에 따로 적는다.

## 라이선스

자료마다 라이선스가 다르다. 페이지 하단 표가 그 페이지에 쓴 출처와 라이선스를 보여 준다.

- 이 위키가 쓴 글, 코드, 시험 애드온은 MIT 라이선스다.
- 재배포가 허용된 자료(MIT, BSD, Apache, CC BY, GPL, 이 저장소 자료)만 원문을 발췌한다. CC BY와 MIT는 출처와 저작권 표기를 붙인다.
- 라이선스가 없거나 재배포를 막는 자료(All rights reserved, 비상업 라이선스, NetEase 문서, Mojang 비공개 바이너리)는 사실만 한국어로 다시 썼다.

각 라이선스를 위키에 어떻게 적용하는지는 [라이선스 적용 방법](./reference/license.mdx)에 있다.
