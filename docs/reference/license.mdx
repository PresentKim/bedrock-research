# 라이선스 적용 방법

이 위키는 여러 출처에서 가져온 내용을 담는다. 출처마다 라이선스가 다르므로 위키는 아래 원칙으로 다룬다. 어느 페이지가 어느 출처를 쓰는지는 페이지 하단의 출처 표에 있고, 전체 목록은 [출처 목록](./sources.mdx)에 라이선스별로 모았다.

## 발췌와 다시 쓰기

레지스트리의 `redistribute` 값이 기준이다.

- `redistribute: true`인 출처(MIT, BSD, Apache, CC BY, GPL, PolyForm Noncommercial, 이 저장소 자료)는 원문을 `<Excerpt>` 상자로 옮길 수 있다. 상자 머리에 출처 제목, 원문 경로, 라이선스, 커밋을 적는다.
- `redistribute: false`인 출처(라이선스 없음, All rights reserved, NetEase 문서, Mojang 비공개 바이너리)는 원문을 옮기지 않는다. 사실만 한국어로 다시 쓴다. 검사 스크립트는 이런 출처를 `<Excerpt>`로 쓰면 오류로 처리한다.

"사실만 다시 쓴다"는 것은 동작, 값, 구조를 설명하되 표현과 코드를 그대로 가져오지 않는다는 뜻이다. 그래도 원 자료의 권리는 원 저작자에게 있다.

## 라이선스별 처리

| 라이선스 | 처리 |
| --- | --- |
| CC BY 4.0 (Bedrock Wiki, MS Learn 문서, Chest-UI 등) | 원문 발췌를 허용한다. 출처, 저작자, 라이선스, 변경 여부를 표시해야 하므로 발췌 상자 머리와 페이지 하단 표에 적는다. 한국어로 다시 쓴 부분도 같은 출처를 적는다 |
| MIT, BSD-3-Clause, Apache-2.0 | 저작권 고지와 라이선스 문구를 유지하는 조건으로 발췌한다. 발췌 상자 머리의 라이선스 표시와 하단 표가 그 고지다. 소프트웨어를 그대로 가져온 경우에는 원 저장소의 LICENSE를 함께 보존해야 한다 |
| GPL-3.0 (AsaJS, StarLibV2 등) | 코드는 가져오지 않고 동작과 기법을 한국어로 설명하는 것이 기본이다. 발췌가 있다면 그 블록은 GPL 그대로이고 블록마다 라이선스를 표시한다. 발췌한 코드를 따로 가져가 쓰면 GPL-3.0 조건(소스 공개, 같은 라이선스 유지)을 따라야 한다. 위키의 나머지가 GPL로 바뀌지는 않는다 |
| PolyForm Noncommercial 1.0.0 (Cinnabar) | 비상업 목적이면 누구나 쓸 수 있다. 이 자료의 발췌가 위키에 들어 있으므로 **위키 전체를 비상업 목적으로만 이용**한다. 복사본을 배포할 때는 이 약관(또는 약관의 URL)과 `Required Notice:` 줄을 함께 전해야 한다 |
| 이 저장소 자료 | 이 프로젝트가 새로 쓴 분석과 시험 코드다. 위키와 같은 조건으로 쓴다 |
| 사실만 쓰는 출처 | 원문을 옮기지 않는다. 출처 표에 라이선스 상태(없음, All rights reserved 등)를 그대로 적는다 |

## 이용자가 지킬 것

1. **비상업**: 위키 전체를 상업적으로 쓰지 않는다. 학습, 개인 연구, 취미 프로젝트, 교육·공공 기관의 이용은 허용 범위다.
2. **출처 유지**: 위키의 내용을 옮길 때는 해당 페이지의 출처 표와 발췌 상자 머리의 라이선스 표시를 함께 옮긴다.
3. **GPL 발췌**: GPL 블록을 따로 가져가면 그 블록은 GPL-3.0을 따른다.
4. **상표**: Minecraft는 Mojang AB와 Microsoft의 상표다. 위키는 Mojang이나 Microsoft와 관계가 없으며 비공식이다. Mojang 파일(`bedrock-samples`)은 모든 권리가 Mojang에 있어 위키는 사실과 짧은 구조 설명만 다시 쓴다.

제3자 라이선스 요약은 저장소 루트의 `NOTICE.md`에도 있다. 이 문서는 법률 자문이 아니다. 확실하지 않은 이용은 원 저장소의 라이선스 파일을 직접 읽고 판단한다.
