이 페이지는 `scripts/gen-rules.mjs`가 `rules/*.json`에서 만든다. 직접 고치지 않고 JSON을 고친 뒤 `npm run gen-rules`를 실행한다. 주제 페이지의 규칙 글머리(`- **[ID]**`)도 같은 원본에서 채워진다.

설명과 예제는 주제 페이지 [패턴 레시피](../../json-ui/recipes.mdx)에 있다.

## 제안 규칙

아직 본문 규칙으로 합치지 않은 제안이다. 쓰기 전에 근거를 확인한다.

| ID | 규칙 | 수준 | [근거 환경](../rules.mdx#근거-환경) | [출처](../source-abbreviations.mdx) |
| --- | --- | --- | --- | --- |
| PAT-13 | **키로 짜는 2차원 배치.** 세로 팩토리 항목마다 (1) 가로 스택의 왼쪽과 오른쪽 spacer를 버튼 문자열 키로 켜서 버튼을 옆으로 밀고, (2) 그림은 높이 0 패널 안에 두고 항목 높이는 키로 끌 수 있는 sizer가 정하게 하면, "높이 없음" 키가 붙은 항목 다음 항목이 같은 줄에 놓인다. 서버는 평범한 버튼 목록만 보내고 `selection` 번호는 바뀌지 않는다. 겹친 항목끼리 눌림 영역이 겹치지 않도록 가로 spacer를 같이 준다. | 작동팩, 추론 | - | SLB 4장, GrimUI 키 문서 |
| PAT-14 | 상자형 서버 폼 레시피: 제목 플래그(HOST-34)로 크기를 고르고, 크기별 템플릿은 전역 변수 `ignored`로 쓰는 것만 생성한다. 칸은 `grid` + `collection_name: form_buttons`로 만들고, 칸마다 `'%.8s' = 'textures'`로 이미지와 `inventory_item_renderer`를 가른다(PAT-11). 수량과 내구도는 버튼 텍스트의 고정 폭 머리말로 보내고(EXP-11), hover에 툴팁을 둔다(INP-28). 숫자 ID는 `(#v - 0)`으로 넣는다. | 작동팩 | - | Chest-UI |
