이 페이지는 `scripts/gen-rules.mjs`가 `rules/*.json`에서 만든다. 직접 고치지 않고 JSON을 고친 뒤 `npm run gen-rules`를 실행한다. 주제 페이지의 규칙 글머리(`- **[ID]**`)도 같은 원본에서 채워진다.

설명과 예제는 주제 페이지 [파일과 정의](../../json-ui/files-and-definitions.mdx)에 있다.

| FILE-10 | 일반 속성의 변수 치환은 **값 전체가 변수일 때만** 된다. `"text": "$title"`은 되고 `"text": "제목: $title"`은 `$`가 그대로 찍힌다. 조합이 필요하면 변수 식을 쓴다(FILE-11). | 실측 | BC-facts |
