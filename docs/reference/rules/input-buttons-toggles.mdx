이 페이지는 `scripts/gen-rules.mjs`가 `rules/*.json`에서 만든다. 직접 고치지 않고 JSON을 고친 뒤 `npm run gen-rules`를 실행한다. 주제 페이지의 규칙 글머리(`- **[ID]**`)도 같은 원본에서 채워진다.

설명과 예제는 주제 페이지 [입력, 버튼, 토글](../../json-ui/input-buttons-toggles.mdx)에 있다.

| INP-32 | 바닐라 `common.button`·`common.toggle`은 `focus_enabled`가 켜져 있어 휴대폰에서 폼을 열면 첫 버튼이 호버 상태로 그려졌다. 폼의 모든 버튼에 `$focus_enabled: false`, 라디오 토글에 `$toggle_group_default_selected: -1`과 `$toggle_focus_enabled: false`를 준다. 라디오 토글은 형제끼리만 한 그룹이라 칸마다 부모가 다른 격자에서는 배타적이지 않았다(정적 토글에서는 다른 결과, INP-35, C-66).
